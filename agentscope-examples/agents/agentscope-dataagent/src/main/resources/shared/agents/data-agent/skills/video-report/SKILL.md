# 视频报告生成

当用户要求将分析报告转为视频时，使用此技能。

## 触发条件

- 用户明确要求"生成视频"、"做成视频"、"视频报告"等
- 前提：当前会话已包含数据分析结果（图表或表格）

## 工作流程

1. **提取旁白文本**：从之前的分析回复中提炼出 3-6 句自然语言摘要，覆盖关键发现和数据结论。
2. **调用 generate_video_report**：将摘要作为 `narration_text` 参数传入。
3. **展示结果**：工具返回视频文件路径后，在回复中引用视频。

## 旁白文本要求

- 使用简体中文
- 简洁明了，每句话对应一张图表的解读
- 包含关键数据点和结论
- **总长度严格控制在 100-300 字，绝对不超过 500 字**（超出部分会被截断）
- 建议 3-5 句简短摘要，不要逐条罗列所有数据

## 注意事项

- 仅在用户明确要求时生成视频，不主动触发
- 确保当前会话中已有图表图片（由 run_python 生成）
- 视频时长由旁白文本长度和图表数量自动计算
