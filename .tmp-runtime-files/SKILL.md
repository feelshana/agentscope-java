# 示例技能

技能是一段可被智能体按名称调用的操作手册。目录名（`example-skill`）就是技能 id。

## 何时使用

描述智能体应当使用该技能的场景。要写得具体——运行时会在智能体挑选技能时把这一节反馈给它。

## 步骤

1. 说明该技能需要的输入。
2. 描述要做的工作——读哪些文件、写哪些内容、总结什么。
3. 说明期望的输出格式。

编写完你自己的技能后请删除本文件。
