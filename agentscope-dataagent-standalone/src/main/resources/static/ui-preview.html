关键事实

低频用户虽有 95 人（占活跃用户近 1/13），但仅贡献 0.12% 的访问量；人均访问深度（2.2 次）仅为高频用户（145.9 次）的 1/66。平台流量高度集中于高频用户群体。

二、产品偏好：低频用户"单点依赖"，高频用户"双核驱动"

  • 高频用户：RS分析云 + 自助报表双核（60% + 39%），呈现"查询+自助分析"的深度组合使用习惯。
