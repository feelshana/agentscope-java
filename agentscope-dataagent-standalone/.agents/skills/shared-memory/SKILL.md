# 项目共享记忆

Codex-A 和 Codex-B 使用同一项目目录下的文件交接。账号名称只是用户标签，不代表能访问对方的聊天历史。此 Skill 维护协作记录，不自动提交 Git，也不扩展当前任务的业务修改权限。

## 共享位置与职责

以本 Skill 所在的项目根目录为基准，不要把上层 Git 仓库根目录误当作 IDEA 项目根目录。本文件位于 `.agents/skills/shared-memory/SKILL.md`，下面的路径均相对于项目根目录。

- `AGENTS.md`：先读取，遵守已有规则。
- [PROJECT_CONTEXT.md](../../../docs/ai/PROJECT_CONTEXT.md)：架构、模块、运行方式与长期背景；架构变化时更新。
- [CURRENT_TASK.md](../../../docs/ai/CURRENT_TASK.md)：当前目标、已完成、未完成、测试、阻塞和具体下一步；恢复任务的入口。
- [DECISIONS.md](../../../docs/ai/DECISIONS.md)：技术决策及原因；区分已接受、待讨论和已取代，链接正式 ADR。
- [SESSION_LOG.md](../../../docs/ai/SESSION_LOG.md)：按时间追加简短 checkpoint / handoff 历史。

共享记忆用于导航和交接，不替代代码、Git 差异、测试输出或正式 ADR。只记录已获得的事实；推断、历史报告和待确认事项必须标注来源及状态，不把建议写成已授权的决定。不写入密钥、令牌、完整敏感日志或不必要的个人数据。

## Resume：恢复任务

1. 读取项目根目录 `AGENTS.md` 和上述四份记忆；结合用户最新指令确定当前任务。用户仅说“继续任务”时，优先恢复 `CURRENT_TASK.md` 中未完成事项；用户明确切换任务时保留旧任务为待续。
2. 检查 `git status --short`、当前分支以及任务相关的 `git diff`；必要时检查暂存区和未跟踪文件。记录本次起点，既有修改不能视为本次成果。Git 不可用时记录限制，不假称工作区干净。
3. 根据记忆中的模块、ADR/spec 和具体入口阅读实际代码。对照已完成清单，确认代码是否存在、是否已测试、运行服务是否加载新版本；记忆与实际状态不一致时记录差异。
4. 找到尚未完成的具体操作，优先继续它。历史测试通过不等于当前工作区已验证；不重复开发已有实现，不将待讨论建议直接执行为业务改造。
5. 简短说明恢复出的目标和下一步；仅对无法从文件、代码或现有授权确定的重要问题请求澄清。

## Checkpoint：保存阶段进度

1. 重新读取即将更新的记忆文件并核对 Git 差异，保留其他 Agent 新增的信息；按段落合并，不用旧副本覆盖整份文件。发现同时编辑相同段落时先核对内容，无法确定再说明冲突。
2. 更新 `CURRENT_TASK.md`：更新时间、执行者（已知才写账号标签）、分支、目标、已完成与未完成、相关修改文件、测试命令及结果、阻塞、待确认事项、下一步具体操作。
3. 测试记录注明本次实测或引用的历史记录，列出失败、跳过和未运行项。分别记录代码完成、验证完成、服务加载及提交状态；不把其中一个状态替代其他状态。
4. 将重要决定及原因更新到 `DECISIONS.md`，保留已取代决策的来由；需要正式架构决策时按项目规则另写 ADR，共享记忆不代替 ADR。
5. 追加 `SESSION_LOG.md`：日期/时间（含时区，能获取时才写具体时间）、checkpoint 类型、执行者、成果、验证、遗留事项与下一步。只写简要交接，不复制整个聊天。
6. 检查更新后的内容和文件范围，报告已保存的位置。普通记录只修改必要的记忆文件；规则和 Skill 只有协作方式变化时才改。

## Handoff：切换账号前交接

先执行 Checkpoint，再将 `CURRENT_TASK.md` 整理到接手者无需访问原聊天即可继续：

- 明确已完成、部分完成、尚未开始，以及待用户决策的内容。
- 列出相关已修改/新建文件和已有未提交改动；未知作者就标注“既有改动，来源未确认”。
- 记录可重现的测试命令、结果与环境限制，不推断另一个账号有相同工具或权限。
- 写清下一步操作顺序、代码入口和验收目标；保留被当前任务暂时打断的任务。
- 不自动 commit、push、stash、reset、clean，不覆盖、删除或回滚其他 Agent 的未提交修改。此 Skill 不提供这些操作的授权。

若任务中断，只把实际已完成的工作写为完成，并明确最后一个可靠检查点。不能假设中断中的工具已成功。

## 两个账号的调用方式

在同一个 IDEA 项目中使用：

- `$shared-memory 恢复任务`
- `$shared-memory 保存进度`
- `$shared-memory 交接任务`

也可说“继续任务”“保存进度”“交接任务”，由项目 `AGENTS.md` 引导加载此 Skill。若当前客户端未发现新 Skill，开启该项目的新会话；仍未列出时，明确要求读取 `.agents/skills/shared-memory/SKILL.md` 并执行对应流程。共享的依据是同一份本地文件，不是两个账号之间的自动聊天同步。
