01

打造世界级 Data Agent 的五大架构设计原则

对标 Linear 的结构秩序、Cursor / Claude Code 的透明人机协同、以及现代语义层产品的数据可信度

5 PILLARS
PILLAR 01 · DUAL-MODE NATIVE

双模式原生形态，而非「一套壳子打补丁」

普通问数（探索分析）以靛蓝为识别色，围绕「关系图谱 + 业务规则 + 问数优化」运转；口径问数（强管控）以矿石青为识别色，围绕「文档绑定 + 口径四步流水线 + 选表目录 + 门禁发布」运转。顶栏、侧栏、概览、首次准备与发布台全部随模式原生变形。

PILLAR 02 · CO-PILOT TRANSPARENCY

Agent 是透明协作者，不是黑盒也不是杂乱终端

彻底禁止将内部编排 Prompt 渲染为用户气泡；将平台触发动作抽象为结构化意图卡片；将 20+ 工具调用折叠为 4 阶段里程碑；HITL 确认卡用人话和可视化结构表达（N ── 1），并在画布上以幽灵连线（Ghost Edge）直接呈现草稿提议，做到 Cursor 级别的就地审阅。

PILLAR 03 · SEMANTIC-FIRST GOVERNANCE

只暴露语义对象，把 Git 与脚手架藏在后台

业务与数据建模人员关心的是「模型、关系、规则、口径、视图」，而不是 .gitkeep 或 AGENTS.md。审阅单、侧栏草稿数与画布角标统一按「语义对象」单一数据源计数；工程源码留给「工程与快照」整页，不污染日常审阅。

PILLAR 04 · ZERO-FRICTION FLOWS

消除伪对话、弹窗套向导与竞争主按钮

首次建模用纯结构化分步工作区（内联 Master-Detail 选字段 + 模式自适应准备清单），砍掉底部尴尬的命令输入框；任何屏幕永远只有 1 个实心主按钮，禁用态必带可点击修复原因；状态全部用 6px 状态点 + 轻文字，根治黄块泛滥。

PILLAR 05 · EVIDENCE & CLOSED LOOP

每条口径可溯源原文，每次问数可回流调优

在口径核对页，右侧直接高亮《业务口径手册》原文段落，告别切屏对照；在端到端问数页，每条回答自带「已命中口径 / 引用规则 / 引擎路径」可信溯源条，管理员一键点击即可回流「问数优化」或「修正口径」，形成越用越准的飞轮。

Agent 专属视觉原语（世界级 Agent 产品的核心细节）

组件设计规则
Intent Chip（意图胶囊）替代原始系统 Prompt 气泡：单行淡色胶囊显示「图标 + 任务类型 + 业务对象」，技术 Prompt 默认隐藏，仅管理员在开发者模式可展开。
Milestone Rail（过程轨）4 阶段（读取采样 → 推断结构 → 写入草稿 → 校验编译）+ 实时计时；连续相同动作自动聚合，隐藏底层 skill 挂载降级日志。
HITL Decision Card左侧 3px 主题色条，顶部进度 1/3 + 影响标签；严禁出现 MANY_TO_ONE 等代码枚举，必须用「多对一」+ 可视化 N──1 图示与行数采样证据。
Ghost Edge（画布幽灵连线）Agent 提议的候选关系直接以虚线绘制在关系图上，悬浮或点击节点即可就地「✓ 采纳 / ✕ 忽略」，不打断空间思考。

按钮四档铁律 & 无障碍底线

① 唯一主动作（Primary）
整个视口严格 ≤ 1 个实心按钮，标明「现在唯一最该点的动作」。
② 描边次动作（Secondary）
白底 + 1px 轻边框，顶栏同排 ≤ 2 个。
③ 轻量三级（Ghost）
无边框，用于次要查看、返回或危险前导入口。
④ 禁用必带可点原因（Disabled + Fix）
旁侧必给内联跳转：「2 张表口径未完成 → 去处理」。

无障碍底线：所有 Modal 与 Drawer（含创建知识库、口径发布检查）强制 role="dialog"、aria-modal="true"、焦点锁与 Esc 关闭。

# 执行红海 DataAgent 旗舰界面重构（F01–F36）
优先级顺序：Wave 1 (Agent止血与Git噪音过滤) → Wave 2 (双模式顶栏/侧栏/概览/统一发布台) → Wave 3 (创建决策卡/列表/结构化首次建模) → Wave 4 (关系图/规则/问数优化/公共视图) → Wave 5 (口径溯源核对与验证) → Wave 6 (工程/详情/问数闭环)

五条铁律（验收零容忍）：
1. 严禁将平台拼接的 orchestrator prompt 渲染为用户气泡（统一用 Intent Chip + label）。
2. 严禁将 .gitkeep / .gitignore / AGENTS.md 计入业务草稿徽标或置顶于审阅清单。
3. 严禁同屏出现超过 1 个实心主按钮，严禁使用大面积黄底作为状态提示卡。
4. 严禁在首次建模的表单向导底部保留假聊天输入框或用弹窗嵌套在整页向导上。
5. 保留已落地的工程整页与事实表时间范围能力，不重复造轮子；不单独新建「草稿与发布」一级菜单。
