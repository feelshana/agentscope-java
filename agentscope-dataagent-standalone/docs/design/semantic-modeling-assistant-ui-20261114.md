预览：[semantic-modeling-assistant-ui-20261114.html](semantic-modeling-assistant-ui-20261114.html)。用户最新要求收窄为：保留对话建模的所有功能、展示内容和话术，只优化美观度。本稿替代上一版 assistant 原型作为下一步评审依据，原稿仍保留用于追溯。

## 边界

- 本次只新增独立 HTML 和设计说明，不改前后端、数据库、接口、运行服务或静态构建产物；不提交、不推送。
- 保持当前功能和话术为设计基准，不采用上一版原型新增的停止/重校验动作，不重写助手的输出摘要，不把内联工具内容改为仅能在弹层中看。
- 助手输出段落使用用户截图的示例内容；系统文案、按钮、输入状态取自当前组件。LLM 输出本来是动态内容，不主张用这些示例替换模型回复。
- HTML 用内存夹具展示外观，上传、提交、编辑、授权、删除、预检、发布不调用真实接口；这些能力在产品中的原始协议和行为不因本稿而改变。

| 恢复与提案 | 关系调整、工程预检、差异与 JSON 调整共用卡片样式 | 原有关系/文件/通用提案动作和原文入口 |
| 输入区 | 输入框边界、焦点、文档按钮、发送按钮统一 | 原占位提示、IME/换行、发送条件；busy 或待 HITL 时禁用输入和文档按钮 |
| 异常 | 柔和红色提示与可展开技术详情 | `friendlyError` 原有摘要和行动提示；不另加操作 |

窄屏 CSS 保留对话阅读优先，长代码可在自身区域滚动，结果说明按行重排。深色通过设计区的预览按钮检查配色方案，不代表产品新增全局主题功能。

## 10 种预览场景

1. 空对话与快捷示例：当前四个例子点击填入输入框，可修改后发送。
2. 执行中与过程明细：原里程碑、当前工具、耗时；输入和附件禁用；不展示尚未发生的后续任务。
3. 建模完成、待你确定：截图中的完整过程与回复、两条模型结果、一题口径。
4. 多题确认：自己写空值报错、不采用、稍后，以及最后一题后一起交给助手的提示。
5. 工具内容展开：写入 YAML 原位滚动，点击“放大阅读”查看完整内容。
6. 结果展开与编辑：字段/表说明、查看原来、保存/取消，关系/业务语义/注意事项与展开全部。
7. 恢复会话与关系提案：原恢复提示、技术详情、关系方向/字段调整、四个原操作。
8. 文件提案：预检结论、全文、差异、编辑、重新预检、采用与跳过。
9. SQL 示例与参数调整：SQL 原文、JSON 参数、修改要求、采用修改后的参数及 JSON 对象校验。
10. 异常响应：原友好错误摘要、行动提示、失败工具行和技术详情。

这些是视觉样本集合，不是新增产品场景切换器。关系批量提案、整套方案、规则警示、撤回文件等低频分支没有逐一搭建完整交互演示；若正式实施，仍保留其组件逻辑与所有文案，仅套用相同视觉规则。原产品功能未被替换或删减。
