设计说明 · Design Read

先定方向再写页面。下面每一条都能指着屏幕否决，确认再改比做完再推翻便宜。

被否决的默认方案

数据分析页最容易直接套「蓝 + 绿 + 橙」的通用 SaaS 三色，或者照搬品牌站的紫色发光、颗粒噪点、巨型标题和实时渲染背景。这些都否掉。项目里现存的三种紫各自为政、白底硬描边卡片也一并否掉，改为一套锁定主色。

配色（从配色库现成组合里选）

Set 5 · Violet Console：带紫色相偏移的中性纸 #eeecf7，一个锁定主色 #5B4BD1，伙伴色陶土橙 #D98A3C 只用于第二条数据系列。上涨 / 下跌 / 警示另走语义色，不和主色抢。不是蓝色仪表盘，也不是发光紫。

page / bg / accent / accent-2 / ink / up / down

页面结构

沿用项目真实目录与面包屑，非对称 Bento（5 / 2 / 2 / 3 / 4 / 3 的不同宽度格），一张深色主卡承载点阵数字，顶部一条 12 周时间轴作为非卡片中心件。下方单独一整块数据模型：实体关系图 + 数仓分层表 + 表清单，不是只有 KPI。

你会看到什么

淡紫纸底上浮着白卡，卡片只有极细的发丝描边和 20px 大圆角，没有硬灰框。左上是一张深色卡，主数字由小圆点拼成。点时间轴上的任意一周，主数字、四张指标卡、柱状图和折线标记会同时换成那一周的真实值，不刷新页面。柱子的高矮明显不同，每根柱子下面都有名字、上面都有数值。

动效清单（都有静止版）

① 卡片依次浮入 ② 指标数字从 0 滚到目标 ③ 柱子填充从底部长起 ④ 折线自己画出来 ⑤ 圆环走到 40.05% ⑥ 84 个日活圆点逐颗亮起 ⑦ 建模状态圆点逐颗点亮 ⑧ 时间轴联动是即时切换，不算动画。每条都带系统「减少动态效果」的终态兜底，关掉动画后页面直接是完整静止的一帧。

图片

0 张，且这是刻意的。这一屏每一寸都是数据驱动的几何：柱子、折线、圆点、实体关系图都由 test_data/03-视频平台 的真实数值算出来，没有摄影位也没有插画位。按规则我不会擅自生成或下载任何图片。

反默认两层检查： 第一层「数据平台 → 蓝色三色」已避开；第二层「不蓝就改成暗色终端 / 编辑式大衬线」也避开，落点是浅色纸 + 平面主色 + 高信息密度。项目首次按这套规则出稿，没有历史方向需要绕开。
否决点 ①　想保留品牌紫但不要现在这套分裂的三紫：当前稿已把紫收敛成一个 #5B4BD1。若你觉得应该彻底换掉紫，换成库里的 Set 4 · Teal & Clay（青绿 + 陶土）只需替换开头一处变量块，其余布局不动。
否决点 ②　不想要深色主卡和弥散光晕：可以把它降成一张普通白卡，点阵数字改放在浅底上。代价是首屏少了一个视觉重心，Bento 的层次会更平。

规范与自检

按 product 路线落地后的令牌、图表几何、动效终态，以及反廉价黑名单和起飞前自检的逐条结果。

配色令牌（一处定义，全文只引用变量）

碰撞检查：主色紫不与上涨绿 / 下跌红冲突；--ink-3 在卡片底上达到 4.5:1；主色在白卡上达到 3:1；描边用 alpha 而非硬灰；--glow 全屏只用一次。

KPI 卡片结构（每一张都按同一套解剖）

顶部 30px 图标块 + 右侧状态小标 → 11px 标签 → 25px 大数字（等宽数字、负字距、从 0 滚入）→ 单位 / 上期说明 → 底部 30px 火花线或圆环。
不给 6 张一样大的格子：主卡 5 栏跨 2 行，其余按 2 / 2 / 3 / 4 / 3 栏分配。

图表选型与几何（零依赖，手搓）

  • 品类比较 → 柱状图。全部 12 周用 value / 2800、单周用 value / 280（真实单周单品类峰值 242），两套域上限都从 0 基线算，10 根柱每根有名字和数值。切换作用域时图例与说明一起换，不留下上一步的数字。
  • 时间趋势 → 折线 / 面积。ys(v) = (H−pad) − (v−min)/(max−min) × (H−2pad)，12 个真实周值。
  • 占比 → 圆环。dashoffset = C × (1 − 40.05%)。
  • 密度 → 84 天点阵，4 档亮度按当日去重人数分桶。
  • 时间轴联动 → 主数字、KPI、说明文字即时 set，不插入补间；柱子重绘时做一次 0.62s 高度过渡，减少动态效果下直接给终值。

动效与终态兜底（8 条）

全部是状态反馈，不是表演。开场先读 RM = prefers-reduced-motion 和 FINE = hover+pointer:fine，每个效果各自分支：数字滚入 → 直接写终值；柱子 / 圆环 → 直接置 scaleY=1 / 最终 offset；折线 → dashoffset=0；圆点 → 全部 opacity:1。另有全局 CSS 兜底。没有 bounce、没有滚动触发、没有 WebGL。

值得先采纳的几处（按改动成本从低到高）

  1. 把三套紫收敛成一套令牌：主界面 #6654CE、列表页 #5B4BD6、建模区 #5F4BC8 改成一个变量，是这一稿最直接的收益。
  2. 柱状图按 value/max 从 0 基线算：不要等高柱，不要只有悬停才显示数值。
  3. 数据模型单独成块：ER 图 + 数仓分层表，别只做通用 KPI 看板。
  4. 时间轴做成真正的联动：选中一周，所有指标和图表即时换值，且不刷新页面。
  5. 状态只用 6px 圆点 + 文字，动效全部带「减少动态效果」终态兜底。
  6. 卡片换成发丝描边 + 20px 圆角 + 带色阴影，页面底改成带色相偏移的中性纸，去掉纯白纯黑和硬灰框。
