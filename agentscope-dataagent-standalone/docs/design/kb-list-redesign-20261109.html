设计原则

五层信息，只留一层强调

  • 标题 → 状态 → 说明 → 元信息 → 动作
  • 只有主按钮使用实心紫，其余全部降级为灰阶
  • 状态用「颜色点 + 文字」而非彩色底块，避免整屏花

单一主行动

  • 已发布库：「开始提问」是唯一主按钮
  • 未发布库：主按钮自动变为「继续建模」，不误导用户去问数
  • 「查看数据」降为文字链，保留但退居次位（Vercel / Linear 做法）

宽度决定舒适度

  • 单卡最小 300px，最多 4 列，不再出现 5 列
  • 卡片高约 210px，行间距 18px，圆角 12px
  • 说明固定 2 行并占位，保证同一行卡片底边对齐

落地改动（对应现有 DatasetsPage.tsx / DatasetsPage.css）

栅格

.kb-library .kb-grid{
  display:grid; gap:18px;
  grid-template-columns:
    repeat(auto-fill,minmax(300px,1fr));
}
@container (min-width:1560px){
  .kb-library .kb-grid{
    grid-template-columns:repeat(4,minmax(0,1fr));
  }
}
/* 删除原 ≥1364px 的 5 列规则 */

卡片结构

  • .kb-card padding 16 → 18，圆角 8 → 12
  • 新增 .kb-card-titlebar：渐变图标 + 标题 + 状态行
  • .kb-card-state 与 .kb-card-info 合并为一行 meta，用 · 分隔
  • .kb-permission 从紫底药丸改为灰字，降权
  • 按钮高度 30 → 32，「查看数据」改文字链

状态语义

  • ● 已发布 vN — 可问数
  • ● 待建模 — 数据已接入，尚未发布
  • ▢ 草稿待发布 — 附带紫色小标签
  • 悬浮：整卡上浮 2px，更多操作（⋯）淡入
