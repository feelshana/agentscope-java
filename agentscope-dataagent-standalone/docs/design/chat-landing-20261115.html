改动要点

① 垂直空间策略

内容列 margin:auto 垂直居中 + 底部多留 28px 做视觉上移。有引导卡约 640px、无引导卡约 480px，两种状态都平衡，不再出现「溢出切卡」或「下半屏全空」。右上可切换两种状态预览。

② 新手卡 → 轨道步骤条

高度 260px → 约 185px。与问数优化 / 公共视图的 .mflow 同一组件族：22px 空心环 + 1px 轨道，只有当前步实心。只有当前步有主按钮，其余步骤的入口收成 hover 才出现的文字链。完成态环变绿勾。删掉卡中卡、四条「第 N 步」重复标签和装饰渐变。

③ 状态对齐（逻辑建议）

现状按注册时间推进 onboarding stage。建议叠加一条状态判断：用户已有可问数知识库时，「准备数据」直接计为完成——不教已经会的人。对应截图里已选知识库却显示 0/4 的矛盾。

④ 推荐问题自然语言化

标题从数据原文（2026-05-01 至 2026-10-31…）改为人话；日期区间降级为 meta 小字。三张卡按意图区分并配图标：趋势 / 对比 / 排名。知识库名提升到分区标题一行，不再每张卡重复。hover 改底色 + 描边，不上浮。

⑤ 输入区控件统一

三个 chip 统一 30px / 8px / 软底：可选项=软底+值+chevron（知识库）、开关=开关态+圆点（联网搜索）、菜单=软底+chevron（分析）。空态输入区从约 90px 收到 2 行（44px），有内容再长高。发送按钮禁用态改 --surface-3 底 + --ink-3 箭头，不再几乎隐形。

⑥ 圆角与 token 清理

圆角收敛三档：大容器 18（composer）、卡片 14（引导卡 / 推荐卡）、控件 8。品牌行「红海 DataAgent | 你的大数据智囊团」从主区删除（侧栏已有），问候成为第一落点。全部色值走 token，暗色自动跟随。
