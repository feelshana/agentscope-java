不要顺手做的事

不要把侧栏再收窄

244 是「草稿与发布」+ 数字徽标 + 17px 图标的底线。 再往 230 以下走，五个字以上标签会开始省略，反而更难扫。

不要给表格加斑马纹

现在 0.5px hairline 分隔是这套界面的基线。 加斑马纹或竖线网格会让 20 行的预览表看起来像 Excel，和其余页面不是一套。

不要在关系图加自动推荐卡

「自动识别候选关系」是用户主动点的动作。 默认再弹一张推荐卡，等于把刚关掉的提示换个样子又塞回来。

不要给预览表加分页

20 行是采样上限，不是分页大小。 加「加载更多」会让人以为能翻到全量，但采样只有 200 行，翻不出东西。

给 codex 的第一句话

按 docs/design/kb-workspace-finetune-20261125.html 执行第三轮微调，共 16 处（W1–W16）。 顺序见 08 章：先 W3/W4/W5 数据集 → W6/W7 单点 → W1/W2 侧栏与图标 → W8–W11 问数 → W12/W13 公共视图 → W14/W15/W16 协作三页。 每条都有「现在 / 改成 / 验收」，以「验收」为完成标准，尺寸用 getBoundingClientRect() 量，不靠目测。 不要改路由、接口返回结构、目录项数量；不要引入新依赖；不要顺手加斑马纹、分页、推荐卡。
