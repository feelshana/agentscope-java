# spec146：看板生成任务恢复与体验缺陷修复

状态：用户明确批准生成任务恢复，并要求修复内部消息、卡片信息及描述保存。本地实现与隔离验证完成，待用户重启IDEA进行真实知识库验收；不提交/部署。ADR0151补充任务订阅归属，不另造Agent循环。

## 范围与验收

1. 看板生成由服务端持有对既有ChatController/Harness执行流的订阅，完整复用RUN、单库、原生会话、容量/超时和工具权限。POST使用请求ID及期望修订，幂等重试不重复执行；同看板最多一个活跃生成，另一用户不读取他人的任务消息。GET恢复状态/真实阶段/有限回复，显式POST停止；读取任务不自动运行模型。
2. 任务最近记录在资产目录原子持久化，前端离开只停止轮询，不取消生成；再进入恢复原任务并重载实际草稿/历史。服务重启后遗留非终态标中断，不虚构继续运行或自动重跑；无跨进程迁移执行承诺。删除/恢复/检查点阻止活跃生成，任务文件随看板清理，状态刷新不得复活已删除资产。
3. 手动轮次服务端保存页面检查点；自动修复关联原任务，仅允许一次，继承原检查点；恢复旧已完成任务不触发新的模型请求。界面显示运行/完成/失败/停止/中断，失败不当成成功；刷新后停止/撤销及后续生成可用。
4. 按框架保留名/稳定ID识别compaction内部消息，在历史解析及既有展示投影中排除，保留模型原生上下文文件不改。真实用户文字即使提到summary也保留；问数/建模/看板展示一致，统计不新增内部提问。
5. 卡片知识库、创建归属、更新和创建时间同一紧凑信息带，长库名省略/窄屏换行；不伪造旧日期或其他人姓名。既有列表视图/筛选/权限动作保持。
6. 修复CORS遗漏PATCH：保持原允许来源及JWT/Agent/资产权限；真实预检、跨源PATCH及无授权拒绝均验证，不以开放权限绕过403。

## 验证

任务幂等/离开后继续/恢复/停止/失败/重启中断/撤权/其他用户隔离/并发拒绝/删除保护与文件清理；历史内部摘要排除及真实消息保留；CORS GET/PATCH允许与无授权拒绝；前端相关测试、构建、真实浏览器隔离交互及文档门禁。真实LLM/Wren条件结果单独记录，不能以模拟执行冒充全链路。

本轮结果见[20261118报告](../test-reports/20261118-dashboard-generation-recovery.md)：任务/控制器/权限/CORS与H2历史投影回归通过；浏览器模拟任务接口验证刷新、重进、各终态、最多一次修复及撤销检查点继承。未重启用户服务或调用真实模型/Wren生成；保持进行中。
