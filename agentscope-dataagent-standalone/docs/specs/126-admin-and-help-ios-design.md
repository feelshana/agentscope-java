# spec126：全局管理员与帮助引导设计落地

## 目标与依据

按用户指定的 `docs/design/admin-help-ios-20261111.html` 改造实际界面，沿用项目图标、导航及真实权限。用户要求保留开始逐步指引、重新打开新手任务、重置新手任务。

## 实现范围

- 管理页采用紧凑页头、白色名单卡、姓名/账号/部门即时本地过滤、头像与权限说明卡。添加管理员使用搜索选择弹窗和明确确认，移除使用行内确认，保留最后管理员保护与失败反馈。
- 只展示现有接口提供的成员和部门。不伪造权限来源、授予时间、在线状态或变更日志，不修改角色和授权规则。
- 帮助抽屉采用516px设计宽度、搜索、分类定位、四步任务进度和帮助卡片。原三项任务动作保留，重置仍确认并说明已有数据保留。
- 复用现有接口、引导状态和路由；不新增UI库，不实现设计稿中的演示标注或无实际目标的联系/文档按钮。

## 验收

真实操作逻辑接通；添加/移除失败保留输入，最后一人不可移除。中文搜索、键盘、加载/空态/错误、窄屏与iframe可用。帮助三个动作各调用原流程，重开不重置，重置只改任务记录。构建、现有测试及浏览器隔离接口验证，未授权不提交/push/部署。

## 本地实施状态

2026-11-11：页面和三项原操作已实施；前端三个部署前缀各104项、最终构建、Spotless及后端1131项（33条件跳过）通过，Maven打包成功。Chrome隔离接口验证失败保留、权限门禁、中文组词、三项新手动作和窄屏/门户iframe通过。详见[测试报告](../test-reports/20261111-admin-help-design.md)。待用户在实际账户与环境试用；未提交/push/部署。
