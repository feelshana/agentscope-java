# spec141：对话生成 GenBI 仪表盘试用版

状态：用户已批准实现；试用版已完成本地实现与真实Agent/浏览器验收，待用户试用。[验收记录](../test-reports/20261116-genbi-dashboard-trial.md)。

## 背景与目标

用户选择一个已发布知识库，通过自然语言生成整张看板，在同一工作台预览并继续修改，最后由管理者发布给有知识库查询权限的成员。复用官方 GenBI 的构建指导与校验，以及平台现有 AgentScope 会话和 Wren 查询，不自行编写另一套 Agent 循环。

## 方案概述

- 新增独立 dashboard-agent，挂载与 CLI 同源的官方 genbi/usage 技能；受限工具调用官方 genbi build/register/verify，Agent 使用原生文件工具编写单页 HTML。
- 独立工程从已发布模型复制语义上下文，禁止修改知识库模型、profile、平台文件。每个草稿固定绑定创建者、知识库和独立会话。
- 试用版采用 live 模式：生成页面通过平台桥查询官方 Wren MCP；身份和凭证留在宿主页面。预览在无同源权限的 sandbox iframe 中运行，限制外联与顶层跳转。
- 官方 build 给出通用网页指令；平台补充内部托管协议、ECharts 运行库和 live 查询桥，不调用外部 deploy/open。发布需管理者显式点击，发布为不可变 HTML 修订，后续编辑不改变已发布页面。
- 后端负责资产、ACL、版本和查询，前端负责工作台、SSE 对话和隔离预览。更新 ARCHITECTURE 第14章，ADR0149 记录执行边界。

## 影响面

- 后端：dataset 仪表盘资产服务、tools/data 工具、runtime 上下文、Agent 装配、web API 与聊天选库校验。
- 前端：仪表盘列表/工作台/发布浏览、菜单与 API；按路由延迟加载，避免增加登录页负担。
- 数据：平台 MDL 持久根目录下新增独立 dashboards 目录，原子元数据与不可变版本；不修改既有业务表。

## 验收标准

1. 已发布知识库的查询用户可建自己的草稿，对话能调用真实 GenBI 指令和官方 Wren 查询生成 HTML，刷新后能恢复。
2. 预览可显示真实统计、筛选和图表；查询失败明确显示错误，不以假数据代替。
3. 继续对话修改草稿；知识库管理者可发布选定版本；普通查询成员只能浏览已发布版本，不能访问他人草稿或发布。
4. 撤销知识库权限后，预览/查看/查询与排队执行都重新校验；路径逃逸、密钥内容、任意 CLI、未选择知识库的调用被拒绝。
5. 编译、相关后端测试、前端构建和文档门禁通过；真实 Agent 验收单列结果，不以单元测试替代。

## 不做的事

- 本版不做逐图钉入、拖拽布局、公开匿名链接、外部云托管、定时截图或跨库看板；不把 GenBI 描述成自行生成代码的服务。

## 测试要求

- 覆盖私有草稿、发布隔离、ACL撤权、查询边界、路径/命令限制和版本竞争；验证隔离预览消息来源及查询错误。

## 2026-11-16 用户批准的界面优化

按 [HTML设计稿](../design/dashboard-ios-preview-20261116.html) 落到正式React：沿用知识库底色/白卡/圆角/柔影/动效，真实归属筛选和版本状态、收起对话/展开预览/手机切换、显式发布确认。创建入口与首次对话按下方追加需求精简。列表投影增加当前用户是否创建的布尔值，不泄露ownerId。缩略封面只来自已打开预览中的实际ECharts渲染，当前登录内存有界缓存，刷新/登录变化不持久；无缩略图时明确提示，不在列表批量查询、不使用宣传样例冒充用户数据。生成文档本身不套用静态样板HTML；完整保留原生Agent/ACL/Wren查询/隔离/发布边界。无新增ADR。

## 2026-11-16 用户追加：精简入口、权限说明与完整删除

- 列表复用知识库/语义建模/例行任务的页面容器、标题及边距；删除重复创建引导和“我的看板”标题，仅保留新建按钮、范围筛选及搜索。
- 新建仅选择已发布知识库、填写名称，进入空白创作会话后由用户描述需求，不自动发送。
- 权限继续继承知识库；卡片/工作台提供“访问权限”说明，管理者可进入原有知识库成员管理，明确影响同库所有看板。全局管理员依既有规则可管理所有库；普通QUERY用户仅能看已发布版，创建者/管理者可编辑草稿，管理者发布。
- 删除由创建者或知识库管理者发起，HTTP重新校验RUN及知识库权限；不可通过仅隐藏列表实现。确认说明将清理元数据、独立GenBI工程/草稿、全部发布修订、校验/临时文件、关联原生会话上下文/转录/历史投影/附件/已读与选库记录以及本地封面缓存；不删除知识库、上传表、语义模型、共享记忆或平台审计日志。
- 用现有原生会话门禁拒绝运行中删除；持久删除标记阻止新入场/工具/查询/发布。清理清单保留完整会话身份以支持部分失败/进程重启重试，待清理卡片显示重试入口；根目录/文件不得通过链接逃逸。
- 验收覆盖创建者/管理者/仅查询/无权限、运行中/部分失败/重试、全部修订与专属会话附件清理、其他库/其他Agent与其他会话不受影响，以及目录链接防护；UI不使用样例数据冒充删除成功。
