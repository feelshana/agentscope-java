# 150 · 问数优化与建模对话联动

状态：已实现并通过隔离浏览器验收，待真实知识库和 Wren 联调体验。

## 用户流程

- 工作台空态以「添加业务问题」为主操作，展示已有候选问题。使用说明、试问和已确认问答保留独立入口。列表有题时用「待处理 / 已确认」和状态筛选组织工作，保留批量分析与批量重写。
- 选题后优先展示当前状态、口径与下一步。SQL、上一次 SQL、展开后的 SQL 和 MDL 按需查看。口径待确定时显示业务资料入口。已保存示例区分待发布和已发布。
- 建模对话从快捷提示、题目详情或明确的问数优化指令进入单题范围。输入区显示可移除的题名标签。匹配多个题目时先选题。新增题目使用现有问数优化流程。题目结果可从对话直接定位，题目与状态均取真实草稿。
- 「查看这道题」和「边聊边核对」打开同一种并排形态，左侧显示单题，右侧保留助手。窄屏在两区之间切换。关闭对照回到发起位置，保留题目和未发送的输入。
- 单题请求固定到本知识库中的题目 ID，只能写该题文件。需要改变共享口径、关系或计算字段时，先给出与此题关联的方案，沿用现有批准流程。单题澄清留在会话内，用户回答后继续处理该题。SQL 走已有草稿规划和人工核对。显式发布后供线上问数参考。

## 验收

- 从全屏对话选择一道已存在的题，修正单题过滤条件。结果卡可以直达同一题。并排和工作台显示一致的状态与 SQL。原题以外的业务规则和问答文件受写入限制。
- 从工作台进入、关闭对照，切换时保留输入。宽屏可同时查看，窄屏可在题目和对话间切换。现有试问、批量处理、口径卡片、问答确认和统一草稿发布入口可用。
- 关闭对话再进入，已经处理的单题仍能从历史消息定位。运行失败时保留可重新提交的用户请求，结果以草稿实际状态为准。
- 当输入匹配多题时，即使已有题目标签也先由用户选定。可搜索题名，选题后原消息可继续发送。
- 对照上一次 SQL 时提供返回当前版本的入口。保存携带用户核对的题目修订，若其他窗口或助手已改写则重新加载题目，要求核对新内容。
- 批量分析和重写只处理勾选的适用题目，切换分类或筛选条件时清空勾选。已批准的共享方案可查看并要求助手核对草稿、补全缺项；是否已经写入以工程草稿为准。
