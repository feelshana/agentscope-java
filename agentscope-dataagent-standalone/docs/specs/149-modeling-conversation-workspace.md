# 149 · 对话建模与模型工作台

状态：用户已确认设计稿并授权实施，待产品验收。

## 页面流程

- 管理者从列表进入建模时默认进入对话，也可直接查看模型。保留资产、业务规则与字段定位链接，以及只有 QUERY 权限时的线上只读入口。
- 新数据进入对话式准备页。先呈现表和字段待确认摘要，按需打开字段编辑器。确认后在会话中展示查询范围、可选文档和开始建模操作。按钮和明确的开始指令走同一个准备检查。
- 首建顶栏显示「语义建模 / 知识库名称」、发布状态和「回到知识库」。字段摘要显示各表的纳入数和确实需要判断的字段。点击表行进入该表，点击待确认字段提示则打开对应表的筛选视图。底部「查看建模字段」按默认顺序打开现有弹窗。
- 所有未确认表都已全选且没有待判断字段时，可用「确认全部字段」直接完成。需要人工核对时在弹窗中逐表处理。已确认表可保存修改。确认完成后，准备清单替换原字段摘要。
- 左上「语义建模」返回建模列表，右上「回到知识库」返回当前库，两条路径都保留准备进度。准备卡上的文档可直接打开现有只读阅读器。带有可填写指令的建模输入框在占位提示后显示小号「Tab 填入」。空输入框聚焦时按 Tab 可填入「查看字段」或「开始自动建模」，发送后执行对应操作。输入框沿用问数对话的边框、工具栏和发送按钮样式。
- 对话与工作台共用一个助手实例、队列、草稿、发布和口径确认流程。工作台顶栏居中放四个模块，库名后显示线上版本。关系图和详情铺满剩余空间。
- 对话结果可检查草稿、定位模型变化或临时对照工作台。待确认在对话中处理，工作台按待处理数量提供入口。工程快照从更多菜单打开。草稿入口按修改出现，发布后对话提供去问数。
- 自动建模沿用首建面包屑。展开建模过程可查看执行明细，结果卡默认显示草稿摘要。输入框上方用浅橘底色和感叹号标出待确认口径，点击「去确认」直达会话里的下一条问题。
- 对话内容在较宽窗口适度放宽，回复、确认卡与输入框共享两侧对齐线。宽屏的 AI 标识放在回复框外，窄屏放在回复框内。输入区域失焦时收为单行，聚焦时恢复多行编辑及强调边框。收起时保留未发送内容和当前阅读位置。
- 口径确认卡的「确定」位于右下角，「稍后」紧邻左侧。当前完成最后一题处理后批量提交已确认的答案，点「稍后」的项目保留待确认。
- 重新进入时，已保存的过程、回复和已确认口径按轮恢复。首次建模的改动明细集中在草稿面板，后续维护保留最近一轮的改动入口。待处理弹窗居中。存在待确认口径时，发布前提示本次生效范围，提供「去处理」和「跳过并发布」。
- 首次建模的对话尾部提供「发布模型」和「查看模型」。校验、索引和预热期间原位显示「模型正在发布」及进度，主按钮保留原文并置灰。问数就绪后显示绿勾及「去问数」。失败原因在原位反馈。重新进入时按草稿、线上版本和问数准备状态显示对应操作。工作台使用相同的状态切换，待确认和草稿检查仍走原流程。
- 已发布模型产生草稿时，对话沿用同一张发布卡，展示改动数、目标版本和「检查并发布」。推荐问题仍可在「问数优化」中管理。
- 已发布知识库进入建模对话时保留历史。输入框左侧「快捷提示」展开历史下方的建议面板，收起输入框时入口只显示图标。建议覆盖模型、问数、公共视图和业务资料，并参考当前草稿模型的名称、字段和关系。点击填入后可编辑再发送，已有输入可选择追加或替换。
- 问数优化及公共视图沿用各自结构化的请求和状态刷新，人工 SQL 核对、资料上传与资产审核继续在现有工作流内完成。

## 验收

- 字段确认、查询范围、文档及自动建模可在同一页面完成，退出后可继续准备。
- 两个视图切换时输入和流式任务保留。完成后工作台呈现已保存结果。SQL 改写后原题刷新。
- 干净草稿、未首发、待确认、发布中和发布完成分别显示正确操作。已有书签和引导仍可用。
- 桌面为单层页头，窄屏页签独立一行。关系图、对话记录和编辑面板均可操作。
