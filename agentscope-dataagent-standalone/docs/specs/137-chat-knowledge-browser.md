# spec137：对话中的只读知识库浏览

## 方案

新建与进行中的问数会话，将已选知识库按钮拆为独立书本查看按钮和名称下拉按钮。查看按钮悬停提示，打开时保持选中；未选库仍为原选择入口。只读浏览不改变本轮选库、输入草稿或已保存会话。

右侧与工具详情共用区域，互斥打开；宽屏并排、窄容器覆盖。概览显示库名、说明、数据集数量与可搜索列表；点击数据集在面板内查看示例数据和字段信息，支持返回、搜索、错误重试及关闭。共用详情页表格组件、样式与现有QUERY权限接口，所有用户（含管理员）在这个面板内均不能编辑、刷新样本、上传、删除或管理成员。

只打开面板才读取该库详情，字段随详情复用；点击单个数据集才请求最多20行预览，不预查所有表，不调用Agent，不额外持久存储。面板关闭/切库取消未完成请求，过期响应不能覆盖新库；切库时面板跟随当前选择，无有效选库则关闭。数据为当前数据集资料与有限样本，问数仍使用已发布语义模型，不将资料浏览解释为发布口径预览。

## 验收

1. 首页及已有会话入口一致；图标与下拉操作独立，无嵌套button，不干扰发送或回答流。
2. 查看/返回/关闭后输入和会话保留；工具查看与知识库面板互斥，Esc关闭并可返回入口。
3. 数据集搜索、字段搜索、样例显示、NULL/0及长表横向滚动正常；空库/空样例/无权限/加载失败可理解和重试。
4. 网络验证不开面板不新增详情请求，开库无样例请求，点数据集仅加载该表，字段切换不重查数据；无新写接口/数据库变更。
5. 验证切库竞态、请求取消、只读无编辑入口、窄屏/iframe尺寸及当前前后端回归；截图与结果记录在测试报告。

不做AI推荐问题、跨库浏览、自动查询全表、修改模型与新的数据权限体系。

## 2026-11-13侧栏布局微调

用户反馈数据集页上方留白过多，要求腾出表格空间。库名和只读标记合为单行；返回按钮并入数据集标题，业务说明默认单行省略并可展开/收起；页签与搜索合并一行。样例与字段表格用剩余高度布局，表格独立滚动、固定表头，不再用视口减固定像素的高度上限。保留原只读和按需请求机制，未增加接口或扩大任务范围。
