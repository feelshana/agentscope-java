# spec 070：例行任务首发占位

状态：已实施并验收，2026-10-19纳入本轮主题提交，尚未部署。

## 背景与目标

用户2026-10-17要求例行任务保留展示，不实现具体功能，后续迭代。原列表和修改无owner校验，不以隐藏前端按钮代替关闭接口。

## 实施范围

ScheduledTasksPage保留原入口/面包屑，显示功能待开放，无创建/查询/编辑/状态/删除交互；SecurityConfig在/api/**通用规则之前deny全部/api/scheduled-tasks及子路径。无新开关，任何profile和角色均不开放。保留原数据/表，不擅自删旧控制器或建设调度器。

## 验收

1. 普通用户和admin直接读写旧接口均403，未登录仍走现有401策略；数据库原记录不变。
2. 页面显示入口和待开放状态，不发任务列表请求，无可提交表单。
3. 其余知识库、问答、建模、登录不变。未来上线须补归属隔离与完整执行能力。

关联ADR0082；上线总览原地更新当前边界；旧验收报告保留历史失败证据。
