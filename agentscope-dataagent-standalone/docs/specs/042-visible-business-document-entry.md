# spec 042：显著业务文档入口与上传反馈
状态：已实现，验证见 docs/validation/2026-10-07-business-document-entry.md。
## 目标与方案
业务文档入口移到建模主区顶部，优先建议先提交文档。展示真实上传进度、成功文件名、失败原因、已保存文档预览；从 GroupDetail.knowledge 恢复已有资料状态，分析任务状态独立显示。更新文档明确替换原内容。顶部强化“查看语义模型”及资产范围说明。复用上传接口与现有模型工作区，不新增实体或配置。
## 验收
1. 进入建模即可看到文档引导，无需滚到输入框；无文档仍可直接对话。
2. 上传时防重复提交，成功显示文件名和已保存内容；失败显示错误，已有内容保留。
3. 刷新恢复已有文档状态；异步分析失败不误报上传失败。
4. 切换知识库不显示前一知识库的上传状态；模型入口明显且跳转正常。
## 验证
前端构建、Maven 打包与已有检查；浏览器核验入口及真实上传、刷新恢复与失败反馈。
