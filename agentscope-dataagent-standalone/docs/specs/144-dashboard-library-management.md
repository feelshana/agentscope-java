# spec144：仪表盘基本信息与列表管理

状态：用户已明确批准上一轮建议，本地实现及功能验证完成，待用户体验；不提交或部署。沿用spec141/ADR0149权限与持久资产设计，无DDL或新权限体系。

## 范围

1. 卡片/列表菜单及工作台可编辑名称与选填描述（80/500字），复用现有原生模态框；新建知识库/名称必填，描述选填（按下方用户体验追加）。服务端RUN、QUERY、创建者或MANAGE检查、清理中拒绝及资产锁内权限复核；基于expectedUpdatedAt冲突拒绝，不静默覆盖。
2. 元数据独立原子保存，不调用模型/CLI、不修改HTML/SQL/校验摘要/发布修订。资料对有权查看者即时生效，页面内部标题仍对话修改并发布。无变化保存不更新时间。
3. Asset/View增加description与createdAt，旧JSON兼容为空/未知，后续校验与发布保留二者；不伪造旧创建时间。新看板创建时间固定，访问/查询不更新时间。
4. 列表按已授权数据执行搜索（名称/描述/知识库）、范围、真实状态及排序；草稿/已发布/未发布修改/清理待重试，普通查看者不获草稿状态。默认最近更新，支持最近创建/名称，未知日期排末尾，稳定ID打破并列。
5. 搜索→范围→状态→排序→视图，沿用知识库令牌；卡片最多两行描述，空值不占大块。默认卡片、列表信息紧凑且操作等价；个人视图偏好按用户隔离，切换保持筛选，窄屏无横溢。筛选空态支持重置。

## 用户体验追加：创建表单

2026-11-17用户要求取代第1项“新建仍仅知识库/名称”：增加选填描述，知识库/名称标必填。以可搜索的知识库选择器替代原生select，限定当前有查询权限且已发布未清理的库，支持键盘与无结果/无可用库。名称标签右侧“使用知识库名称”按钮显式填入并可编辑，不随换库覆盖用户输入；超80字截断提示。沿用UUID资产和允许同名规则，不增加编号/唯一约束；仅对已可见同名给非阻断提示。创建请求原子保存描述，服务端校验80/500字且不创建非法字段的残留工程。新增交互/字段传递/同名独立/取消/窄屏回归，后续结果单独记录。

追加流程已本地实现，验证见[创建表单报告](../test-reports/20261117-dashboard-create-dialog.md)。
