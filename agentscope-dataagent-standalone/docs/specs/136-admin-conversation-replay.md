# spec136：管理员只读对话回看

2026-11-13用户已确认方案并授权实施及本地真实问答验收，个人分支liyufan_dev；不提交、不部署66。

## 目标与方案

管理员历史按轮显示当时知识库、原用户反馈，复用正常会话的正文/表格/图表展示；保留抽屉、搜索和分批加载，增加展开阅读。独立管理接口验证全局管理员、用户和main会话归属；只投影最终正文、知识库快照和视觉资源，不返回原始工具输入输出。图表需来自当前会话保存的render_chart结果且归属该用户；图片限当前会话已持久化附件，旧资源不可用明确提示。仅回看，不重跑Agent/SQL或更改原会话。

## 影响面

- 后端：AdminConversationController及只读展示服务，批量读取反馈，不增加列表请求。
- 前端：共用知识库标签、Markdown/ECharts展示；管理员只读图片授权路径及展开阅读。
- 数据：复用消息、知识库快照、图表、附件和反馈存储，无DDL。
- 文档：ADR0148取代0141仅正文限制，ARCHITECTURE第7章及验收记录更新。

## 验收

1. 同会话切换知识库，历史按轮展示原快照；缺失为未记录，零库为普通聊天。
2. 图表及Python持久图片可回看、图片可放大；不存在资源明确提示；仅加载历史不触发执行。
3. 详情显示原用户赞/踩且不可修改；读取反馈失败不阻断正文。
4. 非管理员拒绝跨用户回看；伪造用户/会话/图表位置/附件会话被拒，普通接口仍按所有者限制。
5. 分批加载不漏轮，展开/收起不丢位置，搜索限已加载内容；原用户会话状态不变。
6. 本地实际问答后通过管理员历史检查知识库、图表、图片和反馈并截图；条件与未验证内容照实记录。

不做列表反馈汇总、反馈筛选、管理员代点赞/继续执行/删除、任意工作区文件访问或全量历史扫描。
