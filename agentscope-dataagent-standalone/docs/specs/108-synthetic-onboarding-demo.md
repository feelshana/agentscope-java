# spec108：新手引导改用虚构订单与客户

> 下文记录初版素材及验收。当前新手引导使用随包的 10,000 条订单和 200 位客户，见 [ADR0134](../adr/0134-bundled-onboarding-sample-files.md)。

## 状态与授权

2026-11-02，用户已确认“虚构中文姓名，并替换本地示例”，且明确选择新手引导的“使用示例文件”入口。本地代码与隔离验证已完成，待用户实际界面体验；不新增建模或问数流程。

## 方案与影响

- 48000条订单、2000名虚构中文姓名客户；固定customer_id关联，允许重名，不变更订单、金额、日期和参考统计。
- 内置文件改为演示订单.xlsx、演示客户.xlsx；恢复脚本从仓库中的通用合成文件复制并校验，不再默认从历史恢复真实资料。现有本地旧文件保留，API不再提供。
- DemoDataService的只读示例使用独立版本库demo_commerce_v1和新系统源ID；不覆盖旧demo_data或旧知识库。沿用现有连接配置和权限边界，旧库URL不冒充新示例。缺密码或库准备失败不影响文件上传。
- 同步引导文案，客户名自然化；不自动创建知识库、确认口径或发布，不把管理员答案装入知识库。
- 涉及DemoDataService/Properties、关联源识别、GuidedTour、文件分发工具、配置默认值和文档；无平台表迁移。架构相关描述同步第11/12章。

## 验收标准

1. enabled=true、两文件就绪时，示例API仅返回两份新文件；旧文件、私有文件及路径逃逸不可读取。enabled=false时保持关闭。
2. 新文件完整解析为48000/2000行，中文姓名允许重复、客户编号唯一，其他字段及汇总不变。
3. 无只读密码时仍可使用示例文件；旧demo_data JDBC配置不得把旧真实源显示成新示例；新源仅可关联新版本库，普通源和跨用户权限不放宽。
4. 新示例数据库独立建两表/索引并导入，重复启动不追加，不自动DROP/TRUNCATE/覆盖已有业务数据；未完整准备不标记就绪。
5. 本地data/demo-samples放新文件及新清单，旧素材备份/保留。用户重启后端并刷新即可从新手引导点击使用。

## 不做

不部署66、不删除旧库/知识库/账号、不改Wren/SQL兼容、不扩大MySQL版本范围；真实模型建模/问答由用户随后本地体验。旧知识库与旧凭据的线上退役另行明确，不能声称本次删除了历史真实资料。
