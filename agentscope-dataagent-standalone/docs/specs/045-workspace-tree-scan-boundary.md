# spec 045：工作区文件树范围与响应隔离

- GET /api/agents/{agentId}/workspace/files 保留认证与 RUN 权限。
- 根与所有子目录使用工作区相对路径，响应仍为相对路径，不包含容器系统目录。
- 深度沿用 6 层，最多 2000 项；超量返回 413，扫描超时返回 504，取消后停止后续递归。
- 阻塞文件读写与目录扫描使用 boundedElastic，不占用 parallel 或 Netty 事件线程。
- 前端文件树与贡献树在切换页面时取消请求；知识库列表取消被替代的旧请求。
- page-read 日志在服务器处理超过 1000ms 时 WARN；短请求使用 DEBUG。只测量请求进入服务器后的处理，不包含浏览器 Stalled 时间。

## 人工复验

1. 重启后端、刷新前端，进入工作区：树只显示工作区文件，不出现 usr、proc 等系统目录。
2. 连续切换工作区、业务术语、例行任务和知识库。离开页面时旧文件树请求应取消，知识库无需等待全盘扫描。
3. 在 Network 查看 Stalled 与 Waiting for server response 的完整时间；若再慢，按 requestId 对照 page-read 日志。没有对应长后端处理时继续排查浏览器连接、代理及其他挂起请求。
4. 字段编辑查看长说明，确认可换行编辑，保存重载后保留。
