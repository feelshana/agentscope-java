# spec142：零售旗舰仪表盘样板间

状态：用户已授权；已完成本地数据、建模、真实生成/修改/发布与浏览器验收，待用户体验。[验收记录](../test-reports/20261116-retail-showroom.md)。

## 目标

制作可复现、有可信经营故事和高品质视觉的旗舰样板，让用户通过真实交互了解产品能力。使用明确标注的合成零售数据，保留数据文件、口径、设计参考、自然语言提示和验收记录。

## 方案

四表：交易明细、门店、商品、月度渠道目标。覆盖2025年4月至2026年9月，支持同比、季度/月度切换、区域与渠道过滤、收入/毛利/订单/达成率、趋势、结构、区域和商品分析、门店排名。净销售与净成本具有一致金额口径；目标按门店/月/渠道独立粒度聚合，不与交易明细直接连接导致重复。

先确定整张视觉概念和设计令牌，再生成数据并使用平台上传/建模/发布、选库→对话生成→预览→对话修改→管理者发布。平台生成代码仍由Agent通过官方GenBI流程写出，所有统计通过Wren，不能拿静态截图充当交互成果。

## 验收

- 清晰标注演示数据，文件可重建，有独立真值核验。
- 视觉具备明确主次、可读数字、节制配色和图表细节，桌面/手机不溢出。
- 时间、区域和渠道筛选真实生效，核心统计和真值一致；无数据和失败有清晰状态。
- 实际记录建库、生成、修改、发布的ID与结果；没有完成的环节明确标注。
- 不修改既有知识库、样板或模型服务配置；不自动提交或部署。
