# 建模专用导航与关系图对象目录

## 使用场景

用户进入某一知识库后，在同一工作区找表、看字段、核对问答和处理发布。左上方的知识库图标返回当前库，旁边显示库名和线上版本。

## 布局与验收

- 桌面使用紧凑的文字导航。关系图和业务规则在「语义建模」分组内常驻，用横线与问数优化、公共视图和资料分开。工程与快照使用单库只读页面。首次准备和只读浏览按现有权限显示可用入口。
- 进入关系图时显示可收放的对象目录。点击目录或画布的模型打开相同的字段详情，可继续查看表属性与关联规则。小屏优先展示当前详情，关闭后可继续从目录选取。
- 切换到业务规则或其他模块时使用该模块自己的内容和操作。编辑中的字段沿用离开确认，兼容现有深链接、并排对照和建模对话。
- 工作区沿用现有数据、权限和发布流程。用前端回归、构建及浏览器验证目录、详情、模块切换和只读访问。
- 顶栏贯穿知识库导航与内容区，库名、模型检查、草稿审阅与建模对话共用一行。模型版本在库名旁切换。模型检查直接打开问题清单，草稿审阅集中显示变更和待办。
- 缩放、适应、自动布局和全屏放在关系图右下角。全屏内提供模型检查、版本和草稿审阅入口。

## 七屏设计评审后的实施范围

- 对象目录和模型检查从头显示完整技术名，可自动换行。画布优先显示已有业务名称，技术名从开头换行预览，悬停可看全名。零关系时独立模型紧凑排列，目录给出关系入口。模型检查按真实问题分组并定位，未关联作为模型状态，发布阻塞由实际校验决定。
- 字段列表支持搜索和分组。点击字段进入详情，说明、其他字段属性和衍生列沿用现有详情编辑器。
- 关系图、模型检查和字段详情参照 S1–S3 的色彩和排版。点阵画布与目录、详情面板分层，选中和编辑用淡紫强调，检查数量和规则引用用浅琥珀区分。技术名使用等宽字体，字段说明支持两行预览。
- 问数核对同屏展示口径、已有依据、SQL 和确认操作。会话中有不同的上一稿时可看行差异，并保留 SQL 当前稿、上一稿和展开结果。草稿保存、线上发布和 SQL 规划检查状态明确区分。
- 业务规则保留官方分类、适用范围和已知来源。视图列表突出用途和真实状态，详情定位核查、验证、发布步骤。资料显示真实文档状态，沿用业务文档和数据表入口。
- 暂缓自动合并推断、通用检查忽略、完整依赖统计和文档同步审批。验收覆盖 1280 宽长表名、检查定位和未保存说明保护，以及有上一稿与无上一稿的问数核对。

## 第 05 章 · 草稿改动与模型详情

- 画布右下角用胶囊显示改动数，展开可定位具体改动。列表可切换本轮和全部草稿范围，单独开关高亮。可撤销的条目进入现有审阅确认，按文件恢复线上版本。同文件的其他条目也会恢复。放弃全部继续沿用审阅确认，范围是整个知识库草稿。
- 模型详情突出已有业务名称，技术名完整显示并可复制。字段、表属性、关联规则使用等宽分段。表属性集中展示说明、主键等已有元数据。YAML 独立入口支持全屏阅读、草稿行差异和校验反馈；格式错误有行号时标注到行。保存沿用现有 Wren 校验。
- 关联规则按条展示真实分类、口径、关联字段与规则所在章节，原文可展开。可能相关的文档段落单独折叠，并可进入资料。问答引用次数、规则业务原始出处和表刷新时间没有可核实数据时省略。

## S2 · 模型检查的处理路径

- 未关联放在「使用建议」，顶栏计数只统计待核对的实际检查项。单表可独立问数；确实需要跨表补充字段时可从指定模型打开已有关系编辑器，显式选择目标表、字段和对应关系。「让助手评估关联」预填针对当前模型的完整请求，要求提供同库关联候选、关联价值、字段和基数的依据及待核实项，证据不足时说明可否保持独立。
- 草稿工作台可把未关联模型标记为独立使用，立即从使用建议和计数移出。该标记按账号和知识库保存在当前浏览器。对象目录显示「独立使用」，可从该模型的表属性重新显示关联建议。标记只影响建议与显示。
- 缺说明可展开选择任一字段并进入说明编辑，缺失的规则引用可打开原规则修正，未归类规则可选择官方分类并移入。保存沿用既有草稿接口，检查项以最新快照重新计算。
- 校验结果使用已有业务资产定位信息，直达对应核查、验证或未完成视图的检查确认。一般诊断可打开工程或将原始报错带到建模对话。已发布版本仅提供查看和说明。

## S4 / 第 06 章 · 业务规则

- 规则全空时提供默认过滤、术语、指定取数表三种句式示例与新建入口。预填的是可编辑句式，示例内容以占位展示。草稿保存后仍统一发布。资料入口沿用现有资料页和建模对话预填。
- 有规则时用单页分组清单，六个官方小节展示数量并可定位。三种常用分类为空时收成一行，其余分类有规则才占清单位置。支持跨组搜索、只看草稿改动和问题、未归类直接移到官方小节。无匹配时可清除筛选。
- 选中规则后右侧展示保存预览、结构化字段、真实文件和小节位置、涉及模型字段及可对照的草稿差异。仅展示规则自身中可核实的文档引用，问答和视图依赖数量暂不展示。保留旧原文规则的编辑、原文阅读、草稿增删改和分类移动；新建结构化规则需符合对应句式。离开或关闭前确认未保存编辑。

## 第 07 章 · S9–S12

- 规则页用 44px 单行索引与细分隔线。结构化条目显示规则名称与摘要，原文条目显示最多 20 字的首句锚点与余下内容。选中行以左侧线条和背景标记，详情头显示分类、文件、行号和状态。
- 结构化规则通过「按字段 / 原文」切换编辑。旧原文可直接编辑，可无损转换的括号术语提供采用句式入口。文件位置和可对应的线上差异默认折叠，同一小节提供相邻规则入口，删除放在更多菜单。
- 「仅看有问题」显示结果与隐藏条数。未归类规则打开详情选择目的地并预览位置，可在过滤结果中批量移动未归类规则。移动沿用单条草稿写入，部分失败时展示进度并刷新成功条目。
- 空态展示三个紧凑的新建入口和六个官方小节的文件骨架，点击入口后才打开编辑。文件骨架说明预期路径，实际写入继续使用现有草稿规则。
- 业务规则桌面页沿用第 07 章的 68px 模块导航、54px 通栏、344px 详情、30px 搜索框和 27px 主按钮。清单与详情共用稿件配色和字体。窄屏保留模块下拉与全宽详情，视图操作放在清单底部。

## S5–S7 · 问数优化、公共视图与资料

- 三个模块与业务规则共用紧凑导航、字体、浅灰底色、紫色主按钮与选中态。工具栏按可用宽度排布，窄屏将目录与内容上下排列。
- 问数优化显示当前问题和核对进度，业务口径在 SQL 前。宽屏在右侧展示已有依据与线上版本，可打开现有规则与版本核对面板。
- 公共视图宽屏用两列卡片呈现类型、用途、技术名和状态，选中后在右侧核查口径、查看问题验证和发布状态。
- 资料按业务文档和数据表切换。业务文档显示真实文件状态，正文沿用阅读、原文与章节定位。数据表显示字段清单和纳入范围，沿用搜索与筛选。

## 一体化知识库工作台 · 整理版 S1–S24

- 知识库卡片在新浏览器标签页打开概览。工作台顶栏显示「知识库 / 库名」，点击「知识库」在当前标签页返回列表。所有库内页面共用工作区、数据、语义模型、协作与管理四组目录。数据集子目录与列表、详情使用同一完整名称，长名称自动换行。
- 数据集列表、三类详情、导入记录及数据源连接信息在同一工作台浏览。上传、关联或使用示例完成空白未发布库的首批数据接入后，进入建模对话确认字段。已有数据的库继续补数据时停留在数据集页。部分失败保留导入结果及可用的建模入口。
- 首次建模对话和关系图根据字段确认、助手运行、待确认口径和当前草稿校验状态提供下一步。可发布草稿在关系图提供「审阅并发布」，打开「变更与待办」审阅单。首次发布成功后显示问数准备状态与问数入口。
- 字段和口径确认后，已写入建模改动的草稿即使缺少当前工程检查记录，也可审阅，用户确认「检查并发布」时执行完整校验。已有失败记录时，下一步直接打开发布检查中的问题。旧发布地址改为打开关系图和审阅单。
- 建模内容挂在同一目录下，模型检查、版本、对话与发布继续使用同一套操作。草稿与发布在工作台中可打开。旧库详情、数据集和建模深链接继续兼容。
- 成员与权限、设置提供独立内容区，沿用 QUERY / MANAGE 与服务端授权。空库仍显示目录及准备路径。概览、各列表和运行状态只显示可从现有接口核实的信息。

## 第四、第五轮工作台修补

- 关系图的建议提示可按知识库收起，目录里的「关联建议」可打开使用建议并恢复画布提示。规则工具条合并为一行，规则原文与结构化字段同步，保存仍写同一份草稿。
- 问数录入、待处理和示例使用两列布局。公共视图和问数优化共用建模对话，核对时详情与对话并列、各自滚动，右上角可关闭对话。公共视图从页顶进入核对，目录暂时收起。问数的核对依据在详情内原位展开，「确认并保存」固定在题目区底部，问答仅通过勾选后批量移除。成员页保留单独授权和批量邀请，角色席位依据现有授权列表。
- 工作台顶栏保留直接问数入口，概览页提供复制链接。草稿变更、发布检查和影响预览都在同一审阅单。工程为只读页，可从审阅单带文件路径和对照状态进入，普通成员沿用已发布浏览接口可见的内容。
- 时间范围从设置页逐表或批量配置，建模准备继续使用自动门禁。问数优化可跳转到设置范围。技术信息保留六条元数据和全部物理字段，字段较多才使用表格内部滚动。

## 知识库顶栏状态与发布引导

- 工作台各页从同一份草稿、待办和发布检查状态显示下一步。正在导入、建模、发布或准备问数时显示进度。优先处理发布阻断，其次审阅草稿或处理待办。无待处理事项时收起草稿入口。问数入口依据线上可用状态与权限显示。
- 草稿入口按对象计数，待办另计。校验失败、视图待核查／待验证和工程文件不完整时提供定位入口。待检查的草稿继续走「检查并发布」，服务端发布时仍执行完整校验。
- 审阅单说明本次可发布的内容和可暂缓事项。页面级操作留在对应页面，模型检查只在相关页面有可查看结果时出现。沿用既有路由、发布合约、版本守卫和新手引导。
