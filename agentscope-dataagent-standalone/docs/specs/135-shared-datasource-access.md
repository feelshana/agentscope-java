# spec135：共享数据源与连接治理

用户已确认方案并授权在liyufan_dev实施；2026-11-13最新授权提交、push并合入develop-2.0，由用户操作66。

## 目标与边界

保留独立连接ID，允许不同用户创建相同连接。创建人/全局管理员可授权、撤销、停用和删除；MANAGE可配置且包含USE，USE仅浏览及向有MANAGE的知识库关联表。凭据不向浏览器返回；按用户最新要求，密码沿用现有存储方式，不做加密转换。

数据源成员撤销只影响直接浏览及新增关联，不撤销已有知识库绑定；已有数据集刷新、建模和问数继续按知识库权限。源停用则阻止新的外部连接、发布及问数（含缓存和排队后二次检查），在途已提交数据库语句与已保存历史不追溯删除。关联锁与成员/配置变更共用连接行锁。有关联时禁止删除、禁止更换目标/数据库账号，允许改名及密码轮换。

## 实现

- ExternalDataSourceAccess/ExternalDataSourceService服务集中身份、授权、依赖和事务；HTTP保留原连接CRUD/枚举URL，增加成员/目录/停用接口。
- 平台库仅增加成员授权及操作审计表、enabled列；不改password列和已有密码，不新增密钥或启动密码迁移。模型服务已有加密配置独立保留。
- 连接变更提交后刷新Wren profile并回收依赖库实例；失败不扩大权限。DatasetService、WrenQueryAccess、发布选源和直连入口共同校验。
- 页面保持现有风格，增加全部/我创建/共享给我、权限/创建人/依赖数量，按权限显示配置/成员/停用；成员支持中文名账号搜索和分页；关联选择器显示创建人及权限，停用源不可选。

## 验收

1. A创建，未授权B不可见且直接API拒绝；授权USE后可枚举并向B可管理的库关联，不能改配置/借用存储密码测试其他目标/授权/删除。
2. MANAGE可改名/轮换密码但不能转授权/删；所有者及全局管理员可治理，固定权限不能被撤销。
3. 取消成员后不能新增关联，已绑定库按KB权限继续用；没有源权限的KB使用者仍能问数，不能浏览源其他表。
4. 停用后枚举/关联/刷新样本/发布/问数被拒绝，缓存与排队后二次检查保持；启用后恢复。
5. 有依赖禁止删或换目标；改名保留关联；密码不出现在HTTP/审计，新旧密码沿用现有持久化格式；编辑配置时不填密码保留旧值。
6. 成员弹窗键盘/窄屏/加载失败/搜索迟到响应正确，真实浏览器及后端授权/持久化/回归验收。

不做自动连接合并、部门继承、审批、表级授权或任意SQL执行。关联ADR0146/0147（密码方案已按用户最新要求简化），更新架构与迁移指引。
