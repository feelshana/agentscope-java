# spec076：显式视图、问数日期门禁与耗时记录

> SQL 时间边界与配置以 [spec083](083-llm-per-table-sql-window.md) 为准；本页保留历史需求，不作为当前验收依据。

## 目标

按 ADR0089（取代0088的过重部分）收敛基础建模；缺少日期的事实查询先澄清；减少 Agent 自发画像并记录每步成本。

## 实施

1. 平台提示要求用户主动提出视图，再说明结构并确认，复用原生文件写确认；不另建视图授权状态或自定义结构协议，历史视图不处理。
2. 接通有限采样日期识别、表角色/日期元数据及发布读取，保留用户确认，不自动重采样历史数据。
3. 在 Wren 工具发现前运行无工具日期门禁，结构化 PASS/ASK_DATE/ASK_DATE_COLUMN/ASK_CLARIFICATION；失败不执行数据查询。读取近期原生消息理解日期补充及明确追问，不改问题、不存独立日期继承状态。确定范围仅注入本轮上下文。
4. 替换运行时正则日期拦截；保留只读/撤权检查与建模画像限制。相同本轮 SQL/参数仅复用成功结果，不重复回执。
5. 中间件记录各阶段开始/结束/耗时/失败/取消和轮次摘要，独立轮转日志。

## 验收

- 普通建模提示不要求视图，用户主动要求后通过现有文件确认创建；租户/库写权限保持原有验证。真实LLM遵循效果另测，不把提示视为确定性防护。
- DATE/TIMESTAMP 与字符串采样日期标记正确；用户确认不被刷新覆盖。
- 缺日期只澄清，不调用 Wren；维度/普通聊天通过；切换知识库与日期语义不继承错误范围；无效模型输出安全澄清。
- 用户要求全历史仍询问有限区间；不得用 MAX 或采样值偷偷确定日期。
- 同轮重复成功 SQL 不执行两次，不重复点赞来源；排队撤权仍生效。
- 每轮模型、工具和门禁都有可关联终态，包括错误/取消。
- mvn test、mvn package -DskipTests、前端构建；真实服务同题复测另行记录。
