# spec 097: 使用与管理权限共用知识库详情

> 状态：用户2026-10-28明确确认纠偏，已实施并完成本地回归和浏览器夹具验收；现场BI仍待验。沿用ADR0116权限边界，不新增角色或ADR。

## 目标与方案
使用用户和管理用户复用DatasetGroupPage、DatasetDetailPage及同一路由。卡片入口、布局、数据集列表、数据预览/字段信息/技术信息交互保持一致；以服务端canManage限制成员、编辑、建模、关联、上传、采样刷新、删除等写操作。

只调整明确的GET详情及预览读面以允许QUERY，不全局放宽原getGroup/get方法。原管理写接口保持MANAGE，读投影不返回连接凭据或未发布业务文档。旧只读地址重定向到统一页面。

## 验收
1. 同一库使用/管理用户打开相同组件，均可点数据集切换预览、字段、技术三个标签。
2. 使用用户不显示管理写按钮，也不能通过直接API写入；无授权者读详情及预览仍被拒绝，预览后复核撤权。
3. 管理用户原有操作不受影响，不因共享详情读取而获得别人的库或连接凭据。
4. 用户授权导入此前BI人员Excel到当前IDEA本地平台库；通过既有幂等服务导入，保留原ID/密码/角色/授权，不导入BI密码。

## 验证与范围
新增后端共享详情/预览/写拒绝测试及浏览器同组件角色对照；前端构建和回归、Java及文档门禁。共享记忆和架构同步。正式BI/生产部署不在本次范围，不自动提交。
