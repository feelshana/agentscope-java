# 072 基于 MDL 的事实模型时间边界

> SQL 时间边界与配置以 [spec083](083-llm-per-table-sql-window.md) 为准；本页保留历史需求，不作为当前验收依据。

## 规则

- 样本日期格式识别阈值为 60%，不保存置信度。
- 识别结果写入列 description：语义类型、格式、需要时间范围。
- 事实模型/含 Cube measure 的模型执行聚合或 DISTINCT 时必须过滤时间列。
- 维度模型不强制时间条件。
- 自定义字段名、中文字段名和 VARCHAR 日期均由 MDL 元数据识别。
- 建模和问数统一在 Wren CLI/MCP 调用前拒绝违规 SQL。

## 验证

覆盖原生日期字段、自定义 VARCHAR 日期字段、维度模型放行、事实模型无时间条件拒绝，以及带 BETWEEN/比较条件放行。
