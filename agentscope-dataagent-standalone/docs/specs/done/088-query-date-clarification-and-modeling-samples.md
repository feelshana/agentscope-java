# spec088：问数日期优先澄清与建模样例约束

## 背景与目标

用户未给分析日期时应先询问，不通过 MIN/MAX 或首尾日期探查替用户决策。建模按已知时间配置生成匹配的样例问答，接受成功执行的空结果。

## 方案概述

DataAgentConfig 的问数最高优先级约束与 WrenQueryContextMiddleware 运行时说明一致；后者每轮提供服务当前时间、日期、时区。建模提示与 WrenProjectContextMiddleware 说明先参考当前配置选样例日期，不改变用户问题或业务周期。FactQueryWindowPolicy 只调整拒绝指导文本，保留拒绝后同轮停止。

## 影响面

- 后端：平台提示词、运行时上下文和中文工具拒绝指导；无接口、配置或数据迁移。
- 前端：无协议或界面变更。
- 文档：ADR0102、ARCHITECTURE_zh、README 索引、AGENTS 和共享记忆。

## 验收标准

1. 受限事实表的业务分析问题缺少日期时先询问，SQL 调用为零；补充相对日期后按历史继续原问题，不探查日期。验收覆盖不同表、时间列及 SUM/AVG 指标，营收、库存变动、温度均只是测试场景，不构成生产业务规则。
2. 请求30天、配置10天时提示限制，不自行缩小、拆分或切换工具绕过；结构或规则解释不强制日期。
3. 建模自拟问题与 SQL 的范围和业务条件一致；固定业务周期不能缩短后冒充完整验证。
4. SQL 实际执行成功但为空时正常结束；被门禁拒绝时停止验证，不向用户索取技术样例日期。
5. 窗口等于上限允许、超限拒绝、联表逐表检查、配置变化使缓存失效；同轮拒绝控制及权限隔离继续有效。

## 测试要求

新增可控时钟测试验证每轮时间刷新和时区一致，补齐等于上限边界；运行现有适配器拒绝和权限回归、mvn spotless:check、mvn test、mvn package -DskipTests、前端 npm run build。真实模型受控测试与加载后的服务验收分别记录，未完成项不得记作通过。

QueryDateBehaviorLiveTest 使用原生 ReAct 与合成元数据，查询仅执行在隔离 SQLite 内存空表。测试夹具适配常用日期表达式，保留真实空表聚合形状：总聚合返回一行 0/NULL，分组查询返回零行。检查每轮收到空行后不再新增 SQL 批次，允许预先同批提交的查询及实际成功前的语法修正；测试夹具不属于平台查询链路，不验证 Wren 方言、日期解释准确率或真实数据库性能。

## 不做的事

不新增日期解析/分类、相对日期算法、历史日期状态、重试额度或矛盾输出自动复核；不改官方 skill、历史视图、SQL 保存确认或用户工程资料。
