# SQL 问答对管理与视图文件读取

## 目标

在语义建模页提供独立的 SQL 问答对列表和编辑入口，覆盖建模工作区与点赞记忆两类官方 Markdown 来源，并修复视图资产查看的 404。

## 行为

- 列表按来源显示问题、SQL、文件名和生效提示。
- 建模来源保存到当前知识库工作区，提示重新发布。
- 点赞来源保存到当前用户/知识库的 liked-examples，并调用官方 memory index。
- 两类来源均可删除；点赞来源删除后同步重建官方 memory index。
- 所有路径只能在对应来源目录内，跨用户或跨知识库返回错误。
- 视图优先读取 `views/<name>/sql.yml`，不存在时读取 `metadata.yml`。

## 验证

后端覆盖 SQL 读查询校验、路径隔离与 Markdown 更新；执行 Maven 测试和前端构建。
