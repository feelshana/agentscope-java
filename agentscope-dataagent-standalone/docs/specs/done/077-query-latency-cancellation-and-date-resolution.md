# Spec 077：问数耗时、取消恢复与月日日期解析

## 目标

为问数链路提供可关联的阶段耗时，保证终止后同一会话可继续提问，并将无年份的月日输入解析为当前年份。

## 行为

- 日志记录请求、容量、日期门禁、Wren 注册/发现、模型、工具和 turn 的开始、结束、耗时与状态。
- 取消传播到当前 Reactor 流；lease 在取消后释放，运行中的不可中断操作按现有 operation 语义延迟释放并可观测。
- 日期门禁只拦截缺少必要信息的请求；`10月6日` 的当前年份补全由问数 Agent 根据提示理解，平台不解析或注入日期范围。
- 完全未提供日期的业务问题不自动套用全年。
- 简单问题提示 Agent 一次召回、按需描述、一次查询、结果足够即结束。

## 验收

覆盖定向日期解析、取消后复问、lease 生命周期、工具重复调用提示和完整构建测试。
