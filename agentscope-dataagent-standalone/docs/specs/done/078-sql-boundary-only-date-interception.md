# spec078：SQL 执行前日期条件拦截

> SQL 时间边界与配置以 [spec083](083-llm-per-table-sql-window.md) 为准；本页保留历史需求，不作为当前验收依据。

## 目标

避免问数 Agent 对包含日期字段的事实或指标模型执行无边界聚合、去重或全表查询，同时不在平台重复实现自然语言日期解析。

## 行为

- 问数 Agent 直接接收用户问题和历史消息，平台不运行独立日期判断模型。
- LLM 负责把“10月6日”“去年”等表达转换为 SQL 日期条件。
- `run_sql`、`dry_run`、`dry_plan` 调用 Wren 前读取已发布 MDL 的日期字段和模型属性。
- 事实或指标查询包含聚合、分组或去重且没有对应日期条件时，调用被拦截，Wren Gateway 不执行。
- 拦截错误使用中文说明性能原因和补充日期条件的要求；平台不改写 SQL、不生成日期范围。
- 维度类查询按既有模型属性放行；VARCHAR 日期字段依据 MDL 类型或描述参与检查。

## 验收

- 简单问数首轮没有额外 `date_gate` 模型调用。
- 带日期条件的 SQL 正常调用 Wren。
- 无日期条件的事实聚合被拦截且 Gateway 调用次数为零。
- “10月6日”不会出现在平台生成的日期范围或系统注入消息中。
- 日志只记录边界拒绝的知识库、工具和原因，不记录完整业务结果。
