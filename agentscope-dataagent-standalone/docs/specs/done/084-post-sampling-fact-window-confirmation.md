# spec084：采样后事实表时间范围确认

## 目标

恢复采样完成到自动建模之间的配置步骤。仅事实表进入时间范围弹窗，维度表即使有创建/更新时间字段也不弹；配置仍独立保存在数据库，不写入或读取 MDL。

## 流程

关联/采样完成后进入建模工作台，先加载待配置事实表；仅有新事实表或未选择有效时间字段的配置才自动弹窗。用户保存所有待配置表后再挂载和启动自动建模。没有待配置事实表直接自动建模。关闭弹窗或加载/保存失败时保持暂停，可重开重试；刷新不绕过检查。

已配置表不重复弹窗，后续新增事实表只要求补新增表。知识库页面保留独立编辑入口，修改配置不需要重新建模或发布。模型使用数据库配置的共用 SQL 时间门禁。

## 表角色与接口

默认复用SchemaGenerationService现有模型调用返回FACT/DIMENSION/UNKNOWN，保存到数据库采样摘要tableRole/tableRoleConfirmed，不增加模型调用，不读取MDL。旧记录/无法判断时显示行内角色确认，UNKNOWN不当FACT；维度表过滤，确认维度时清除旧窗口配置。PUT fact-query-windows/table-role受MANAGE与数据集组锁保护。

建模前加载配置，策略通过WrenProjectContextMiddleware提供给建模Agent，但不生成默认起止日期；保存成功且无待确认表时才挂载建模面板。仅采样成功导航携带一次性start=1自动启动，消费后移除，普通访问不重复自动启动。

## 验收

有时间列的维度表不弹；新事实表弹窗；配置成功才启动建模；无事实表直接启动；失败/取消/刷新保持保护；旧配置不重复确认；跨知识库不串状态；配置保存不依赖MDL。
