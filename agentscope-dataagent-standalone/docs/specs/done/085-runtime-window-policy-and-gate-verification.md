# spec085：动态时间策略隔离与工具门禁验收

## 需求

用户确认：具体窗口天数不写进MDL，只保留明确日期与小窗口查询的通用建议；建模Agent可自行选择样例日期，不要求用户确认。修正样例名称/已确认业务口径与SQL过滤不一致，并验证工具门禁实际执行。

## 实施

- 模型/列描述与业务规则不固化平台窗口数值；已知历史描述中的平台窗口不作为执行策略，实际配置从数据库读取。保留真正的业务时间口径，不批量重写历史或已发布MDL。
- 建模与问数上下文均提供当前授权知识库的数据库策略，并明确这是运行提示、不得复制成MDL规则；修改窗口指向知识库配置页。建模可以自行选择有限样例日期，仍通过门禁，不把验证样例冒充用户问题。
- 提示要求保存/复用示例时核对已确认的有效订单、软删、退款及内部账号等过滤；不自动增加未确认业务规则，不建设SQL业务解析器。
- 独立sql-window-gate.log记录trace/session/group、调用入口、SQL指纹、配置快照、逐表decision、耗时及ALLOW/DENY/SKIP/CACHE等状态，不记录完整SQL或业务行。Agent预判不得冒充工具门禁结果。
- 通过真实配置LLM+实际CLI/MCP适配器+模拟数据库执行端验证缺日期、超窗、多表漏条件、别名/中文名/独立窗口/未登记/不限制。只使用合成SQL和测试配置，不连接或改动生产数据，不依赖主Agent主动生成非法SQL。

## 验收

已有授权、只读、排队撤权和同轮拒绝停止保持；真实LLM检查与模拟模型单元测试区分记录。每个拒绝用例断言CLI/MCP执行端未收到查询。检查允许路径、拒绝路径、缓存/跳过和动态配置更新；全量测试、Spotless及前端构建/打包通过。
