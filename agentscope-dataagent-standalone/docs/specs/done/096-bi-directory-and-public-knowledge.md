# spec 096: BI账号接入、人员目录与公共知识库

> 状态：已实施并通过本地验收（2026-10-28）；真实BI/公司环境待现场验收。关联ADR0116。

## 背景与目标
生产应用位于10.194.2.66，浏览器同源路径计划/dify/dataagent/。BI固定链接打开宿主及iframe，应用自行读取Local Storage账号。补充人员资料、只读详情、筛选批量授权和管理员公共库配置。

## 方案概述
- 新账号入口独立开关，username优先、account兼容，不使用中文userName作身份；客户端用户名由用户明确接受为信任前提，不声称可信SSO；平台角色只取数据库。JWT继续用于后续请求。
- UserEntity补姓名、公司、部门；导入按账号幂等更新资料，保留平台ID/角色/授权，不导入BI密码。未导入人员可首登创建。
- QUERY只读投影、有限预览与已发布模型；MANAGE写接口保持。公司/部门筛选、选中人员批量授权为当次快照。
- 公共库由管理员集中配置，所有已登录用户获得QUERY，显式MANAGE保留；统一列表/工具/排队撤权判断，不开放私人历史。
- 同步前端、SQL、架构、配置表、模拟入口及发布指引；包由用户自行构建。

## 验收标准
1. 开关关闭拒绝用户名入口；开启后首登普通用户、已存在管理员沿原角色；空/非法账号拒绝。
2. 重复导入不变更ID/角色/授权；重名不会合并；筛选结果同时显示姓名账号公司部门。
3. 使用用户可读本库详情/已发布模型，写入及他人未授权库被拒绝，返回不含凭据及草稿。
4. 公共库对未来新用户生效，关闭后无显式权限者不可见/不可查询；排队后再核权限。
5. 普通用户不能配置公共库或模型；批量授权事务失败不部分落地。

## 不做的事
不实现BI会话校验、动态组织授权、数据源协作、新正确率模块；不修改Wren官方技能或查询边界。

## 测试要求
新增身份HTTP、人员导入/搜索、公共ACL/撤权、只读投影/写拒绝测试及前端测试；真实BI/生产网络待环境就绪后验收。
