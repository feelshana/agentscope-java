# 081 — Auto-pilot 与事实表小时间窗口

> SQL 时间边界与配置以 [spec083](083-llm-per-table-sql-window.md) 为准；本页保留历史需求，不作为当前验收依据。

## 需求

- 建模会话启动时默认选择官方 Auto-pilot。
- 知识库保存事实表最大分析窗口，允许 7/14/31/90 天，默认 31 天。
- 事实表聚合、去重或分组 SQL 在 Wren CLI、MCP、Cube 和 memory store 前统一校验窗口。
- 缺少时间条件或超过配置窗口返回中文 422，禁止通过扩大范围绕过。
- 维度表查询不受该窗口限制。

## 验收

31 天内的明确日期范围通过；超过窗口、无日期条件、100 年范围均被拒绝；建模和问数读取同一知识库配置；前端可保存并刷新窗口；官方 skill 文件不被修改。
