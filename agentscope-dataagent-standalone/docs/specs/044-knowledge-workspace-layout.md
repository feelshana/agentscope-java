# spec 044：知识库页面布局与交互

对应 ADR 0053。用户选定第一版视觉、第二版知识库卡片菜单。

## 行为

- 2026-10-10：暂时移除知识图谱和树结构目录入口，旧链接回退到数据集；最新行为见 [spec 057](057-suspend-knowledge-graph-and-tree.md)，覆盖下文此前的四入口描述。

- 知识库卡片/列表显示创建人用户名，GET /api/dataset-groups 及单库响应增加 ownerUsername；服务端从真实 ownerId 对应用户读取，列表批量获取，不逐卡片请求用户。缺失显示“未知用户”；长名称截断并提供完整 title。沿用现有可见范围，不因此新增授权。

- 列表搜索名称/说明，最近创建或名称排序；卡片/列表视图使用同一真实数据。加载、接口失败、无知识库、搜索无结果分别呈现。
- 卡片点击或焦点下 Enter/Space 进入详情；问答操作携带知识库 ID。更多菜单提供查看、编辑、删除，按钮操作不触发卡片导航。
- 菜单使用触发按钮附近的固定定位，靠近窗口底部时向上展示；点击外部、滚动、窗口尺寸变化或 Escape 关闭。上下方向键切换菜单项。
- 知识库详情用顶部数据集、图谱、目录和建模导航。建模维持原全屏路径；旧 `?view=modeling` 继续重定向。
- 上传/关联入口、上传进度、导入任务及重试保留；上传弹窗接受点击或拖拽。已有数据时不常驻巨大上传区；空库提供上传入口。
- 数据集页的预览只展示简短字段名，字段说明和类型移至独立页签；技术信息包含真实来源、库表和版本。预览最多沿用现有 20 行请求，数值不舍入。
- 顶部“编辑数据集描述”独立弹窗，调用 PUT /api/datasets/{id}/description，使用所属用户校验；保存后刷新元信息，失败在弹窗显示，取消不保存。字段页签按钮仅编辑字段说明，类型只读。
- 响应式布局在窄窗口折叠卡片列数、换行工具栏并在表格内部滚动；普通回答表格样式不改变。

- 共用页头高 64px、面包屑字大 14px；知识库、数据集、业务术语和例行任务的分隔线一致。侧栏更多菜单向右展开，仅提供工作区，点击外部自动关闭。

## 后续界面细化

- 字段说明弹窗最大宽度 1120px（不超过视口 94%），说明列占 45%，使用可换行、可调整高度的多行输入。
- 业务术语和例行任务使用知识库工作台的白色底色、面包屑、标题、间距、表格和空状态。保留已有 API，未补齐调度执行链路。
- 例行任务搜索按任务名称与分析问题过滤，不再提供无效搜索框。

## 待人工验收

| 场景 | 预期 |
| --- | --- |
| 知识库搜索、排序、卡片/列表与空状态 | 正确筛选真实内容，名称说明较长时不撑坏卡片 |
| 卡片点击、问答、菜单、键盘操作 | 入口目的地正确；菜单不误触导航，能关闭 |
| 创建、改名、删除 | 沿用真实 API 与校验，删除保留确认 |
| 上传单表、多工作表、覆盖、失败重试 | 原有业务链路可用，进度不因页签切换而丢失 |
| 外部源关联、图谱、目录、建模 | 入口可用，关联进度可见，建模仍进入全屏工作区 |
| 数据预览、NULL、长值、字段信息、技术信息 | 显示真实数据，横向滚动局限表格；未改变数值精度 |
| 数据集描述保存、取消、刷新及其他用户请求 | 描述刷新后保留，取消不保存，其他用户无法修改；字段说明不受影响 |
| 侧栏更多 | 三点图标，右侧只有工作区，外部点击及 Escape 关闭 |
| 字段说明保存 | 重载后仍存在；只读类型不提供无效修改 |
| 宽屏、窄窗口、触屏 | 操作可访问，不被多层侧栏挤占 |

前端 TypeScript 检查与生产构建已通过。尚未开展真实浏览器操作验收；本轮未增加或运行自动化测试。
