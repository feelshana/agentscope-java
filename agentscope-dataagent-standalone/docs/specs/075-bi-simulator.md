# spec 075：模拟 BI 入口与真实免登联调

日期：2026-10-19；状态：本地实现与验收完成；云端部署及真实BI联调待进行。

## 目标

提供独立静态模拟BI工作台：选择测试用户→点击图标打开新页→iframe进入真实DataAgent。复用现有bi-login.mjs、真实prod免登接口、JWT及权限，先本地验证，再交用户部署到云服务器。不删除既有账号、知识库和历史。

## 方案

- 静态首页、iframe宿主页、共享样式与小型浏览器模块放在docs/integration下，不编入DataAgent产品入口。用户名不入URL，入口页记录本标签页的身份；刷新沿用未过期JWT，不续期。切换身份显式重新免登并清理旧iframe。
- 私有模拟配置包含共享密钥、basePath和测试用户列表，由外置配置提供；示例不含有效密钥。前端角色仅为说明，真实管理员仍SQL设置，未知用户仍走现有自动创建。
- 本地Node内置HTTP服务仅监听loopback：静态文件+真实后端流式代理；可读取独立前端构建目录，保持/dataagent/前缀。无认证接口mock、用户信息代理伪造、密码登录回退或额外依赖。
- 云端用Nginx静态目录与同源/dataagent/代理；不需要Node常驻。届时提示用户上传配置和发布包、执行迁移、启动服务。当前不操作云端部署。

## 验收

真实MySQL和prod认证配置：首次用户自动创建、SQL设置管理员、账号切换及隔离、不同标签页、刷新不续期、过期拒绝并重新进入、错误密钥/凭据/重放、生产无密码入口。通过实际浏览器验证图标、新页及iframe进入，补充聊天/知识库/授权实测和桌面/窄屏。保留测试数据及截图，记录未覆盖的云端/实际BI边界。

不重做产品UI，不修改建模和准确性规则，不自动提交或推送。交付说明与ADR0086、上线总账及共享记忆同步。

## 实施补充：实际JAR首次创建MCP客户端

本地prod JAR验收暴露`No default McpJsonMapper implementation found`：MCP JSON适配器SPI已在JAR中，但后台线程继承AppClassLoader，无法发现Spring Boot嵌套依赖。主线程预先初始化会掩盖问题，不能用普通类路径测试替代发布包验证。

`WrenInstanceRegistry#createClient`仅在创建/初始化框架MCP客户端期间临时采用应用ClassLoader，finally恢复调用线程原值；保留原工具、授权、发布模型和连接恢复行为。新增2个无真实进程的发现/恢复测试；实际冷启动JAR中由浏览器发起的Wren查询已返回100。
