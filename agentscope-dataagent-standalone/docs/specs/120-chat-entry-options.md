# spec120：新对话默认选库与联网开关

状态：2026-11-06 用户确认实施。联网边界见 [ADR0140](../adr/0140-per-turn-web-search.md)。

- 主界面点击「新建对话」时，按创建时间倒序，在有查询权限且已发布、可问数的知识库中选第一项。MANAGE、QUERY 和全员授权同等参与。加载期间可手动选库或清空，手动操作优先。没有候选时保留普通聊天。只预选库，输入框留空。
- 「基于此库提问」、历史会话、建模和引导按已有入口指定的范围工作。预选只应用一次，之后可切换或清空。
- 问数输入框提供「联网搜索」，进入页面时默认关闭。在页面内连续发送、新建或切换会话时保持用户选择，手动切换影响之后发送的请求。不选库也能开启。每次请求按发送时的选择单独授权，后端在调用处再次校验。
- 搜索只用于公开信息。涉及内部指标时仍以 SQL 为准。公开信息和内部统计可以组合，回答区分来源。
- 搜索服务未配置时明确提示不可用。用户明确要求联网但本轮未开时，可以用原问题和原查询范围仅本次联网重试，开关保留用户的选择。回答引用本轮真实返回的网页时显示「网页来源」。

验收覆盖：无库、单库及多个不同授权的库，跳过不可问数的库，旧会话及指定库入口，加载期间手动选择，首次发送和连续发送保留开关，手动关闭后请求无联网授权，仅本次联网重试保留开关，失败或未引用的结果不显示网页来源。
