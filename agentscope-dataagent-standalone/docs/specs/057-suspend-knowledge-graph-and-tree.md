# spec 057：知识库详情简化与建模分支集成

日期：2026-10-10。对应 ADR 0068。

## 行为

- 详情页只保留“数据集”和“语义建模”，上传、关联和导入进度保持可用。
- `?view=graph` 和 `?view=tree` 显示数据集，不触发 KG 状态/图谱接口。`?view=modeling` 继续进入完整建模页面。
- 显示远程新增的基础模型发布状态；业务模型入口继续使用当前工作台风格。
- `dataagent.knowledge-graph.enabled=false` 时不注册 GraphRAG 服务与 kg 控制器，旧表关系图接口返回 404，不做图谱计算。
- 保留 Wren 语义关系、文档增强、基础模型发布及语义建模内的模型关系展示。

## 用户试用建议

1. 查看列表创建人及知识库详情，仅看到两个入口。
2. 上传 CSV/Excel、关联数据库表，确认导入进度和基础模型发布提示。
3. 进入新版语义建模，体验问题录入、业务文档、确认/修复及发布。
4. 基于发布模型问答，检查 CSV/图片、历史续问，以及点赞反馈保存/取消。
5. 打开旧 graph/tree 链接，确认数据集回退且没有图谱请求。

自动化测试及真实业务联调未在本次执行，不将编译通过视为建模问答验收。

合并后前端生产构建、后端编译和格式检查通过。远程新增 requirements-wren.txt 指定 `wrenai[memory-onnx]==0.15.0`；本机 PATH 的 `E:\Develop\python\Scripts\wren.exe` 对应包当前为 0.14.0（onnxruntime 1.23.2）。本次未改动外部 Python 环境，试用前应确认应用实际配置的 Wren 环境并对齐依赖；编译不验证 Python CLI 兼容性。
