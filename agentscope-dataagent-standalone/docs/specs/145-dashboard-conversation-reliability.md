## 范围及验收

1. 同一预览FIFO有界队列，最多6并发、单修订120请求；正常8并发全部排队完成。超预算显式失败并计入状态。取消/离开/换修订停止旧排队，调用及队列执行前保留当前凭证检查和服务端原门禁。错误被生成页面catch也记录为查询失败，不误报整板成功。
2. 兼容旧query(sql)，新增可选panelId和dataagent.panel({id,title,element,kind,load,render})；统一加载/空/错/单面板重试与选择通知，独立处理面板异常。宿主按窗口/通道/修订、字段长度白名单收消息，不解析任意网页为原生配置。旧页面只报告查询，不编造面板验收。
3. 对话显示实际阶段、预览自检、错误及选中面板；诊断作为有界不可信数据随当前单库请求发送，源码定位优先局部edit。用户本轮成功产生新修订且预览稳定报错后，最多自动发起一次修复；只读/发布查看/首次打开/停止/过期或权限/明显网络错误不自动调用模型。不新增ReAct循环。
4. 输入区停止复用原AbortController，允许重试取数/带报告修复；对话宽度可拖拽及键盘调整，窄屏保留切换。计划/回复来自真实模型或事件，不虚构百分比/成功面板。
5. 每次用户生成前保存有界草稿检查点（10个内容哈希），复用原权限/资产锁/空闲会话门禁；撤销用expectedRevision防并发覆盖，仅恢复草稿HTML/原校验标记，已发布指针不变。清理中/运行中/撤权/错误快照拒绝；不迁移原生Agent上下文，界面明确撤销页面而非删除会话。
6. 官方verify保留为文件检查；客户端真实运行自检单独呈现，不宣称所有业务口径/筛选均正确。此版不是全原生面板资产，也不承诺局部热更新或后台全浏览器测试服务。
