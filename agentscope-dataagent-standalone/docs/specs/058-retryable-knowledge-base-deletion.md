# spec 058：知识库完整删除与失败重试

日期：2026-10-10。依据 ADR 0069，用户已授权实现。

## 行为

- 保持 `DELETE /api/dataset-groups/{id}`，成功仅在完整清理后返回 204。
- 所有权验证沿用 ownerId。已完成删除的 owner 再次请求返回 204，其他用户无法借用删除凭据。
- 删除请求写持久记录后禁止新导入、关联、建模、发布、字段编辑和 Wren 查询；取消与该库关联的问答订阅，中断并等待同步/异步登记的任务。
- 等待任务停止最多 15 秒；尚未停止时返回 503「删除尚未完成」，后台继续重试，不提前删除目录或物理表。
- 严格关闭该库 Wren 实例。客户端正常关闭失败时可由 SDK 执行强制关闭；最终关闭仍失败则保留实例并重试。
- 汇总已有数据集物理表、新导入资源清单及此前删除任务中的表名，再原子更新删除清单。外部 datasource 来源不进入待删除表集合。
- DROP TABLE IF EXISTS 和目录不存在均可重复执行；目录或物理表失败不能伪报成功。
- 最后事务删除全部库级元数据和旧图谱记录；引用该库的例行任务暂停且清空 knowledgeBaseId。
- 列表新增 `deletionPending`，显示待完成状态、阻止详情/编辑/问数入口并提供「重试删除」。
- 历史消息、下载附件、数据源连接、用户反馈状态和其他库资源保留；共享沙箱仅按原空闲策略回收。

## 持久状态

- `.kb-deletions/<id>.json`：ownerId、groupId、tables、complete、lastError、updatedAt。
- `.kb-resources/<id>.json`：新导入物理表名，DDL 前登记。知识库清理完成后移除。
- 成功凭据保留 complete=true，清空 tables/lastError，阻止旧任务重建。
- 未完成任务由独立后台线程恢复；不依赖浏览器一直打开。
- 后台与重复请求按库串行，不同库使用各自执行登记；不全局停止问答。

## 手工验收步骤（未执行）

1. 创建独立体验库，上传四张电商测试表，补充描述、关系、模型、术语、业务规则，完成建模发布与一次点赞。
2. 生成问答图片/CSV并确认可下载，记录该库 ID、导入表名、模型目录与历史会话。
3. 删除后确认列表消失、导入物理表不存在、库级元数据无残留、模型目录及库级点赞记忆消失。
4. 历史回答和已保存附件仍可读取；外部数据源配置、其他知识库及用户共享沙箱不被整体删除。
5. 独立库关联外部测试表后删除，确认业务库原表与行数不变。
6. 在长时间导入/建模/验证过程中删除，观察该次执行取消；任务未停止时应显示删除待完成，后续不能重新写文件或建表。
7. 使用独立测试数据库/目录模拟 DROP 或文件删除失败，确认返回 503 和待完成状态；恢复条件后自动或手工重试完成。
8. 待清理时重启后端，确认 30 秒后的重试恢复；完成后重复 DELETE 应幂等。
9. 检查与该库绑定的例行任务已暂停且关联解除。跨库会话不会被删除，显式选中被删库的新问题应拒绝执行。

不要用生产知识库模拟失败。这里列出验收场景，不表示已经执行这些验证。
