# spec 079：原型导航与辅助页面改造

## 背景与范围

2026-10-21用户在已完成数据源UI基础上，明确要求业务术语、例行任务、更多、左侧栏及“对话 > 知识库”顶部栏按 `docs/previews/dataagent-design-preview-20261014.html` 和所附截图改造。本页记录已选原型的落地范围，不引入新业务方案。

## 实施

- 左侧栏沿用原型的浅灰紫背景、216px骨架、品牌区、白色新建按钮、紫色选中标记、历史分组及底部账号；继续读取实际历史/身份，保留分页、删除和批量管理。
- 顶部面包屑统一为原型高度、分隔、文字和间距；窄屏以展开导航按钮打开单份侧栏，支持关闭、Escape及键盘焦点。
- 业务术语：知识库选择、搜索、四列表格及页脚提示；新建/编辑轻量弹窗，保留分库API、字段限制、同义词、分页和删除，不改变既有管理范围。
- 更多：新增 `/more` 页面，展示既有工作区入口；工作区原功能保留。
- 例行任务：统一页面与表格外观，但按ADR0082继续占位，不调用任务API，不复制原型的演示任务或可操作的创建/启停。
- 原型顶端演示条、角色预览及假会话/角色不进入产品；不改知识库卡片主体、聊天工具链、建模、认证或同事性能任务。保留spec078工作树；上层shared/.seed-manifest.json既有变动不触碰。

## 验收

1. 桌面与原型对照导航、标题、表格、面包屑、图标、间距与配色；历史和账号使用API/JWT实际值。
2. 术语搜索、添加、编辑、删除和分页可用；切库取消旧读取，旧结果不覆盖新库，保存错误保留草稿且不越库提交。
3. 更多进入工作区；例行任务保持占位且无任务API请求。
4. 390px窄屏正文无整体横向溢出，导航可开关、切页收起，Escape恢复焦点；数据源页及全屏建模边界不回归。
5. 前端构建通过；浏览器验证及原型截图对照记录于专项报告，接口桩与真实后端结果分开。同步架构第11章与shared-memory，无提交或部署。
