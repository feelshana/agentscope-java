# spec143：管理员会话历史按助手分类

状态：用户已批准；本地实现及相关验证完成，待用户体验评审，不提交或部署。

## 背景与目标

管理员历史将三类主会话混合展示，模板导入和自动建模消息也计为提问。保留三类记录及原生上下文，默认问数，支持按助手筛选并使列表、统计、导出一致。

## 方案概述

从服务器会话路由标识识别问数/建模/仪表盘，只有缺路由时才按明确旧agentId回退；未知记录归其他并在全部可见，不按标题猜测。overview/users/export共用类型谓词，缺省query。展示索引标题使用知识库名或看板名，后台有界刷新既有记录，搜索保持数据库统一口径；不更改原始消息/活动时间/运行上下文。同步ARCH第7章。

## 影响面

- 后端：AdminHistoryQueryService/OverviewController、会话分类与标题投影、SessionHistoryService。
- 前端：管理员历史类型分段、标签、动态统计用语、长用户消息折叠、API筛选；沿用现有视觉。
- 数据：无DDL；只更新现有展示索引title，不清理消息或资源。

## 验收标准

1. 默认仅问数，切换建模/仪表盘/全部后分页归零，保留其他筛选；未知类型仅全部可见。
2. 同一筛选作用于会话列表、用户统计、CSV，跨类型用户去重；无效类型400，非管理员403/401，撤销管理员后现有令牌不可访问。
3. 问数用提问数，建模/仪表盘用对话轮次，全部用用户消息数；说明仍按会话最后活动筛选、计入会话全部USER消息。
4. 既有建模/看板会话在后台刷新后显示业务对象名，可搜索和导出；资源丢失仍保留历史并明确标题，不展示平台生成指令作为对象标题。
5. 长源码用户消息默认折叠可展开，详情始终只读，不运行历史SQL或生成HTML。
6. 用户体验后调整：助手类型筛选放在日期筛选右侧，与其他筛选框同排等高；窄屏按空间换行。

## 测试要求与边界

真实HTTP/H2覆盖路由内部UUID、边界匹配/未知路由、统计导出一致及权限撤销；标题投影覆盖未变化/缺失转录、缺失资源及路径安全；前端回归、构建和浏览器桌面/窄屏交互。只改管理历史，不改普通侧栏、三助手运行/知识库授权/保留期限/发布规则；不操作线上。

本地验收见[验证报告](../test-reports/20261117-admin-history-assistant-types.md)。知识库标题优先历史名称快照，非所有者缺快照时不取后来改名；列表、搜索、导出使用同一展示索引。浏览器使用隔离演示数据，真实旧记录需启动本地后端后由后台逐批更新。
