# spec 041: 知识库成员、问答权限与 BI 身份接入

更新：2026-10-10。状态：权限规则已确认；身份协议、多库范围待确认，尚未实现。对应 ADR 0050。

## 权限矩阵

| 操作 | QUERY 使用 | MANAGE 管理 | 全局管理员 |
| --- | --- | --- | --- |
| 卡片、基于库问答 | 已授权库 | 已授权库/本人创建库 | 所有库 |
| 下载本人问答 CSV/图片/报告 | 是 | 是 | 自己的会话附件 |
| 进入详情、预览/下载原始文件 | 否 | 是 | 是 |
| 维护数据、描述、字段、文档、建模和发布 | 否 | 是 | 是 |
| 成员授权、撤销、删除库 | 否 | 是 | 是 |
| 读取他人私有历史/附件 | 否 | 否 | 不因库管理权自动获得 |

MANAGE 包含 QUERY。普通用户没有授权不显示卡片，直接调用详情/工具接口也拒绝。首期不分组织，不做行列级权限，旧库保持私有。

## 用户同步与登录契约

- 全量 BI 用户同步到本地目录，稳定 BI ID 唯一映射 userId，改名保留会话和授权。
- 建议幂等新增/更新/停用，不物理删除历史身份；同步频率及停用生效时效待确认。管理员角色明确映射，不自动导入所有 BI 用户为管理员。
- 无重复登录操作，但后端需要可信身份凭据。建议短期身份交换或可信网关；具体协议待确认。
- 裸用户名和统一密码不作为生产免登录契约。签名凭据校验签名、发行方、受众和有效期；一次性票据限制有效期且拒绝重复兑换；网关验证 BI 会话、清除客户端伪造身份头，后端仅信任约定入口。
- iframe 展示由 BI 前端决定，约定嵌入 Origin、HTTPS、会话传递、过期与登出。浏览器参数不能授予管理员。

## 数据与 API

- knowledge_base_grant(group_id,user_id,role,granted_by,created_at,updated_at)，角色 QUERY/MANAGE，组合唯一，按 userId 建索引；所有者天然 MANAGE。
- GET /api/dataset-groups 建议 page/size/search/sort，默认 20，上限 100，先 ACL 过滤再搜索排序分页，返回 items/total/page/size。现有数组响应与聊天选择器同步迁移，不能静默变更契约。
- 返回当前用户角色及可用操作，不返回连接密钥；QUERY 只问答，无详情跳转；MANAGE 有详情和管理菜单。
- 成员 GET/PUT/DELETE 仅 MANAGE/全局管理员可用，记录操作者、时间和角色变更；授权选人通过分页用户目录。
- 库/数据集详情、源文件、导入、编辑、建模、发布及库级语义配置均检查 MANAGE。问答读取允许 QUERY，生成附件下载检查会话归属。
- Chat groupId 必须后端授权并构造 (ownerId,groupId) 上下文，单个共享库也需跨 owner 解析。首期单库提问为建议待确认，空选库不扩大到平台所有库。
- 新工具查询复核当前权限；撤权阻止续问及新数据读取，已有本人历史和附件保留；计划任务按创建用户权限执行。
- 列表只读元数据，不建立计算实例或逐库探测外部数据库。

## 实施顺序

1. 确认 BI 身份、同步/停用、管理员映射及单库提问范围。
2. 增加成员迁移、统一授权服务、成员接口和审计。
3. 收口库/数据接口，适配共享库上下文和 Wren，保证 UI 与实际查询一致。
4. 迁移分页列表、选择器和授权界面。
5. 联调验收、容量评估后上线。

## 待实施验收

| 场景 | 预期 |
| --- | --- |
| 无授权猜测库 ID | 不列出，拒绝详情、工具和源文件 |
| QUERY 共享库问答 | 查库所有者数据，结果归提问用户 |
| QUERY 直接调用详情/预览/编辑/授权 | 后端拒绝 |
| MANAGE 维护和授权 | 可操作，记录变更 |
| 全局管理员跨创建者管理 | 管理所有库，不自动获得他人历史 |
| 撤权回看/下载旧结果，再续问 | 旧内容可读，新查询拒绝 |
| 伪造用户名、角色、ownerId/groupId | 不能换身份或扩权 |
| 用户改名/停用 | 改名保留身份，停用拒绝新访问，时效待定 |
| 分页搜索 | 结果和总数仅包含有权限库 |

以上为设计要求，尚未执行验收。多库场景待确认后补充。
