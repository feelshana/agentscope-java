# spec121：管理员按用户查看对话历史

状态：已确认，2026-11-06。

## 背景与目标

线上试用后，需要查某个用户何时提问、问了什么、收到什么回复。现有会话管理页主要显示会话元数据和会话树，查看正文需要到平台库查表。新增面向全局管理员的只读页面。

## 页面与筛选

- 入口为「更多 → 管理 → 用户对话历史」。按姓名或登录账号搜索用户，只有一个匹配结果时直接加载历史。有多个结果时，展示姓名、账号和部门供选择。
- 进入页面直接看到全体用户的会话，按最近活动时间倒序分页。列表显示会话标题、用户、助手和时间，点击用户名可筛到该用户，也可切回全体用户。日期（北京时间）和标题筛选支持两种范围。只查询平台已登记的用户会话，排除内部子会话。
- 点击会话后打开只读详情，按时间显示提问与最终回复正文。多轮按原顺序配对，未保存回复时保留问题并提示。长会话按轮分页，工具前的过程文字不当作最终回复。
- 查询数据 CSV、Python 产物和其他附件只显示不可交互的占位提示。正文支持基本 Markdown 排版，禁用附件链接、嵌入图片、图表数据加载及工具原始结果。

## 实现与权限

- 独立的管理端只读接口在服务端检查全局管理员身份。查询按选中用户和会话归属绑定。详情仅返回必要的消息文本和时间，附件引用在服务端处理，管理员浏览该页面不改变用户的已读状态。本功能不新增正文查阅审计。
- 复用平台库的会话登记、索引和消息数据。已存在但尚未同步的会话显示「正文暂不可用」，不通过本入口读服务器文件或触发历史索引补录。
- 无独立数据副本、全文检索、导出、代用户续聊或删除。实现后同步架构第 7.5 节。

## 验收

1. 全局管理员进入页面可直接看到多位用户的会话，同一时间的会话翻页不漏不重。按姓名、账号搜索或点击会话所属用户后只显示对应账号。日期和标题筛选始终作用于当前范围。
2. 打开有工具调用、追问或无回复的历史会话，验证用户问题、时间与最终正文准确，跨分页不会错配。
3. 普通用户直调管理接口被拒绝。提交另一用户的会话标识无法绕过归属校验；管理响应不含下载链接或文件 ID，管理员直接访问其他用户的附件仍被原接口拒绝。
4. 查阅前后会话已读状态一致。用本地样例核对页面和接口，再由授权管理员在 66 验收。
