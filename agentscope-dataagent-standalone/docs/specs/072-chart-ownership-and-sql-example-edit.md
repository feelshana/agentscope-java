# spec 072：图表归属与SQL问答对安全编辑

日期：2026-10-17；用户已确认方案并授权实施及测试。

## 目标与边界

修复ChartController仅凭chartId读取，以及SqlQaExampleService正则替换破坏Markdown/YAML的问题。保持前端接口/问答/官方Wren工具链不变，不处理其余重启、连接恢复和建模业务口径问题，不自动提交。

## 方案

- ChartOptionEntity增加可空owner_id用于兼容旧表。新图从框架RuntimeContext获取请求用户，不接受模型指定身份；缺身份拒绝生成。读取使用已登录用户与chartId同时匹配，无管理员旁路；共享库的图仍属于提问人。旧无主图保留但拒读，不自动回填。提供MySQL迁移SQL，dev ddl-update及H2回归验证。
- SQL样例分离Markdown frontmatter与正文，安全解析YAML，仅修改nl/sql并保留其他字段，序列化后再次解析核对精确值；正文SQL代码块同步，SQL不合并空白。问题/SQL长度与原只读规则保留。
- 临时文件校验后原子替换；沿用库级锁，点赞编辑与官方索引/点赞写入串行。索引失败恢复原文件，使派生索引失效并恢复投影，后续官方索引准备成功前不声称生效。建模样例仅草稿、显式发布后生效。
- 坏文件列表明确提示且不可编辑，不自动猜修；缺失/未知来源/路径越界返回明确错误。

## 验收

1. 原越权请求在相同chartId下变为404；本人200，匿名401，其他用户/admin/共享库owner无旁路；并发生成隔离、缺身份无保存、重启持久归属、legacy-null不可读。
2. 连续编辑、有无tags、folded/literal/quoted SQL、中文及冒号/#/引号/反斜杠/行注释、CRLF和空白保持；不改额外元数据和无关正文，坏文件不覆盖。
3. 建模草稿不改发布快照；点赞索引成功可召回新值、失败恢复源与派生状态，重复编辑/并发写串行；只读/路径/QUERY与MANAGE维持。
4. 比较同机图表读取及小文件编辑耗时，不增加大模型或数据库业务查询；官方索引耗时单列。执行定向及全量测试、前端构建、Maven分发和文档检查。
