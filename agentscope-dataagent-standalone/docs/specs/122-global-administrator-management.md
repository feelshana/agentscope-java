# spec122：在页面维护全局管理员

状态：已确认，2026-11-06。

「更多 → 管理 → 全局管理员」列表只显示当前管理员。点击添加后按姓名或账号搜索已存在的用户，确认后授予权限。列表中可确认移除权限。移除只影响全局管理员角色，账号、其他角色及会话继续保留。

服务端只允许全局管理员执行，并在角色变更事务内复核操作者权限。重复提交结果一致，保护最后一位管理员，旧角色替换和删除账号入口也遵守同一约束。授予后重新登录取得包含管理员角色的凭证，撤权后后续 API 请求不再认可旧凭证上的管理员角色。沿用现有用户表和固定 24 小时凭证期限。

验收覆盖列表只显示管理员、搜索并添加、保留自定义角色、撤销后旧凭证不可调用管理接口、普通用户无法直调及最后一位管理员无法移除。
