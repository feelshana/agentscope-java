# spec 043：对话界面与知识库信息编辑

对应 ADR 0052。实现范围：侧栏、回答排版、过程展示、返回导航、知识库编辑及数据源表单操作布局。

## 行为

- 历史列表只显示问题标题和相对时间，不显示回答摘要；仍使用历史分页接口，不因列表显示创建沙箱。
- 用户入口显示头像与用户名，菜单仅含用户名。品牌及页头使用 `--da-shell-header-height`；侧栏使用 `--da-sidebar-bg`。
- 回答表格 `min-width: 100%`，表头、数据统一居中；少于五列采用固定等宽，多列采用自然宽度及内部横向滚动。表格最大显示高度 480px，代码块最大高度 400px。
- 失败或中断的过程默认展开；停止后允许下一次提问，旧请求的收尾不能清除新请求的繁忙状态。
- `PUT /api/dataset-groups/{id}` 输入 `name` / `description`。名称为 1–100 个中文、字母、数字、短横线或下划线；说明不超过 1000 字符。同一所有者下重名返回 409，非所有者按既有查询行为返回 404。成功后刷新列表，不更换 ID 或移动资产。
- 数据源试连使用 `POST /api/datasources/test-connection`，可带 `sourceId` 复用本人已存密码。失败展示原因，成功后保存按钮可用；取消不保存。保存前试连是前端交互规则，创建/更新 API 仍支持已校验参数直接保存，不把临时试连结果当作后端授权。

## 验收

| 场景 | 预期 |
| --- | --- |
| 两列、三列、多列表格及窄窗口 | 占满回答宽度、全单元格居中；宽表内部滚动，不撑坏页面 |
| 长中文、代码、图片和多个附件 | 正文层次清楚，代码可滚动，图片展示和鉴权下载正常 |
| 历史列表加载更多、切换、批量删除 | 问题标题准确，操作和分页不回退 |
| 用户入口、返回导航、知识库菜单 | 用户入口仅显示名称；返回目的地正确；菜单可正常关闭 |
| 改名、空名称、非法字符、重名、超长说明、他人 ID | 合法改名后资产仍可用；其他情况拒绝 |
| 新建源试连、编辑源密码留空、改参数后保存 | 试连不落库；复用本人密码；改参数后必须重试 |
| 他人 sourceId、试连失败、试连期间修改或取消 | 不复用他人凭证；失败原因可见；旧响应不恢复保存资格 |
