# spec 078：按既有原型改造数据源管理界面

## 背景与目标

用户已选择 `docs/previews/dataagent-design-preview-20261014.html#sources` 作为本次视觉与交互基准，授权改造数据源管理。将现有大弹窗改为知识库下的独立管理页，沿用原型的面包屑、标题、四列表格、状态标签与轻量表单弹窗。

## 方案概述

- 新增 `/configure/datasources`，从知识库列表进入，保留原有全局导航。
- 新建/配置使用独立弹窗；详情先展示连接概况，仍可浏览数据库、表及字段。
- 原型之外的既有加密/采样配置折叠在“更多连接选项”，删除收纳到行末菜单，详情库表浏览按需展开。
- 复用 `api/datasources.ts`，保留 MySQL/PostgreSQL、加密、采样、密码留空保留、测试成功后保存和删除约束。
- 列表检测、错误、加载与空状态显示实际接口结果，不使用原型的模拟连通状态。刷新、切换及关闭时忽略过期响应。
- 只改此界面及其入口，不改后端、权限、Wren 链路或其他页面布局。同步架构第11章与共享任务记录；因替代 ADR0017 的部分弹窗展示方式，用 ADR0087 记录，旧 ADR 正文保留。

## 验收标准

1. 知识库入口进入独立管理页；面包屑返回知识库，刷新/直接打开路由有效。
2. 名称与数据库摘要、连接类型、实际连接状态、详情/配置/检测操作按原型布局；删除能力保留。
3. 新建/编辑必须检测成功才能保存，修改字段使旧检测失效；失败不误报成功，编辑不展示已存密码。
4. 详情概况及库表字段可访问，快速切换不能展示旧响应；弹窗支持键盘、关闭后焦点恢复。
5. 桌面与窄屏无页面横向溢出，表格必要时局部滚动；加载、空数据、接口失败均可理解和重试。

## 验证要求

执行前端 TypeScript/Vite 构建，使用浏览器对照原型并验证主要交互、错误及窄屏。接口桩验证与真实数据库验证分别记录；不操作已有用户连接或数据。
