## 目标与范围

按`docs/design/semantic-modeling-20261113-p1.html`四屏还原字段整理、编辑行状态、外部源准备、上传文件准备。使用现有项目导航/图标/主题变量，设计说明、标注编号与示例数字不进入产品。

- 聚焦态52px头部：返回、库名、整理字段/准备/自动建模三段箭头。字段整理/准备隐藏完整工作台页签、布局选择、右侧助手与发布栏；开始后回到已有建模工作台，本次不实现p2/后续四阶段助手设计。
- 独立表导航与紧凑字段卡；全部/待确认/技术筛选，AI建议/全选/全不选保留，时间锁定与关联键取消确认保留。
- 业务说明常驻可编辑、悬停/聚焦状态；未纳入字段也可修改说明，不将该字段纳入模型。setup失焦通过现有confirm=false保存说明，显式确认选择；adjust仍使用原保存/重新建模事务边界。失败保留输入、阻止前进，避免异步请求覆盖新输入。
- 完成全部表后自动进入准备。字段选择待保存时切表/退出须防丢失；不会静默取消勾选或吞掉失败。
- 准备清单整合字段、符合服务端候选条件的查询时间范围、可选多份业务文档和一个开始按钮。已有时间策略按当前值显示，改动保存即生效；未配置值默认31天，在用户点击开始时先保存再启动。未知角色须明确选择；失败/未完成上传禁止开始。
- 上传文件/维度表/无日期列不出现时间配置空块；业务文档新增/替换/删除沿用现有接口与状态，不在准备时抢跑建模。

## 边界

不更改MANAGE/QUERY授权、Wren-only、发布快照/线上问数、字段引用检查、时间门禁及多文档管理。无新接口、实体、DDL、依赖，不另写ADR。逐步引导在时间步骤保留专属“确认范围，继续”，先持久化默认范围再交给开始步骤，避免遮罩阻断；普通模式仍只有一个开始按钮。原HTML存在“改动即存”与旧保存按钮的差异，以实际成功回执显示状态；不把视觉示例当业务事实。
