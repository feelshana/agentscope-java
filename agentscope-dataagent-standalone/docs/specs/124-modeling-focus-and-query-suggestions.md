# spec124 建模布局、问数联想与规则阅读

状态：已确认，实施后待交互验收

## 建模工作区

- 参考原型，将页头右侧主要操作位替换为「专注对话 / 并排查看 / 专注模型」布局切换。事实表时间范围和知识库入口收进更多菜单，「去问数」保留在发布区附近。
- 从采样流程首次进入建模时，采样成功后默认打开专注对话。只切换布局，沿用既有建模启动条件，避免重复发起建模。直接访问已有模型时沿用原有默认工作台。
- 并排展示模型和对话，窄屏使用单面板切换。三个模式共享对话实例，保留会话、流式输出和未发送输入。「查看建模结果」定位模型，「继续对话」回到输入框。待确认事项和显式发布仍可访问。
- 衍生列表达式使用现有代码字体与浅色代码块，长表达式可滚动查看。
- 模型详情中的普通列、日期列、衍生列及关联字段按现有分组独立展开和收起。分组标题显示字段数量，支持鼠标和键盘操作。搜索或从建模结果定位字段时，自动展开目标分组。

## 问数联想

- 使用所选单库的已发布字段元数据。按显示名、同义词和字段名匹配，候选标注指标或维度以及所属模型；例如输入「曝」，可选择「曝光次数」。衍生列也参与匹配。
- 选择候选只替换光标处匹配的文字，保留句子其他部分，不自动发送。支持鼠标、方向键、Enter、Esc，兼容中文输入法组合态。
- 复用 QUERY 鉴权的数据读取入口。切库清空旧候选并忽略迟到响应；无库、未发布或无权限时不展示候选。

## 业务规则

- 对齐工作台的字号、字重、行高、表单及按钮。按官方规则类别分组；结构化规则展示适用范围、条件、例外和涉及字段，非结构化原文占整行，长字段名可换行。
- 点击规则在详情中查看或编辑，保留新增、移动、删除及保存交互。保存失败保留输入。QUERY 仅看已发布规则。界面排版不改写规则正文和官方小节。

## 验收

- 采样后进入专注对话，反复切换布局不重复建模，流式输出与未发送输入保持，模型结果能定位，待确认与发布入口可用。
- 普通列和其他字段分组可独立折叠，搜索和定位能展开目标分组，草稿和线上只读视图均可使用。
- 已发布库输入「曝」能选择曝光次数；验证中文输入、键盘操作、切库、重名字段和无权限场景。
- 在桌面与窄屏验证长规则、长表达式、规则编辑失败重试和只读状态。运行前端构建与文档一致性检查。
