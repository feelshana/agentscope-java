# ADR 0087：数据源管理使用独立页面与轻量弹窗

状态：Accepted（2026-10-21，当前用户授权本分支按既有原型实施）

## 背景

用户选择 `docs/previews/dataagent-design-preview-20261014.html#sources` 改造数据源管理。原 ADR0017 的大尺寸列表、详情弹窗不再适合本次选定的界面。

## 决定

- 数据源列表使用 `/configure/datasources`，由知识库列表进入，面包屑返回；桌面沿用现有全局导航。
- 新建/配置使用约 640px 的原生模态框，保留现有数据库类型、加密、采样和测试后保存；高级选项按需展开。
- 详情先展示连接概况，按需展开数据库/表/字段浏览。删除进入行末菜单并保留确认、后端拒绝反馈。
- 窄屏仅数据源页收起全局侧栏，使用面包屑返回；表格局部滚动，表单单列。
- 状态来自现有 API，不将原型的演示连通性、Doris 标签或假数据移入产品。

## 影响与边界

本决定替代 ADR0017 中数据源列表和详情的展示方式；其历史正文保留，关联库表的 `AssociateTablesModal` 不在本次范围。后端接口、租户权限、连接策略、Wren 工程、建模及问数流程不变。此决定不采用同事另发 AGENTS.md 中的工具接入或 Cube/View 等规则变更。

验证与限制见 [spec078](../specs/078-data-source-management-ui.md) 和 本轮报告（来源 `boundary-lyf@b67a179a:docs/test-reports/20261021-data-source-management-ui.md`）。代码、构建与隔离浏览器验证已完成；真实数据库回归、提交和部署分别管理，不由本 ADR 宣称完成。
