# ADR 0083：私人图表归属与结构化SQL样例编辑

日期：2026-10-17；状态：已接受（用户确认）。

## 决策

交互图表与私人附件保持同一归属原则：创建者取框架请求身份，读取需本人登录，不因知识库共享或管理员身份开放他人的聊天产物。无身份不持久化；旧无主记录保留而拒读。新增owner_id迁移，不从不确定的聊天引用推断归属。

官方SQL样例继续使用Wren Markdown/YAML源，平台只提供正确编辑和保存能力。采用结构化frontmatter更新、精确SQL字符串与正文同步、保存前往返校验、库级互斥及原子替换。点赞样例写入与索引在现有发布项目锁下完成，索引失败恢复源并使派生状态重新准备；不把文件变更或HTTP200等同索引生效。建模样例仍需显式发布。

## 影响

旧图表不再展示，聊天文字保留；不做历史回填或数据删除。SQL元数据可能规范化排版，但其他字段值和正文保留。已损坏文件明确列出，不自动修复猜测内容。复用现有解析依赖与官方索引，问答协议及大模型调用次数不变。

实施与验证见spec072及专项报告。该决策仅授权这两个P1修复，其余P1继续单列。
