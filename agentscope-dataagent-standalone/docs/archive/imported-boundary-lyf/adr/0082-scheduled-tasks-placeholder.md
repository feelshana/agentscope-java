# ADR 0082：首发例行任务只保留占位入口

日期：2026-10-17
状态：已接受，用户本轮明确指令。

## 决策

例行任务首发只展示入口及“后续版本开放”提示，不读取或修改真实任务，不模拟已经具备调度投递能力。前端页面不调用旧列表/CRUD接口；SecurityConfig在认证API通用规则前拒绝/api/scheduled-tasks及其子路径的所有访问。保留已有表/记录和旧控制器以便后续迭代，不自动删除、执行或投递已有任务。

## 原因与影响

旧ScheduledTaskController列表及修改缺少用户归属控制。只隐藏按钮不能阻止直接HTTP访问，所以后端一并关闭。当前仓库该表仅由CRUD使用，未发现读取该表的后台调度器；后续开放必须重新设计owner、权限、选库、执行器、取消、时区及投递并完成隔离验收。此决策替代此前“入口及功能保留、缺口后续补齐”的安排，不表示已实现owner隔离。

## 验证

已登录普通用户/管理员对GET/POST/PUT/状态/DELETE均被拒绝且原记录不变；页面保留菜单但无列表请求/编辑操作。具体实现与本轮结果见spec070及上线总览。
