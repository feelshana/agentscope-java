## 已发现并修复
1. 新public_query列无数据库默认值使旧原生INSERT失败：实体与SQL均默认false，不改旧测试造假。
2. 新入口开关影响旧prod票据默认行为：新模式替代票据、未启用时保留原行为。
3. Boot4 HTTP序列化器对Jackson2树节点输出形状不符：返回标准集合，新增HTTP断言。
4. spring.codec为旧版名称，用户资料超过默认256KB：查本机Boot4配置元数据后改为spring.http.codecs.max-in-memory-size，保留原意图50MB；以大于256KB真实HTTP请求验证。
5. 子路径页面版本检查原先读取BI根页面：改为appPath；目标前缀纳入测试。双边MCP类加载器保护去重，统计可靠性提示与搜索提示并存。
