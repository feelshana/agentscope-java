# 看板工作台与对话呈现优化

2026-11-17，codex/architecture-phase1。用户明确要求按截图与既有HTML稿直接优化，沿用spec145补充验收；本轮仅前端与文档，无新ADR、接口、数据库、模型提示或权限变化。原spec143/144/145全部未提交工作保留，不提交/推送/部署。

## 结果

- 顶栏桌面62px、窄屏58px；小返回箭头、名称、真实状态，右侧保留主操作，更多菜单收拢编辑信息/权限。只读成员显示看板信息，描述与所属知识库仍可查看；窄屏查看已发布版在同菜单可达。菜单支持方向键、Escape、外点关闭及焦点回归。
- 看板助手使用独立的白色网格/图表SVG、紫色圆角底；移除重复副标题/知识库行/独立进度行，真实进度紧凑放在助手右侧。未改其他助手图标或生成页面主题。
- 输入区去掉textarea内层边框、焦点轮廓和阴影，仅外圆角容器有轻焦点提示；保留发送/停止、选中面板目标与权限提示。对话面板使用绘制隔离，菜单打开后输入边框/按钮仍正常绘制。
- 初始六类方向：业务总览、趋势变化、结构对比、Top排名、异常波动、帮我选方向。短标题加说明，点击仅填入并聚焦，允许修改后手动发送；提示词仅使用可用数据，不编造缺失指标/异常因果。
- 回复区优化角色、Markdown标题、列表、引用、表格/代码与技术说明折叠。实际草稿变化才显示文件/运行检查结果和原撤销，不虚构变更计数或确认交互。向上阅读时不强行跟随新消息，支持回到最新。
