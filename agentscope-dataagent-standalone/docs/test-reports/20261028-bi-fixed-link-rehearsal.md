基线为 `codex/integrate-boundary-lyf-v2@b82bb7f4`。本轮未改业务代码、未生成Maven发布包、未操作公司服务器、未向Git加入真实人员名单。目标是验证：BI仅配置固定链接，应用自己读取Local Storage登录，既有用户复用，未知账号创建普通用户；同时核对上传Excel与导入脚本到66后的可执行方式。

- 既有IDEA服务8080/PID28860保留，未重启或改配置，当前仍为开发密码登录模式、账号入口关闭。本轮不以8080代替BI模式验收。

- 当前前端源码以 `/dify/dataagent/` 构建到忽略的output目录，不覆盖项目静态产物。Node18766模拟同源入口及前缀剥离，代理真实后端API；没有模拟登录API响应。
- 独立Chromium通过Playwright CLI操作，固定入口新开标签页；外壳iframe始终指向 `/dify/dataagent/bi-entry`，外壳没有script、账号参数或消息接收逻辑。模拟门户写存储仅代表BI原有登录行为，不是要求BI新增代码。
