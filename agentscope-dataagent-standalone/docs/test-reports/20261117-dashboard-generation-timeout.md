## 原因分层与证据限制

1. 已确认直接原因：写网页所需path/content未到达工具执行器，页面没有落盘，预览没有内容可展示。
2. 已确认放大因素：同一种错误被持续交回模型，反复完整生成仍未修复参数，主要时间耗在模型调用，而不是写盘或查询。
3. 已确认时限问题：ChatCapacity#execute配置600秒，通过takeUntilOther结束当前响应；截图已出现该统一超时文案，但同一trace的模型/工具事件持续到14分钟。这说明HTTP响应结束没有让此原生执行同时结束，具体取消传播路径需另行修复验证。
4. 底层来源尚未定论：现有业务转录不保留上游原始SSE工具参数/finish_reason。ToolCallsAccumulator#build在累计JSON解析失败时保留已有参数，并把非法raw content归一为{}；因此当前记录不能区分上游空参数、长参数截断/格式错误或流式累加丢失。不能仅凭空input就断言模型没有生成代码，也不能断言一定是解析器丢失。
5. 最大35轮限制后的总结也在本轮出现；36次模型记录包含最终总结，不能把它当作36轮成功生成。
