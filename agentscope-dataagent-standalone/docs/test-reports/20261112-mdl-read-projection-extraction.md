HTTP JSON保持不代表Java二进制类名保持。旧服务的三个入口继续委托，调用方已同步新DTO类型；新组件不是单独的HTTP端点，也没有绕过原入口权限。读取仍按原次序分别读取元数据和文件，不新增一致性锁或宣称获得跨文件原子快照。
