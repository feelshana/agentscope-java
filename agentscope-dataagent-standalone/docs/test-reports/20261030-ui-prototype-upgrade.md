## 代码核对结论

- 以实际入口和守卫为准：普通问数零/单库，模型变更进入草稿且统一发布，业务歧义在对话内处理。
- 字段整理、业务文档多份、逐轮建模条目、试问SQL修正、工程术语、分析参数确认、查询CSV及管理员服务在原型中有对应入口。
- 普通QUERY可以查看详情与有限数据预览，不能改该库；普通用户仍可创建自己的库和数据源，不能把单库只读误画为全账号无创建能力。
- 后端仍有任务接口不等于当前产品开放：`ScheduledTasksPage`明确不调用API并显示后续版本开放，原型同样保持未开放。
- 已移除旧原型多库全选、逐文件授权和Cube/View编辑的过时主线。

## 技术验证与限制

- 内嵌JavaScript通过Node `--check`；浏览器主流程与响应式检查通过。
- 文档一致性：`mvn test -Dtest=DocsConsistencyTest -DfailIfNoTests=false`，5项通过，0失败/错误/跳过。该命令默认绑定前端安装、三前缀测试（各57项通过）与构建钩子；构建附带动态/静态导入及chunk大小警告，非本轮新问题。静态构建产物产生不同文件名，已把本轮新增生成文件保留至Git根忽略output/ui-prototype-20261030/incidental-build，并按起点内容还原三份原来干净的静态文件；最终无生产源码/静态包差异。
- 未运行Java全量测试、真实LLM/Wren/Docker/并发验收；没有必要以后台全套测试代替HTML原型评审。
- 最终记录更新后直接执行`mvn surefire:test -Dtest=DocsConsistencyTest -DfailIfNoTests=false`，5项再次通过；该直接目标没有重跑前端生命周期。`git diff --check`通过；静态包与前后端生产源码差异为空，暂存区为空。
- 文件选择仅记录名称/大小，字段整理和连接/建模/发布均为本地模拟；页面刷新重置内存状态。试问仅内置一道完整示例，新题入口明确提示范围；不伪造任意问题的模型结果。
- 本地静态预览地址只服务本次原型。HTML双击可独立运行，无需服务、登录、CDN或联网；调研文档链接需用编辑器阅读。
