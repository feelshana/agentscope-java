## 实现及浏览器环境

`AppShell.css`/`SessionsSidebar` 实现浅灰紫侧栏、216px 桌面骨架、品牌、新建对话、选中态、历史分组及实际用户。`ShellNavigation` 提供窄屏抽屉，正文 inert、Escape、循环焦点和恢复焦点；全屏建模不显示导航。顶部 `KnowledgeBreadcrumb` 统一高度、路径、分隔与留白。

`SemanticConfigPage` 继续使用可管理知识库列表与原组级术语 API，重做搜索、四列表格、分页、新建/编辑/删除弹窗。`MorePage` 提供工作区入口；`WorkspacePage` 仅调整面包屑。`ScheduledTasksPage` 使用原型页面和表头、明确占位。

IAB 通过 cua_repl 的 DOM/Playwright 定位器交互和截图验证，无 Playwright CLI 降级。使用仅绑定 loopback 的临时 Vite（18772）及内存 API 桩、原型静态服务（18771）；未接触真实用户连接或数据。测试身份、知识库、历史和词条均为虚构；源代码中的生产 API 未被替换。浏览器视口为 1280×800、390×844，另在参考附件原始尺寸 2561×1398 核对知识库导航与顶部栏，无整页横向溢出。

## 本次实测

| 场景 | 结果 |
| --- | --- |
| 术语查询 | 按名称、定义及同义词筛选；搜索“销售额”命中营收 |
| 新建、编辑、删除 | 新增试用术语、修改定义、菜单确认删除后表格实际更新；同义词中英文逗号拆分并去重 |
| 分页 | 25条数据跳到末页；切换20条/页后正确显示前20条及表头 |
| 知识库切换 | 经营分析仅显示经营成本；销售读取延迟1800ms时切库，延迟结果没有覆盖新库 |
| 保存失败 | 显示错误，弹窗与已输入草稿保留，没有假成功 |
| 读取失败与空状态 | 术语失败、知识库失败、无可管理库均有明确状态；失败恢复后点击重试加载成功 |
| 例行任务 | 只展示表头与后续版本占位，无创建/启停操作；内存请求记录未出现 scheduled-tasks 请求 |
| 更多与工作区 | 更多→打开→工作区，显示既有文件浏览和“对话 > 更多 > 工作区”路径 |
| 知识库与数据源 | 左侧知识库进入原页面，路径显示“对话 > 知识库”；数据源入口进入 spec078 独立列表并显示检测状态 |
| 历史与身份 | 实际接口数据按今天/昨天分组；点击历史 URL 使用 conversation-0，而不是 storage-0；批量管理全选4条/取消正常；中文JWT用户名正确显示张三 |
| 移动导航 | 打开216px抽屉，Tab/Shift+Tab留在导航，Escape关闭并回到展开按钮；切页收起，正文从AX树隐藏后恢复 |
| 窄屏页面 | 业务术语/例行任务使用表格内部横向滚动，文档宽390；术语弹窗 clientWidth与scrollWidth均356；更多入口不溢出 |
| 全屏建模边界 | 正确路由 `/configure/modeling/sales` 的导航不可见，展开按钮为0；桩未覆盖MDL API，页面显示预期404，因此不将其记为建模功能通过 |

本轮只回归历史选择及批量选择/取消，未重测历史删除后端契约或实际发起问数。内存 API 桩会在 qa-entry 时重置事件；保留的 final-fixture-events.json 仅覆盖最后阶段，不能当作前面所有 CRUD 的完整调用记录。
