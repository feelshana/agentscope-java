| 再次进入工作台 | Chrome 隔离 API 场景覆盖历史未验草稿、失败后刷新、补检成功、确认发布、进行中检查刷新与完成、另一编辑者占用和释放。两次补检触发零次生成请求。390px 视口无整页横溢，未发现页面脚本异常。 |
