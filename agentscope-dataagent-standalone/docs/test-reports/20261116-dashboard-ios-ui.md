# 仪表盘 iOS 界面正式实现验收

2026-11-16 Asia/Shanghai。用户批准[HTML设计稿](../design/dashboard-ios-preview-20261116.html)后实施，沿用spec141，无新增ADR。本地代码/服务/浏览器验证完成，尚未提交、推送或部署66。

## 实现范围

- 列表、新建弹窗、对话创作、预览、发布确认沿用知识库的 `#f2f2f7` 底色、淡顶部光、白卡、22px圆角、分层柔影、悬停上浮与按钮反馈。默认收起仪表盘侧栏，保留现有侧栏手动展开与导航能力。
- 从大块创建表单改为紧凑引导和新建弹窗；提交需求与知识库后创建真实资产，恢复原生会话，再把需求消费一次发送给原有dashboard-agent。失败保留输入，不自动切模型或重复发送。
- 列表按服务器当前用户`owned`投影区分我创建/共享，查询搜索同时匹配名称和知识库；版本状态根据真实修订/权限计算，不把所有可编辑资产算作自己创建。返回值不增加ownerId。
- 工作台减少重复头部、折叠技术说明与长技术回复，完整原文仍可展开。收起对话、展开/退出预览、Esc、手机对话/预览切换可用；生成/查询/空态/失败状态保留。
- 发布必须经过确认，提交当前修订；忙碌、无HTML、未检查、无修改和无管理权限时不能发布。冲突仍由原服务拒绝，界面显示错误。
- 去掉“实时数据”措辞；仅显示按知识库权限查询，以及本次查询完成的时间，不代表源数据更新时间。

主要文件：`DashboardLibrary`、`DashboardsPage`、`dashboards.css`、`dashboardState`、`dashboardThumbnails`、`DashboardPreview`、`AppShell`、`DashboardService.View`。

## 封面与边界

封面由已经打开的实际页面中的ECharts Canvas本地导出，最多组合前三个可导出的图表。使用ECharts现有`renderToCanvas`接口，不加依赖、不改CSP、不后台批量执行看板、不使用样例图冒充业务数据。

缩略图经过既有精确窗口/随机通道检查，并限制PNG data URL类型和450000字符大小。当前登录内存按资产/修订缓存，最多18项，凭证变化后不可复用；不写浏览器持久存储，不新增截图服务或封面权限端点。捕获仅在成功查询且没有运行错误时接收，凭证在途变化时丢弃。无记录、SVG renderer或无法导出的图表显示明确封面提示；整页刷新后须再次打开才能恢复缓存。该版本不提供跨会话持久缩略图。

生成的HTML、数据、已有发布修订均未修改。Wren-only、ACL、事实窗口、只读SQL、opaque内层预览、外联限制、显式MANAGE发布沿用原实现。

## 与获批设计的视觉核对

`view_image`同轮检查获批列表/创作页截图与最终浏览器截图、手机图。桌面1488×1058与设计图一致尺寸。以下对照用于验收，不把真实生成看板内容强改成静态原型：

1. 背景/紫色/白卡/阴影与知识库及设计稿一致，实际取色确认。
2. 主标题、紧凑引导、筛选搜索、三列封面卡片顺序一致；产品侧栏沿用真实59px尺寸，原型76px不覆盖全局系统。
3. 31px页面标题、21px区块标题、13px控件及12px对话层级与原型一致，保留现有产品图标；开始创作使用产品chevron。
4. 卡片22px、控件12px、两级阴影、悬停上浮和按压反馈按原型参数落地；减少动态效果关闭动画。
5. 对话/预览分栏、单一预览工具栏、短主回复加展开细节、发布状态及确认弹窗与设计一致。
6. 真实卡片标题/归属/数量/时间取服务器，替换原型演示值；首屏产品文案没有增加营销块，去掉原型标识。真实封面为图表组合而非原型示意小图。
7. 看板内容保留原有HTML主题和响应式：零售看板在较窄编辑画布下会自行切换2列指标/单列图表，收起对话或展开可获得完整宽度；不覆盖为原型固定4指标布局。
8. “查看完整回复与生成说明”和查询完成时间为生产语义补充；不会拿固定演示答复或静态数字替换真实Agent与查询结果。

正式界面按获批视觉体系落地，已修正长技术回复挤占对话、缩略图CSP错误等发现。保留以上真实内容、产品组件和数据边界差异。
