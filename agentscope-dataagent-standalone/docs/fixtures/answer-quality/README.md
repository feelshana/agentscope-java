# 回答内容校验

`checks.py` 用原始数据独立计算的期望行校验首个结果表，并用 Decimal 检查明确的加法合计行。它避免把主答案之后出现的正确对照数字算成主答案正确，同时保留前导零，并排除百分比/平均值和仅标签中含“合计”的非合计行。

运行回归：`python -m unittest discover -s src/test/python -v`。

这不是运行时自动纠错或语义裁判。指标定义、过滤范围、分母、单位和因果解释仍须对照来源文档与独立证据人工复核。数值标准来自原始文件，不以 Agent 自己生成的 SQL 作为唯一答案；首轮与修复后的重试结果应分别统计。单一结果表、显示舍入容差及文本标识等约定只适用于明确配置的验收题，不能据此宣称任意报告均已正确。
