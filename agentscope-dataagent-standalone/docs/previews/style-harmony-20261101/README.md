## 建议规格

| 部位 | 建议 |
| --- | --- |
| 配色 | 白色主画布，侧栏#F6F7FA，正文#303442、辅助文字#667085；统一温和紫#6654CE与淡紫#EEEBFA。保留品牌SVG自身渐变，按钮使用纯色。 |
| 操作层级 | 页面唯一主要动作使用紫色填充；新建对话、上传、关联和设置为白底描边；卡片提问为淡紫轻按钮；移除黑色填充。 |
| 侧栏 | 建议224px宽、40px导航行、14px导航文字；Logo保留、无副标题。保留历史管理和个人资料，不恢复已移除的会话圆点。业务术语继续在主线业务知识内。 |
| 知识库卡片 | 充分宽度四列，中屏三列/两列，窄屏单列；高度约240–260px作为试排目标。图标28–32px与15–16px名称同行，说明最多两行。状态/权限小标签，数据量、创建人、日期用12px以上纯文字，不加创建人头像或图标。取消灰色统计面板和大号数字。 |
| 卡片动作 | 沿用查看、说明编辑、菜单和原提问行为；图稿的按状态动作仅作候选，不以数据集数量推断可问数，实施时须沿用实际发布状态、权限及阻塞原因。 |
| 详情页 | 建议24px标题、36px控制；创建时间与数据量同排。普通发布提示约44px，导入完成提示约32–36px；进行中、失败和重试信息不因紧凑设计隐藏。 |
| 数据表 | 保留新版五列与来源两行信息，建议表头40px、双行来源数据行64px；行数/字段数继续居中。保留零行与未统计差异、名称查看及显式查看入口。 |
| 低频操作 | 图稿设置菜单承载原编辑信息和事实表时间范围，属待认可的收纳调整；成员与权限保留直达。不能删除这些功能或改变QUERY/MANAGE权限。 |
