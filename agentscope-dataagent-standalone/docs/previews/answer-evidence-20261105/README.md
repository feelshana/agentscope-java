## 体验顺序

1. 默认回答中点击订单总金额，打开“口径与来源”。
2. 切换“结果定位”，高亮SQL返回的ROLLUP汇总单元格。
3. 点击28.82%，查看公式、分子分母和结果依赖链；节点可以点回原始结果。
4. 打开“技术详情”，检查本轮真实SQL、原始JSON及明确未知的字段。
5. 顶部“数据边界”展示已知事实与尚不能支持的判断。
6. 下载本次5行CSV，或预览定位到具体依据的反馈。反馈不提交服务器。

顶部工具栏属于原型评审辅助，不是正式产品新增导航。

## 原型和现有产品的区别

新增逐项引用、依据面板、依赖链及定位反馈仅在HTML中演示；没有修改业务源码、数据库结构、官方技能、生产权限或模型配置，不代表服务端证据契约已经实现。唯一业务动作是用户授权的本地测试问答。

实际图表为双轴柱线图；原型为了把注意力留给依据核对，改为金额横条图，仍使用相同的四个渠道金额。正式产品继续使用现有ECharts体系，本原型的离线图形不是新的图表库选型。

原回答包括详细口径列表；原型把关键条件放在正文短说明，其余归入依据面板。额外展示PC端份额作为派生结论的交互样例。Q1/C1为本原型可读别名，不冒充已有后端证据ID。

本轮实际回执的“返回行逐列合计”对ROLLUP明细和汇总行进行了重复相加；实际回答正确采用了SQL汇总行。原型特意定位到这条真实汇总行，展示不能重复求和的边界。此处仅记录观察，没有顺带修改统计实现。

## 验证与视觉对照

内置浏览器已成功打开本地登录页；读取现有Chrome窗口时因不能可靠识别网址被停止。随后使用Playwright CLI独立命名浏览器操作已知的本地应用并验证原型，没有连接或读取用户Chrome的认证存储。

浏览器实际验证通过：

- 总金额定位到ROLLUP汇总单元格；明细、订单数可分别切换，渠道标签与数值一致。
- 占比公式、双输入依赖、节点返回结果定位；原SQL与JSON展开。
- 标签左右键切换、弹窗Escape关闭、反馈仅预览。
- CSV实际下载；内容与真实5行结果核对。
- 1280、768、390px页面无整体横向溢出，依据底部可达，关闭后返回回答；手机导航遮罩关闭有效。
- file://直接打开独立HTML，交互及占比双单元格引用正常。

通过view_image直接比较实际页面和原型截图，检查品牌及导航、白色背景、紫色色值、字体层级、表格居中、右侧详情模式、间距与窄屏。保留原项目224px侧栏及品牌矢量；原型详情默认520px，属于新增可读空间。修复初版截图滚动位置、明细点击后错误的渠道标签以及手机遮罩点击区域。上屏新增文字限于本次依据方案、评审辅助及真实测试内容，图表形态和口径折叠为上述明确设计调整。
