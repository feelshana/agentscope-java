# 功能图标设计提案｜2026-11-01

最初按用户要求先交付图标设计。后续用户已认可推荐组合并授权实施，默认线性/导航选中实心现已接入生产组件及全流程原型；实施与验收见[专项报告](../../test-reports/20261101-product-icons.md)。以下保留原图稿与设计来源说明。

- `01-icon-families.png/.svg`：8类图标×线性/实心两种风格，含20px示意、16/20/24/32尺寸和选中态。
- `02-in-context.png/.svg`：两套图标在导航、知识库卡片和管理入口中的排版示意。不是实际产品浏览器截图；不修改已批准品牌。
- `index.html`：双击打开两个矢量图稿，可随浏览器缩放检查。
- `outline/`、`solid/`：16个独立SVG，24×24 viewBox、currentColor、透明背景。图形为本轮原创几何路径，未引入外部图标库或业务依赖。
- `build-design.py`：生成矢量文件；PNG通过临时目录中的`@resvg/resvg-js`以1.5倍栅格化，未安装进项目依赖。

建议：默认使用线性，选中时用同语义实心形态，并同步选中背景与文字。图标不是全部选中反馈，始终保留文字标签。

语义：知识库=并列书册；建模=连接模块；术语=文字与定义；任务=日历；数据源=数据库；数据集=表格；新对话=撰写。少量图形使用熟悉的行业约定，避免装饰性星芒、立体阴影或复杂小节点。

设计参考仅取规范原则，不复制品牌：[Microsoft Fluent图标规范](https://fluent2.microsoft.design/iconography)的小尺寸可读性、单色系统图标与复杂度约束；[IBM Carbon图标使用规范](https://v10.carbondesignsystem.com/guidelines/icons/usage/)的尺寸、文字比例与一致性。

验证：两张PNG均已用图像工具目视检查；16个SVG及两张图板的XML解析、PNG尺寸与透明素材格式在交付前核对。重点检查轮廓、线宽、负空间、文字比例、选中对比和卡片中的实际视觉重量。尚未做产品页面替换或浏览器业务验收；本轮不新增spec/ADR。
