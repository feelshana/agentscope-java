# ADR 0080：有界采样与官方 Wren 上下文复用

- 日期：2026-10-15
- 状态：Accepted

## 背景

外部表关联逐列 DISTINCT LIMIT 21 和 COUNT(*) 可能扫描大表。官方 enrich-context Step 4.5 也可能为枚举补全执行 DISTINCT/MIN/MAX；仅把样例写入列 description 无法保证 Agent 读取。

## 决策

关联时每表至多读取 1000 行，在内存提取列样例，不执行 COUNT 或 DISTINCT。外部表总行数对 API/UI 表示未知，文件上传保留准确行数。保留采样开关、30 秒查询超时；采样失败不阻断表结构关联，不回退全表统计。

保存带版本、时间、范围和状态的摘要，使用已有 raw/ 与 knowledge/rules/ 目录，不建立另一套语义体系。原生模型 YAML 保留简短样例，只有业务依据充分时才能写官方 [enum] 标签；不改编译后的 MDL，不改安装版官方 skills。

建模系统上下文直接包含通用探查约束和有长度上限的摘要；问数系统上下文只包含约束，样例通过已发布官方工程规则获取。系统消息可能由框架重新构造，不能使用进程内“已发送”标记把必要上下文永久省略；以每次受限摘要保证新建/恢复会话可用，不承诺每会话仅传输一次。

样本是数据而非指令，不证明完整枚举、全表基数、关系唯一性或最新日期。建模默认不为补齐枚举执行全表统计，必要业务查询验证与问数精确聚合仍通过官方工具进行。行为提示不等于数据库成本硬限制。

## 兼容与验证

新增采样摘要可空列，沿用现有 JPA schema update；生产禁用自动更新时需先添加列。旧记录无摘要显示未采样，不自动访问外部数据库。外部 rowCount API 返回 null（不修改旧存储数值以避免破坏历史），前端统一未知展示。

验收覆盖 SQL/行数边界、失败/禁用、上下文限长、工程发布、权限和前端空值。详见 spec 068。
