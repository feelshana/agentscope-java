# ADR0151：看板任务由服务端持有原生执行订阅

状态：已接受，用户批准任务恢复；本地实现与隔离验证完成，待真实知识库体验。

## 决策

浏览器断连与用户取消分离。看板专用任务API负责原请求幂等、当前任务记录/恢复和停止；服务端订阅既有ChatController.stream，保留Harness、原生会话、权限、队列与绝对超时，不复制ReAct或工具执行。普通问数/建模SSE保持原语义。

选择应用层持有原执行Flux，而不把主看板请求转换成subagent任务：框架TaskRepository用于子Agent任务，直接通过它调用session.execute会旁路现有HTTP调用级工具事件、容量与选库入口。此处只管理订阅及产品状态，不实现新的Agent运行器；后续框架若提供主任务持久执行接口可替换适配。

最近任务和检查点引用原子存于独立看板资产目录，记录长度有界，读写受原资产锁/授权/路径约束。每个看板一个当前活跃任务，运行中禁止删除或恢复；当前用户只能恢复自己的任务消息。服务进程身份变化时非终态如实报告中断，不自动重放请求。单进程执行，不承诺多实例共享调度或重启接续模型连接。

手动任务建立检查点；一轮自动修复必须引用该用户刚完成的原任务和修订，最多一轮，继承检查点。发布仍为管理者显式动作，任务完成不代表浏览器/业务口径通过。

## 后果

刷新/切页不再丢弃正在运行的看板生成，重新进入读取同一任务。原生上下文与展示历史仍复用框架，不新建聊天存储；有限实时回复只是任务视图，完整历史以原生转录为准。删除包含任务记录，异常/停止/重启不可标成功。补充ADR0149/0150，不改变查询、权限、隔离和发布边界。

## 实施补记（2026-11-18）

当前任务之外按用户哈希保留各自最近终态，以免另一管理者随后生成覆盖原用户的恢复结果；不返回他人需求/回复。主记录与各用户终态记录均随资产删除。验证与服务加载限制见[本地报告](../test-reports/20261118-dashboard-generation-recovery.md)。
