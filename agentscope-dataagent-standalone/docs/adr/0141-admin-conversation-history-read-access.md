# ADR0141：管理员通过独立接口查阅用户对话正文

## 状态

已接受，2026-11-06。

## 背景

线上试用排查需要把用户、提问时间、问题和最终回复关联起来。当前普通会话接口按所有者限制访问，附件也由独立的所有者检查保护。新增跨用户查阅只涉及对话正文。

## 决策

由独立的只读管理接口提供用户搜索、历史列表与正文。每次请求在服务端检查全局管理员权限，详情同时核对目标用户与会话归属。接口只输出展示所需的正文和时间，剥除内部工具记录、附件标识及可加载资源引用。普通会话和附件接口继续检查所有者。本功能不新增正文查阅审计。

## 备选方案

给普通会话详情接口增加管理员例外会同时暴露工具原始结果和现有附件引用，还会把管理查阅与日常会话流程耦合。直接从服务器 JSONL 扫描则需要额外处理实例边界、性能和历史文件归属。选择复用数据库里已保存的展示历史。

## 后果

全局管理员能够跨用户查看已同步的正文。没有同步或已删除的历史无法通过该页面查阅。正文可能本身包含业务信息，因此管理接口保留独立授权。
