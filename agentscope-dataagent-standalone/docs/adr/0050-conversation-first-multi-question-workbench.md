# ADR 0050：以对话为主的多问题建模工作台
- 日期：2026-10-07
- 状态：Accepted
- 关联：ADR 0048、0049；spec 041

## 背景
工作台将对话放在右侧，并同时展示上传、快捷操作和资产入口。用户难以理解下一步。用户还需要提前录入多个问题、检查模型/Cube/视图/MDL，且可选问题目前未计入阶段进度。

## 决策
对话成为建模阶段主区域，右侧仅展示同一批问题和阶段下一步。取消重复快捷任务入口，文档上传合并为对话附件入口。模型详情以固定“查看模型”入口进入独立资产工作区，保留现有资产 URL，并提供返回建模入口。
支持对话一次提出多个问题，以及批量录入弹窗；弹窗只预填同一对话，发送后由助手逐项登记，写入仍通过受保护 YAML 工具和原生 HITL，不建立第二写面。已保存清单与未发送输入明确区分。
问题修改、删除和必验设置通过预填对话修改 YAML，仍须用户发送和确认。共用口径合并澄清，每项独立验证与审阅，模型变更使已有结果过期。
所有问题纳入进度和批量验证，只有用户指定必验问题形成发布阻断。可选问题未完成时仍可主动进入发布，并明确提示。
模型详情展示当前工作区草稿及已发布工程快照差异；只展示可取得的 MDL 可视化，不将 YAML 冒充编译 MDL，不因查看触发编译或发布。

## 影响
继续复用 AgentScope 会话、SSE、HITL 和 Wren 查询，无新增模型调用循环、数据库实体或物理查询回退。现有资产编辑和发布安全检查保持有效。阶段进度与发布资格分开计算，补充混合问题测试。
