# ADR 0066：知识库示例存储与召回统一委托官方 Wren CLI

- 状态：Accepted（用户已授权文档和开发）
- 日期：2026-10-10
- 关联：ADR 0062/0063、specs/056；对应决策由本 ADR 取代，旧 ADR 不修改。

## 背景

官方已有 memory store / recall / index / status，项目自研词项检索重复。

## 决策

存储、索引与检索由官方 CLI 负责，移除自研评分、匹配、排序和降级。每个 ownerId / groupId 使用独立工程及明确 --path，路径由鉴权后的服务端选择。保留已发布建模确认示例，经 CLI 同步到当前库；未点赞问数不自动纳入。平台只负责调用封装、超时、参数、结果解析、隔离、同步标记与反馈幂等。按官方顺序输出召回结果，准确报告后端和失败；不直接操作向量库，不实现撤回或历史处理。

## 验证与取舍

通过参数、成功回执、反馈、CLI 和装配测试验证；多租户必须覆盖看不到他人的数据。固定安装版 CLI 实测不得被模拟测试替代。禁用问数工作区上下文同时停止其旧 MEMORY.md/knowledge 注入；本项目动态知识库与官方示例仍保留。

## 不做

历史数据处理、用户自定义规则、点赞撤回、自研检索。
