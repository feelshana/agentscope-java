# ADR0140：问数联网由用户逐轮授权

## 状态

已接受，2026-11-06。实施 [spec120](../specs/120-chat-entry-options.md)。取代 ADR0115 中无需用户授权的自动搜索行为。

## 决策

问数请求显式允许联网时，助手可按需调用已配置的 DeepSeek 搜索。授权只随本次请求进入运行上下文。默认缺省为关闭，模型工具列表和实际工具入口都检查授权，授权不随历史或排队中的其他请求传播。

搜索请求沿用 ADR0115 的数据边界。只发送整理后的公开搜索词和必要参数，搜索词不含内部信息仍由提示词约束。知识库指标来自 SQL。回答的网页来源限本轮工具确实返回且正文引用的链接。

## 原因

业务问数以内部数据为主，公开信息搜索会向外部服务发请求。逐轮选择能让用户看清当前信息来源，也可同时授权库内问数和公开检索。
