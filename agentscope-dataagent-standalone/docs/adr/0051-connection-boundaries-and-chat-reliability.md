# ADR 0051：数据源连接边界、聊天状态与查询成本

日期：2026-10-09
状态：已实现，运行验收边界见 spec 042

## 背景

本轮仅处理整体审查中的第 1、3、4、5 项：外部 JDBC 连接校验、图谱 HTML 注入、聊天停止/断流/繁忙状态、Agent 可见性及工具事件的全量扫描。用户暂缓其他审查事项，知识库共享与 BI 身份继续按 ADR 0050 待办。

## 决策

1. 用户维护的数据源仅允许 MySQL/PostgreSQL。前端改为主机、端口、数据库名及加密选项；后端生成规范连接串。旧 `jdbcUrl` 请求仍可使用，但必须经过同一严格解析，拒绝不匹配协议、多主机、URL 内凭证、路径指令、重复参数和未允许的驱动参数。数据库名暂支持字母、数字、下划线及短横线。
2. 内网部署默认允许用户自行填写外部数据库地址，无须管理员逐个登记。管理员可通过 `dataagent.external-datasource.allowed-endpoints` 配置精确的 `host:port` 以启用目标限制；配置为空表示不限制目标，不支持通配符。MySQL 固定连接/读取超时为 10/30 秒，PostgreSQL 为 10/30 秒（各驱动参数单位不同）。禁用 MySQL 本地文件导入与反序列化参数。元数据 COUNT 及发布前探测增加查询超时。
3. 当前内网自助接入表单默认不加密，同时保留加密与证书校验选项。保存前使用当前表单参数试连，不成功则不能保存；试连不持久化。此默认值只面向当前可信内网，不代表跨网络区域或敏感数据场景可以省略 TLS。
4. 保存与使用均校验连接格式和驱动参数；启用目标限制时同时校验地址。校验覆盖元数据访问、采样/预览、数据源注册及外部连接档案输出。启动时不合规的历史数据源不注册；不合规外部档案不输出，日志记录 ID 和拒绝原因。内置上传数据集库由部署配置管理，不受用户外部源目标限制影响。Wren 修改仅位于连接边界，不改变建模与问答流程。
5. 图谱提示框中的动态文字统一转义，只允许应用自身的固定 HTML 结构。React 文本渲染和 Markdown 主渲染路径维持原有行为。
6. SSE 客户端正确处理分块 UTF-8、LF/CRLF、多行 data 和无空行终止帧。EOF 前没有 done/error 或 JSON 损坏明确报错；退出时释放 reader。停止后清除 busy/pending，标记中断，并防止旧请求的 finally 清理后续请求。后端繁忙异常不能变成空的成功回答。
7. Agent 可见性由带授权条件的数据库查询过滤，批量读取 shares，单 Agent 请求带 ID 条件。保留全局 Agent 优先、自己的同名 Agent 优先、共享分级和已删除所有者过滤。工具事件按后端生成的 requestId 匹配，不再逐事件扫描所有会话；会话查询使用已有 gateway 路由索引并复查所有者和登记是否存在。

## 权衡与边界

- 默认不限制目标地址，适用于当前内网自助添加数据源的使用方式。若日后启用允许列表，它只是应用层目标限制，不提供 DNS 固定或独立网络隔离；管理员还应由部署网络限制出站访问。修改允许列表后需重启服务以重建运行环境，不能声称已撤销现存连接。
- 首次升级无需逐个配置外部源地址。旧 URL 含策略不允许的驱动参数时需通过配置页重存；原始记录不会静默改写或删除。
- 本轮不改令牌撤销、凭证加密、历史增量索引、上传事务补偿、知识库作用域持久化或通用前端重构。
- 浏览器停止会取消 HTTP 订阅，但模型供应商、JDBC 与 Docker 子进程是否立即停止，需要真实环境联调；本轮不承诺全部外部计算即时取消。
- 权限查询不引入缓存，撤销 grant 后下一次查询立即生效；同名共享 Agent 使用创建时间、owner、行号确定顺序。
