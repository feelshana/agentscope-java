# ADR 0084：基于 MDL 字段语义的事实表时间边界

> 日期门禁部分已由 [ADR0097](0097-llm-per-table-sql-window.md) 取代；保留历史背景，其余独立约束按当前实现适用。

## 状态

已接受

## 决策

上传或数据源关联后的样本用于识别日期语义。原生 DATE/DATETIME/TIMESTAMP 直接记录；VARCHAR/CHAR 只有超过 60% 样本按同一格式解析成功时才记录为日期/时间字段，并把格式写入 MDL 列 description 和结构化元数据。无需保存置信度。

表采用事实模型和维度模型的抽象。包含业务指标或 Cube measure 的事实模型只要存在日期/时间字段，其聚合、分组统计和 DISTINCT 查询必须带对应时间过滤；纯维度模型不强制。规则由已发布 MDL/当前草稿字段元数据驱动，不使用固定字段名正则。

## 后果

问数和建模在调用 Wren 前执行相同边界检查，并向 LLM 返回中文修正建议。表级角色只作为筛选依据，最终判断仍落到具体模型和列；复杂 SQL 使用 AST 解析，LIMIT 不能替代时间条件。
