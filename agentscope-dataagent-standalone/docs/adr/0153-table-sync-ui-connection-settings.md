# ADR0153 · 管理员在页面填写表同步连接

状态：已接受，自动建表部分已被 ADR0154 取代。取代 ADR0152 中强制源地址允许列表、文件配置目标账号及加密保存凭证的要求。

管理员从同步页面填写 MySQL 连接。每个任务保存自己的源连接。服务实例复用同一个 `data_agent` 目标实例，目标凭证可在页面更新。首次保存时用目标账号准备幂等同步控制表。目标配置保存在平台库，源凭证随任务保存在控制库。按产品要求新连接凭证直接保存，返回页面的连接信息省略密码。既有环境设置可用于读取旧任务及原有目标配置。

源库执行器继续只执行固定 SELECT，目标连接只用于控制库和任务拥有的镜像。数据库权限及连接可达性由实际账号和网络决定。既有旧 BI 同步继续独立运行。
