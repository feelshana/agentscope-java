# ADR 0087：原生工具展示与查询耗时可观测性

- 状态：Accepted（2026-10-17 用户要求对照日志整体优化）
- 关联：spec075，ADR0081—0086。

## 证据

最新问数日志含三个实际用户请求，分别9、24、9次SQL；第二题达到最大迭代次数。原生工具已经生效，前端却仅对旧wren_call_tool启用Wren解析，带WREN_QUERY_RECEIPT的正常结果被当成损坏JSON，误报截断并建议重新执行。两个Python调用因Docker不可用失败。建模57次调用，5次探测及2次Cube操作被拦截，系统提示仍包含Cube生成和验证要求。拦截有效不等于流程高效。

## 决策

1. 原生及兼容入口共享中文标签、回执/JSON/附件说明解析、错误展示。JSON解析失败不作为截断证据，保留原文，不建议重新查询。官方truncated字段仍如实展示。
2. 保留官方技能原文，清除平台提示中与基础建模禁止Cube/自动探测冲突的执行步骤；允许同一批文件修改完成后集中validate/build。业务定义和已发布视图可复用，简单排名不附加全库诊断，复杂问题按必要证据收敛，不使用硬编码业务SQL或结果缓存。
3. MCP调用记录门锁等待、实例准备、远端执行及返回字符数，CLI记录执行耗时；不记录SQL、行值和凭据。旧日志没有逐调用时长，不能把总体等待断言成数据库慢。
4. 修复调用作用域工具集无选库时Mono空完成导致普通聊天不执行的问题；权限校验及撤权复核保留。

## 限制

时间边界AST、模型角色profile、结果最终采用及点赞准确性仍属此前待完成工作；本次不宣称这些已实现。不恢复物理SQL回退、不修改线上工程，不用扩大历史存储阈值掩盖展示错误。
