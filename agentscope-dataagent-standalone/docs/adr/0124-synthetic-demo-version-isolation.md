# ADR0124：通用示例使用合成订单并与旧示例隔离

## 状态

已接受，2026-11-02。用户确认虚构中文姓名并从新手引导使用新数据。

取代：ADR0122（仅示例素材来源与示例库标识部分；其系统只读源、权限和配置关闭边界保持）。

## 决策

通用展示使用固定种子的合成订单48000行和客户2000行；客户为虚构中文姓名，允许重名，以唯一客户编号关联。合成Excel及校验清单可随Git分发，无真实资料或凭据。

新示例用独立demo_commerce_v1库与builtin-demo-commerce-v1系统源，不将新列结构插入旧demo_data，也不复用旧源身份冒充新素材。默认只读账号改为demo_commerce_reader。已有私有环境若显式指定旧库URL，应明确提示需要配置新库，不自动迁移或删改旧资源。

新手上传入口只提供新文件；默认恢复工具不再提取历史真实素材。旧本地文件可以保留供用户处置，但不在通用API清单中。已有旧知识库、历史Git资料和旧数据库不会因本次切换自动删除，正式退役需单独处理。

## 原因与后果

只替换文件名或复用旧表会导致列错配、已有表非空跳过导入，以及旧资料继续被当作新示例公开。版本隔离避免破坏旧知识库，明确新展示的范围；代价是外部示例路线需要新库和只读账号配置。上传路线仅依赖文件，无需数据库管理员权限或只读密码。多租户、QUERY/MANAGE、只读和官方Wren边界均不改变。
