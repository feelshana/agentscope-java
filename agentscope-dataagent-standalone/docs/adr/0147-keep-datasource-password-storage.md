# ADR0147：共享数据源升级保留原密码存储

- 状态：已接受（用户明确要求简化，2026-11-13）；仅取代ADR0146的密码存储决策。

## 背景

共享数据源尚未上线。用户希望沿用现有密码存储，避免本轮引入密码转换和密钥保管步骤；共享和管理员治理仍需交付。

## 决策

数据源密码继续保存在原password字段，不新增JPA加密转换器、启动迁移或独立密钥，不扩大密码列。已有明文不改动，新建和密码轮换也沿用原格式。模型服务原有加密配置独立保留。

保留API不返回已保存密码、USE不返回连接地址/账号、配置留空密码保留原值、审计不记录凭据等约束。ADR0146其余授权、绑定、启停及管理员边界继续有效。

## 后果

平台升级SQL仅增加enabled和授权/审计表，旧连接默认启用且私有。密码仍为现有明文存储，能读取平台数据库的人仍能读取数据源密码；这是用户本轮明确接受的存储取舍。本轮不提供密文降级转换，不影响模型服务密钥和现有运行配置。
