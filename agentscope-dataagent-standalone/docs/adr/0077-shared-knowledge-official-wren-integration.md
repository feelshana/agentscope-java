# ADR 0077：共享权限与官方 Wren 入口集成

## 状态

已接受，2026-10-15。用户确认以 data-agent-multiAgent-Mdl-lyf（32c6d292）为来源，建模和问数以当前分支为准。

## 决策

知识库采用 QUERY/使用、MANAGE/管理两级授权；创建者和当前全局管理员天然拥有管理权限。管理包含查询；管理者可授权、撤权和删除。未授权用户不能列出或访问知识库，QUERY 不开放原始数据预览、草稿、建模、发布及成员管理。

运行身份始终是请求用户，只有资源归属使用知识库创建者。会话、沙箱、历史、附件和反馈状态仍属请求用户。每轮可选择零个、一个、多个或全部已授权库，范围在会话执行锁内接受；撤权在工具排队结束后、实际调用前复核。共享库中的点赞 SQL 样例属于知识库的召回资料，反馈状态仍私有；保存及重建索引使用知识库锁，避免不同用户并发覆盖。

保留当前官方 Wren skills、CLI/MCP、原生文件工具、HITL、显式发布和原样 MDL。共享权限适配 WrenQueryAccess、WrenProjectAccess、WrenPublishedProject、WrenMcpToolkit；不恢复来源中的旧领域工具注册、SQL 改写或 Cube 路由。外部连接校验修复仅为 dry-run 显式传递连接文件，不修改语义模型。

移植来源已有的操作登记、导入取消与失败传播、删除重试、会话繁忙提示和相关界面修复。来源并未实现全局上传预算、每用户问答准入、有界等待或 Wren 进程总预算，本轮不把这些待办当作已合入能力。

## 影响与验证

新增授权、授权审计和会话选库表，沿用当前 Hibernate 模式管理。新表须纳入部署备份；旧库无授权时保持私有。来源部署配置和打包方式不覆盖当前环境。

权限矩阵、排队撤权、官方工程访问、历史和工具回执兼容均需自动化回归，并执行打包及隔离服务验证。上线服务是否已重载与源码验证状态分开记录。来源文档编号与本分支有冲突，以本 ADR/spec 066 记录集成决定，不覆盖旧 ADR。
