# ADR 0086：禁用语义建模阶段的自动探测查询

## 状态

已接受

## 决策

基础语义建模不执行任何自动数据画像探测。`SELECT DISTINCT`、`COUNT`/`COUNT DISTINCT`、`MIN`、`MAX`、`GROUP BY` 和仅用于统计行数的 `COUNT(*)` 在 `wren_cli query/dry-run/dry-plan` 进入 Wren 前拒绝；把时间窗口扩大到多年也拒绝。实时表和角色未知的表禁止所有探测。角色与日期语义只在已有采样阶段由 LLM 结合样本判定，并写入模型 metadata 的 `properties` 扩展；官方 skill 文件不修改。业务问数仍可通过官方 MCP 执行明确的时间范围统计。

## 后果

建模不再为枚举、基数或极值反复扫描实时库，必须依赖采样和描述。需要验证固定业务口径时，使用独立指标建模模块或用户明确发起的问数流程。
