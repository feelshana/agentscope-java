# ADR0134：新手引导示例文件随应用发布

## 状态

已接受，2026-11-04。取代 ADR0124 的示例上传素材与分发约定，保留只读示例源和旧数据隔离规则。

## 决策

- 新手引导的固定虚构 Excel 放在 `src/main/resources/demo-samples/`，随应用版本打包。IDEA 和生产镜像都通过类路径读取，只提供固定名单中的文件。
- 示例文件默认可用，通过 `DATAAGENT_DEMO_SAMPLES_ENABLED` 单独控制。已有 `DATAAGENT_DEMO_ENABLED` 环境变量可继续作为文件开关的兼容默认值，同时控制可选的只读数据源。
- 示例订单 10,000 条、示例客户 200 位；保留字段、日期范围和主外键关系。点击示例仍走普通上传，由当前知识库拥有导入数据。
- 不再复制到运行目录，不读取旧的 samples-dir。旧镜像所需的生产副本由运维按回退需要留存。可选的只读源仍需显式配置；新空库使用当前模板，已有完整旧批次保留且仍可用，不混入新订单。

## 后果

开发者拉取源码即可使用随包示例。更新素材需随应用重新构建，模板和应用可一同回退。上传产生的知识库数据独立于模板版本。
