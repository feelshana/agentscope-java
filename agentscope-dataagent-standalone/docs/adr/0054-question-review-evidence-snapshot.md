# ADR 0054：验收依据随验证凭据保存

- 日期：2026-10-08
- 状态：Accepted

## 背景

问题 SQL 查询视图时，口径在视图定义中；实时读取当前视图会使旧结果与新 SQL 混搭。已有平台凭据以问题与模型指纹防止过期确认。

## 决策

扩展现有 Receipt，保存外层 SQL 与验证当时的视图定义目录，来源复用 MdlWorkspaceReader，读取与执行处于同一工作区锁。目录明确包含当时所有视图，仅为定义证据，不称为 Wren 物理执行计划。确认/拒绝保留同一快照，旧凭据兼容加载但不伪造快照。页面直接使用确认接口返回状态，并复用服务端工作流引导下一步。问题添加复用统一对话预填弹窗，YAML-first 与原生 HITL 不变。

## 后果

凭据体积随视图目录增加，但可完整审阅跨视图定义且不引入另一套 SQL 依赖解析器。旧凭据需重新验证以补齐定义依据；已有过期及租户边界保持不变。
