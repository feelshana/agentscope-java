# ADR0154 · 表同步 DDL 由 BI 数据开发执行

状态：已接受，2026-11-18。取代 ADR0152、ADR0153 中独立控制库、自动建表和暂存表切换的设计。

- 正式平台仅使用 `data_agent_platform` 和 `data_agent`。管理员在 BI 数据开发手工执行 0152，新建任务时复制页面生成的空目标表 SQL 再手工执行。运行端只检查结构和目标标记。
- 源账号只读。同步目标账号给指定目标表 SELECT、INSERT、DELETE，并给平台同步任务、运行、覆盖三表 SELECT、INSERT、UPDATE。平台连接设置由应用的平台账号维护。使用同一 MySQL 连接提交目标行及对应的进度，失败一起回滚。
- 首次回填写入空目标段。全量刷新和日、月补跑只替换所选范围，异常空结果默认保留既有数据。给单批、单事务和同实例并发设置上限。
