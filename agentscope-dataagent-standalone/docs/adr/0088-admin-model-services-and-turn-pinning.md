# ADR0088：管理员模型服务与整轮快照切换

日期2026-10-21；已接受，用户明确授权第一版手动管理多个服务及无重启切换。

## 决策

1. 更多页提供仅全局管理员可见的大模型服务入口，API独立校验admin，不复用知识库MANAGE。三种预设为OpenAI兼容/DeepSeek/千问（百炼兼容协议），复用原生模型SDK，不建设新的模型网关或ReAct循环。
2. 保存、连接/工具能力测试、显式应用分开；草稿与当前有效快照分离，版本控制防止旧编辑/旧测试覆盖新配置。当前选择与脱敏切换记录持久化，不自动跨到公网。
3. 稳定Model代理配合框架onAgent中间件，在整轮订阅固定不可变模型快照，经Reactor Context传播。切换只影响之后开始的新轮，缓存Agent/历史无需重建；在途模型/凭据版本直到完成都可用。
4. 平台JPA单行加密配置聚合，独立AES-GCM主密钥由环境或持久HOME受保护文件提供；新增0088迁移。数据库和主密钥配套备份，密钥不匹配不得静默改用启动源。
5. 尚未应用管理连接时保留原application的OpenAI/DashScope启动选择；公共模型Key默认值移除，私有外置配置不改。页面只管理模型服务，不替代数据库/JWT/BI配置。

## 取舍与验证

单JVM锁与JPA版本控制符合当前单实例边界，暂不提供跨副本实时传播。代理的结构化输出/上下文大小采取保守声明，工具调用仍使用原生契约。测试只用无业务数据请求目标服务，不自动重试其他服务或执行工具。

按spec080验证权限、加密/恢复、版本竞争、原生HTTP/SSE/tool_calls和整轮快照；公司真实凭据/模型能力及公网允许范围另行联调。扩展既有HTML原型，不接管同事Wren性能工作。
