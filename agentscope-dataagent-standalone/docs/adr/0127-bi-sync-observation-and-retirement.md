# ADR0127：同步观测与停用不进入Web执行面

状态：已接受，2026-11-03用户确认。

补充ADR0125/0126，不改七表投影、Wren及知识库QUERY边界。

管理员Web接口仅通过已有数据集连接读取固定任务状态，并投影白名单字段；不加载密码JSON或运行Shell。长任务继续由既有服务器定时器启动，不为小页面引入新的任务执行/调度系统。源故障也需可查看或暂停，因此观测与pause/resume不得依赖源连接。

暂停标记在目标控制表持久化；作业用独立观察连接读取最新标记，在批次/事务提交前退出并回滚未提交部分。服务器命令可暂停并移除本工具cron，知识库删除或取消全员权限不自动停止作业；保留数据与进度以便恢复，不自动清理资源。

观测不等于保证自动运行：暂停=false不证明cron存在，截止日与最后任务结果分别显示；进程被杀未写结束时依据任务锁识别中断。状态写入仅包含固定阶段码，数据库/凭据异常原文不得展示。页面只对全局管理员开放，普通用户不获得任务元数据访问权。
