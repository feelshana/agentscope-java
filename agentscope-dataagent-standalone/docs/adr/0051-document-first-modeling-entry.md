# ADR 0051：业务文档优先引导与明确上传反馈
- 日期：2026-10-07
- 状态：Accepted
- 关联：spec 042、ADR 0050

## 决策
对话主区顶部固定展示业务文档引导，建议先上传，再提出分析问题；没有文档可直接对话，不增加服务端发布门槛。取消工作台输入框旁重复上传入口。
上传状态基于真实请求显示上传中、成功、失败及本次文件名；文档成功保存与异步口径分析分开展示。刷新后按知识库服务端内容恢复“已有业务文档”，不虚构服务器未保存的文件名。支持查看已保存内容，更新上传明确替换当前文档。
顶部将“查看模型”强化为“查看语义模型”，同时标注模型/Cube/视图/MDL 范围。复用既有上传、分析和资产接口。
