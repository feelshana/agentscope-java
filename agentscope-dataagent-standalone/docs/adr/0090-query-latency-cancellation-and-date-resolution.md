# ADR 0090: 问数耗时观测、取消释放与日期解析

> 耗时与取消观测继续有效；日期解析和执行门禁以 [ADR0097](0097-llm-per-table-sql-window.md) 为准。

- 状态：Accepted
- 日期：2026-10-18
- 关联：ADR 0087、ADR 0089

## 背景

问数首轮包含日期门禁、Wren MCP 注册、工具发现和模型调用，现有日志无法完整关联这些阶段。SSE 终止后，conversation lease 的释放状态也不可见。月日输入（如“10月6日”）被日期门禁错误地要求补充年份。

## 决策

1. 所有问数阶段使用同一 trace/session/request 标识记录耗时和结束状态，不记录完整 SQL 与业务行数据。
2. SSE 取消必须沿 Agent、日期门禁、MCP 和 ChatCapacity lease 传播；lease 释放必须可观测。
3. 日期解析优先处理确定性月日表达；缺少年份时使用服务端当前年份。完全没有日期的业务问题继续按现有门禁规则处理。
4. 工具调用顺序和重复调用约束通过 data-agent 中文提示表达，不修改官方 Wren skill 或 MCP schema。

## 后果

可以区分模型、日期门禁、Wren 冷启动、工具和 SQL 的耗时，并能定位取消后会话未释放问题。默认年份取服务端时区的自然年，答案需展示实际范围。
