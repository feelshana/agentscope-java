# ADR0125：独立正式运行环境与离线BI镜像任务

状态：已接受（2026-11-02用户授权准备；日志取数/事务进度由ADR0126补充并局部取代，正式切换待执行）。

沿用ADR0118镜像构建/运行分离与ADR0116公共库QUERY，不取代Wren-only及MySQL8+准入。

## 决策

正式应用使用新base/project/桥接网络和业务目录，使用已有正式两库；旧环境只在明确切换时停止并保留以便回退。两库从JDBC URL解析，不沿用Docker mysql硬编码。正式模型服务重新配置，不复制旧加密数据/密钥；离线向量缓存与已验收沙箱镜像可复用。

源5.7通过独立只读ETL任务复制精简字段到正式8.0，7张固定业务表供外部数据源关联，另设同步控制表不授予问数账号。小表全量事务替换；两追加日志按半开日期窗口、流式批次写入与逐日提交水位，避免按随机ID当时间或无索引时重复大量分页扫描。目标事务同时提交日志窗口和该表水位，只有7表完成才记录全局成功截止日。

同步只改固定镜像表及控制表，不改平台元数据、ds_表或已发布语义工程。增量数据不是语义版本变更。业务定义与结构变化仍需正常建模/发布；采样/旧回答不是同步状态源。无CDC、无迟到纠正、无历史组织快照，本版按用户确认边界执行。

## 影响

上线前可在独立端口验启动，保持旧库可恢复；DB切换回退必须恢复环境而不是只换镜像。首次同步可能受源时间索引影响，预检提示并由DBA处理，任务不改源DDL。公共库不自动继承BI逐人项目权限，字段公开范围已由用户确认。
