# ADR0089：轻量日期门禁，复用原生历史与确认

> 日期门禁部分已由 [ADR0097](0097-llm-per-table-sql-window.md) 取代；保留历史背景，其余独立约束按当前实现适用。

## 状态

已接受，2026-10-18 用户要求精简后确认执行。取代 ADR0088 中独立视图授权记录、日期继承状态及历史资产处理方案。

## 决策

- 保留官方 enrich-context；基础建模默认只生成基础模型、确认关系和规则。只有用户明确要求视图时，先在对话中说明结构并确认，再复用原生文件写确认。无专用 view_contract、权限令牌或历史视图迁移。
- 日期门禁读取原生近期用户/助手消息、当前授权已发布模型元数据和规则。未明确日期时直接澄清，不改写原问题、不指定默认日期、不调用 Wren。明确追问或用户补充日期通过消息历史理解，不新增问题状态机或持久日期记忆。
- 决策只存本轮 RuntimeContext 并传给本轮模型；拒绝/无效输出不进入工具注册。普通聊天继续原生 Agent 生命周期。该策略不能证明生成 SQL 必然包含日期条件，也不能保证数据库无全表扫描。
- 不建设 SQL AST，退出问数正则日期拦截；只读、显式选库、撤权检查保持。建模实际画像查询仍拒绝；纯 dry-plan 允许结构校验。
- 用现有中间件记录日期门禁、模型、工具和整体耗时；不复制业务数据。真实速度和 LLM 遵循效果需要重载后复测。

## 范围说明

视图意图与范围理解依赖模型遵循提示，实际文件操作仍受原生用户确认和 MANAGE 权限控制，不宣称新增了确定性语义授权。历史视图不主动检查、修改或删除。
