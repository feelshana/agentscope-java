# ADR0146：数据源成员授权与知识库绑定分离

- 状态：已接受；密码存储决策已被ADR0147取代，其余共享与治理决策保持有效（2026-11-13）

## 背景

连接归个人导致重复配置、无法在不分发密码的情况下协作。单纯把前端列表放开不能覆盖关联写入、发布和官方查询的身份边界。

## 决策

连接为独立资源，不按IP去重。USE允许枚举和建立KB绑定，MANAGE附加配置维护；创建者/全局管理员保留成员治理、停用和删除。关联使用操作者身份同时检查源USE与KB MANAGE，资源归属仍为KB owner，不能把操作者替换为owner绕过授权。

绑定是授予知识库的持续供数关系。移除连接成员不撤销绑定，已有刷新/发布/问数按KB权限继续；停用连接在后端阻止新的外部操作与查询，包含缓存/排队后的授权复核。保留历史结果，不承诺中止数据库已接收的在途语句。没有源权限的KB使用者不能因问数反向获得源权限。

关联和治理共用连接行锁，防止关联与撤权/目标修改/删除竞态。存在绑定时拒绝目标或账号切换、拒绝删除；密码轮换不改目标，提交后刷新配置/回收实例。审计不含凭据。

密码通过JPA转换器加密，沿用现有ModelServiceCipher的独立主密钥，但密文带独立外层标记、加密内容带用途标签，不把模型配置密文作为数据源密码接受。旧明文启动事务迁移，密钥错误不回退、不覆盖。数据库和独立密钥及Wren运行文件须配套保管，不能把数据库加密描述为运行文件也无明文。

## 后果

新增平台授权/审计表及列迁移，原来源默认私有且启用。连接管理不自动传播为KB共享，源成员撤销提示明确；需要停止已绑定业务时使用停用，而不是暗中破坏所有KB。单进程实例回收是尽力措施，权限判定不能依赖回收成功。部门/表级权限及多实例即时回收留后续专项。
