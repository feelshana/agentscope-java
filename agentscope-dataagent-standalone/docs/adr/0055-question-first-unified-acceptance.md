# ADR 0055：问题优先入口与统一验收

- 日期：2026-10-08
- 状态：Accepted
- 替代：ADR 0048/0049/0050 中必验与可选的区别，以及初始聊天和批量预填并列入口。

## 背景

最新实际建模日志登记两个 required:false 的空 SQL 问题，原发布门禁不要求它们完成；用户明确要求取消分级，每题生成 SQL 并确认，用问题驱动视图/Cube 建模。

## 决策

所有未归档问题采用同一验收要求；历史 required 只作读取兼容，不进入 Question、API 摘要、提示词或页面。旧凭据匹配旧 required=true/false 指纹，保留已有有效确认。无问题时基础模型仍可问数及按原流程发布。

初始提供批量问题表单；显式提交直接交给原生聊天链路，之后才显示对话。已有问题或原生待处理提案直接恢复会话。追加问题也用同一表单，聊天仅承载口径澄清与反馈。提交本身不批准工具；所有工程写入仍经 YAML-first 与原生 HITL。问题驱动复用/构建 View/Cube，平台仍通过 Wren 验证 SQL 与人工确认控制发布。

## 后果

历史可选问题未确认将阻断新业务版本发布；用户可明确归档不需要的问题。空 SQL 草稿允许保存需求，但必须持续引导补齐；不为了立即出 SQL 猜测未确定口径。
