# ADR 0076：SQL 问答对删除与折叠 SQL 兼容

## 状态

已接受（2026-10-15）

## 决策

SQL 问答对管理模块允许删除建模工作区来源和当前用户知识库的点赞来源。删除操作只能作用于对应来源目录内的 Markdown 文件，并继续执行 owner/group 校验；删除点赞来源后调用官方 Wren memory index，使召回索引与源文件一致。

官方 memory store 产生的 YAML frontmatter 允许 `sql` 使用折叠标量跨多行。管理模块读取时合并折叠行，展示和保存完整 SQL，不按第一行截断。

## 影响

建模删除影响下一次发布内容；点赞删除影响当前知识库的问答记忆。历史文件不迁移，编译产物和发布快照不直接编辑。
