# ADR 0052：对话阅读布局与知识库信息编辑

日期：2026-10-09
状态：已实现；浏览器及真实数据源联调按 spec 043 验收

## 背景

参考 `data-agent-multiAgent` 分支历史界面，按当前组件与用户反馈选择迁移样式。当前分支已包含附件持久化、历史分页与建模确认，不采用旧分支整文件替换。

## 决策

1. 侧栏使用浅灰蓝底色，品牌区与用户区不加水平分隔线；品牌区和页面抬头共用高度变量。历史会话只展示问题标题与时间，保留分页、选择和删除能力。
2. 底部显示头像和用户名，点击仅展示用户名。个人设置、退出及管理员菜单不在该入口展示。此决定只改变入口，不代表 BI 单点登录或后端权限控制已实现。
3. 执行过程显示为可展开的内联摘要与步骤；保留耗时、失败、中断及重试语义。Agent 标识使用渐变图标；回答正文提高行距、标题层次与内容间距。
4. Markdown 表格至少填满回答区域，表头与单元格统一居中；少列按等宽布局，多列允许自然列宽及横向滚动。使用轻表头、斑马纹和水平分隔，表头在表格独立滚动容器中定位。代码块限制高度并独立滚动。
5. 二级页面提供紧凑返回入口。知识库列表的更多菜单支持编辑名称、说明；服务端按所有者校验，拒绝重名和不合法字段，保持知识库 ID 与关联资产不变。
6. 数据源表单左侧试连，右侧取消、保存。试连成功才允许保存；参数变更清除成功状态，过期试连响应不覆盖新表单。连接参数与接口行为见 ADR 0051 / spec 042。

## 边界

- 用户入口简化不撤销后端 API 或已有令牌；独立部署的退出入口、BI 身份接入仍需产品规则确认。
- 知识库改名仅限所有者，不实施待办中的 QUERY / EDIT / MANAGE 共享权限。
- 表格居中是当前产品展示要求，不根据 Markdown 的对齐标记另行左/右对齐。
- UI 预览页只作为样式讨论样例，不代替真实会话、附件和建模场景验收。
