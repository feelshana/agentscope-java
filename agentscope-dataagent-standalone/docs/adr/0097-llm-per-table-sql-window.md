# ADR0097：统一 SQL 逐表时间窗口门禁与文档收敛

## 状态

已接受，2026-10-19。合并并取代 ADR0091、0092、0095、0096 的日期边界方案；按用户明确要求删除这四份重复且冲突的 ADR，引用统一指向本决策。ADR0083/0084/0088/0089 的日期拦截实现均为历史方案；其中采样、显式视图、原生历史与耗时观测等独立约束继续按当前代码适用。

## 决策

基础建模继续使用官方 enrich-context Auto-pilot，官方技能保持不变。事实表时间配置是与建模/问数状态独立的数据库资产，通过知识库页面管理；采样后的外部表由用户确认时间配置，可选 7/14/31/90 天或不限制，并指定一个采样识别出的时间列；只保存确认配置，不自动判定数据库真实表类型。

建模 CLI 的 query/dry-run/dry-plan/memory store 和问数 MCP 的 run_sql/dry_run/dry_plan 共用 SqlWindowGate。登记表通过 datasetId 在当前知识库数据库中关联逻辑名称（DatasetEntity.name），不读取 MDL、Wren 目录或视图定义，不把物理表名自动映射为另一套名称。名称不同就按未匹配跳过，接受漏检。

检查器仅将原始 SQL、登记的 LIMITED 表配置及当前时间交给无工具 LLM：识别实际使用的表及别名，每张表分别验证对应时间字段和有限范围，不取全库最小窗口。未使用表、不限制表、未登记表和匹配不上的视图跳过。中文逻辑名按数据库原值匹配。旧配置多个时间候选列暂按任一列有效判断，保存后只保留指定列。

返回 allowed、tables（table/timeColumn/hasCondition/windowDays/maxWindowDays）、reason。平台验证 JSON 类型和已返回条目的配置一致性；超时、不可用或非法输出拒绝。原始 SQL 和用户问题不改写，拒绝明细直接提供给 Agent 提示用户，同轮阻止继续试探 SQL；跨轮不保留拒绝或日期状态。

只读、QUERY/MANAGE、知识库范围、发布及排队撤权继续由原授权链路实施。耗时以 sql_window_gate 单独记录，检查日志不含完整 SQL 或数据行。空 LIMITED 配置直接放行，不产生风险日志。移除建模工作流窗口字段及旧建模级更新端点，配置保存不要求建模或发布。

## 限制

不建设 SQL AST 或视图/Cube 血缘分析。query_cube 不在本次逐表 SQL 门禁覆盖中；当前基础建模 Cube 命令限制保留。LLM 可能漏检、误判，JSON 校验不能证明表识别完整，门禁不保证执行计划性能。真实模型准确性与延迟需运行验收。当前安装版的物理 SQL 共用内部 WrenEngine.query/connector.query，但没有公开通用物理 SQL MCP 工具或平台可注册的执行前钩子；下沉拦截需要独立的 Wren 运行时集成及物理/逻辑名映射，本次保留平台共用检查器。

## 验证

见 spec083；mock 模型的单元测试验证协议、安全失败和接入，不替代真实 LLM 验收。
