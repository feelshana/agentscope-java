# ADR 0114：单库原生问数与工程能力整合

状态：Accepted（2026-10-26，用户确认方案并授权合并；实施验收见 spec094）；BI入口部分已被 ADR-0116 取代，其余边界仍有效。

取代：ADR0081 的多库工具绑定部分；其官方工具、权限隔离、只读与业务证据原则保持。

## 决策

1. 以同事当前建模与问数为主线，只绑定本轮明确选择的单个授权知识库；不恢复个人分支旧包装入口。零库对话不获得知识库查询工具。
2. 保留原生结果返回模型、按需调用 Python 和产物下载。双方实测都可完成分析；不因缺少自动 CSV 断言必然失败，不接回每次查询自动文件交付。公司导出权限不是此次需求。
3. 接入 BI 登录、私有图表、持久化会话、管理员模型配置与人工切换。调用级模型快照必须覆盖同轮辅助模型检查；独立新操作读取当前服务。
4. 将已验证的结构化 SQL 编辑及受限连接恢复适配进新生命周期，不覆盖新问题确认、草稿修订、准备状态或撤权保护，不重放写操作。
5. 先保存不可变源分支与真实测试证据，再验证最终组合；两边各自通过不能替代整合后的测试。历史功能设计只作为来源，不覆盖当前有效建模边界。

## 验证与后果

三方整合保留完整 Git 来源；冲突解决、迁移并集、当前配置与架构说明随实现更新。单库限制需要前后端及历史选择同时治理。模型服务切换不挽救已发出的故障请求；完整运行与发布验收仍需实际执行。
