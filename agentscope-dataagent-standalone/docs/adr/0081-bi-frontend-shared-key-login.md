# ADR 0081：BI 前端共享密钥免登

日期：2026-10-16
状态：已接受，用户确认协议由本项目定义，并要求同步实现及文档。

## 决策

采用 spec069 的 AES-256-GCM 单参数 ticket 换取固定30分钟JWT。BI前端持有共享密钥，不依赖BI后端、IM SDK或反向Session校验。前端密钥可提取，持有者可伪造任何用户名（包括管理员）；该限制已向用户解释并由用户明确接受，不能将此机制描述为可信SSO认证。防重放、时间限制、同源限制均不消除此限制。

复用本地唯一用户名与内部userId，首次进入自动创建普通用户，管理员由本地roles_csv及SQL维护。消费记录使用既有JPA数据库，不新增Redis；固定过期及跨重启重放保护。dev保留密码，prod关闭密码接口、表单和演示种子。身份凭据通过POST与同源iframe握手交付，不进入URL。前端存储按标签页隔离，新入口整页重载清除旧用户运行状态。

## 后果

BI会话退出、用户禁用与DataAgent JWT失效互不关联；关页不撤销JWT，角色SQL更新在重新免登后进入新JWT。现有7天JWT改为可配置默认1800秒，存量localStorage令牌不迁移；升级后需重新登录。同域路径需要前端构建和Nginx配套。生产可信身份、长稳容量、现有P1另行决策；本次不改变Agent并发或Wren工具链。
