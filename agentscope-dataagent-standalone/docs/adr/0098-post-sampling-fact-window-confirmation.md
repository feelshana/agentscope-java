# ADR0098：采样后先确认事实表时间范围，再启动语义建模

## 状态

已接受，2026-10-19。补充ADR0097的采样后交互，数据库配置独立性及SQL门禁不变。实现使用“现有字段说明LLM顺便判断角色”的默认选择；用户如指定人工分类可调整，未将默认选择记录成用户明确选择。

## 决策

采样完成后，工作台先加载未配置的事实表时间范围，保存成功后再自动启动现有建模Agent。维度表即使含注册/创建/更新时间也不弹时间窗口。已有有效配置不重复弹；新增事实表只补新增配置；关闭、加载或保存失败时暂停自动建模，刷新仍重新检查。

采样既有字段说明模型同时返回FACT/DIMENSION/UNKNOWN，不增加一次LLM调用。结果独立保存在数据库sample_summary_json的tableRole/tableRoleConfirmed，不依赖MDL。无法判断及旧摘要缺少角色时，仅显示行内人工角色确认，不直接当作事实表弹窗；判为维度后跳过并移除旧事实窗口，判为事实后进入时间配置。

配置仍存在dataagent_fact_query_window，通过现有独立API保存；“配置在建模前确认”不代表“配置由建模生成”。知识库页面保留编辑入口，不要求建模或发布。建模系统上下文读取已授权单库的登记策略，提示每张表自己的字段和最大窗口，不能把窗口当默认日期；CLI/MCP执行前仍独立校验。

外部表沿用当前范围，本次不将Excel/CSV自动加入时间配置。UI使用一次性start导航参数触发采样后的自动建模，消费后移除，刷新不重复启动；不新增后台任务或状态机，不修改官方技能。

## 验证

见spec084。真实LLM角色分类可能不准确，窗口内提供“这是维度表，跳过配置”纠正入口；历史摘要不自动重采样或猜角色。
