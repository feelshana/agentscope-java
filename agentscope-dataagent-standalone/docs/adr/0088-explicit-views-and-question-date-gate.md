# ADR 0088：显式视图授权、问题日期门禁与逐步计时

> 日期门禁部分已由 [ADR0097](0097-llm-per-table-sql-window.md) 取代；保留历史背景，其余独立约束按当前实现适用。

## 状态

已接受（2026-10-18，用户确认实施）。

## 决策

基础建模默认仅生成基础模型、确认关系和规则。完整保留官方 enrich-context；创建或修改 Wren 视图必须有用户明确请求、具体结构方案及确认，不将普通建模或文件确认视为视图授权。已有资产不自动删除，不自动发布。

问数在初始化 Wren 前使用无工具的结构化模型判断是否需要日期。涉及非维度数据而没有有限日期范围时先澄清；普通聊天、结构解释及明确维度查询不强制日期。日期继承绑定用户、会话、知识库、发布版本和分析口径。最新日期不能由采样最大值代替。

本决策替代 ADR0083/0084 的 SQL 正则/AST 日期执行门禁：不建设复杂 SQL AST，保留只读、授权、模型边界、超时与建模禁止画像。日期门禁和提示不能证明 SQL 实际使用过滤，也不能保证不扫描全表。可选画像探查默认不做，必要业务聚合使用确认范围。

原生日期和字符串日期采样识别写入结构化元数据；事实/维度建议须用户确认，未确认含日期的模型按未知受限处理。单轮成功 SQL 去重，跨轮不缓存数据。

复用框架中间件记录请求、门禁、模型和工具耗时，贯穿 Wren 排队/准备/执行；失败和取消也记录。日志不复制业务结果或凭据。

## 验证与限制

实现、测试及运行服务加载分别记录在 spec076 与共享记忆。不得以自然语言判断代替授权，不修改官方技能或编译产物，不改变历史已发布业务资产。
