# ADR0137：DataAgent 登录凭证固定 24 小时

## 状态

已接受，2026-11-05。取代 [ADR0136](0136-active-session-renewal.md)。

## 决策

DataAgent 在认证成功时签发有效期固定为 24 小时的 JWT。操作页面和发起请求均不重新签发凭证。前端在到期时显示现有重新认证入口，后端按签名中的到期时间校验受保护请求。

有效期由签发逻辑统一规定，旧的 TTL 配置不再参与签发。已有 JWT 仍按其签发时写入的到期时间校验。新 JWT 从平台读取身份与角色，沿用现有认证入口。

## 后果

移除续期接口、浏览器活动监听和用于应对令牌轮换的引导状态兼容逻辑。一次登录只使用一份凭证，角色变更随下一次认证生效。
