# ADR 0062：Wren 建模流程与点赞后查询记忆

- 状态：Accepted（已实现并通过构建与自动化验证）
- 日期：2026-10-09
- 关联：ADR 0057、0058、0059、0060「预检先于业务方案确认」；specs/054。

## 背景

产品面向自由问数。预设问题应帮助理解业务，而非要求用户先准备完整题单。当前「所有保留问题确认后才能发布」和「只能经建模发布增加确认示例」使流程过重。问数一轮可能包含多次 Wren 调用，用户看到的是最终答案；确认必须关联该答案实际执行的查询，不能给辅助 SQL 套用用户原始问题。

## 决策

### 建模遵循 Wren 官方流程

接入数据、基础语义模型就绪后即可问数。业务文档和用户预设问题均为可选输入；无题单也可进入对话，agent 结合已有模型、文档或用户描述的分析目标提炼语义，仅澄清关键歧义。问题表格保留并明确标注可选，不作为显示对话或发布的必要条件。

遵循安装版 generate-mdl/enrich-context/cube_proposals：先检查已有资产并复用，指标口径和基础粒度明确时建立 Cube，需要关联或复杂 SQL 时建立适合的视图，一次性问题不强制生成资产。Cube 按原始公式定义度量，保留所需实体字段、分析维度和时间字段，查询时选择粒度；不因用户只提月度问题就自动先丢弃客户身份字段。该原则落实于官方技能、提示词和业务方案，不在本轮新增资产适用性分析器或回归引擎。

重要关系、视图、Cube 等业务变化仍由用户审阅，复用现有原生 HITL 和完整文件方案。YAML 校验、编译、查询规划及必要的查询验证由 agent 调用 Wren 完成，技术失败自动修复。保留代表性结果审阅，但预设问题不再形成「全部逐题有效确认」的发布闸；保留工程检查和显式发布，不引入新的能力范围发布机制。未完成问题明确显示实际状态，不宣称已经回答。

### 最终答案反馈驱动查询记忆

每个 data-agent 最终答案下提供醒目的点赞/点踩图标与文字提示：请确认本次口径与结果，正确点点赞，有问题点点踩。反馈可选，不阻塞下一轮问数。只接受最终答案反馈，不在工具结果、中间叙述或每条 SQL 上增加确认按钮。

只有明确点赞才把本轮符合官方筛选条件的成功分析问答对写入查询记忆；未反馈、点踩和仅执行成功均不新增样例。不增加执行成功/可信/高可信等分级体系。反馈认可本轮答案，不宣称用户逐条审阅了 SQL。

保存基于平台记录的真实工具执行：绑定 conversationId、answerId/runId、toolCallId、ownerId、groupId，取得原问题或明确的业务子问题与实际 SQL。失败、被替代、探索性查看、辅助诊断查询不保存。不同业务子问题分别配对，不把用户整轮原问题绑定到每条不同含义的 SQL。Cube 使用本次真实生成并成功执行的 SQL；无法取得时不伪造 SQL，并明确保存结果。依赖多查询/Python 才能回答的整轮问题不得伪装成单 SQL 样例，只保存其中能独立表达其业务子问题的合格查询。

使用知识库独立运行目录承载点赞记忆，保留官方 knowledge/sql 格式，优先复用安装版 memory store/recall；不写全局共享记忆，不修改已发布快照，不要求为一次点赞重新发布模型。召回可同时使用已发布建模确认实例和该知识库点赞实例，示例用于参考，仍须重新经 Wren 查询。保存不改变模型、关系、Cube 或视图。

重复点赞幂等。点赞改点踩时撤销本次反馈新增的样例，不删除其他来源的独立保存记录；再点赞可以重试保存。失败要区分反馈已收到与样例保存失败，不能假报成功。执行链的必要关联信息只用于保存和追溯，本轮不另建通用分析案例平台。

## 与官方的差异及范围

Wren 当前 usage/memory 指引由 agent 默认保存有明确自然语言问题且成功执行的分析查询；排除失败、用户指出错误、探索性查询等。其默认策略无需等待明确确认。本项目按用户要求收紧为「只在最终答案点赞后保存」，由后端可信执行记录完成筛选和写入，避免 agent 把未获反馈的查询自行写入记忆。

本轮不实现：资产适用范围检查、指标边界回归、样例可信等级/状态治理、版本有效性检查或过期重验、发布能力范围声明。现有权限、Wren-only、工程预检、原生 HITL 与发布隔离继续保留；这些既有边界不属于新增治理能力。

## 后果

减少建模前置填表与逐题确认负担；问数学习由真实使用中的用户认可驱动。点赞不是业务正确性的自动证明，本轮不会自动拦截所有粒度或去重语义错误；不以新增防护能力已完成的名义描述效果。

- [usage memory](https://raw.githubusercontent.com/Canner/WrenAI/main/core/wren/src/wren/skills_content/usage/references/memory.md)：成功查询保存规则、原始问题、召回参考；本项目点赞门槛是产品选择。
