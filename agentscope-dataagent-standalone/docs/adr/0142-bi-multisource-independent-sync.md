# ADR0142：多源BI扩展使用独立任务与按日原子替换

## 状态
已接受，2026-11-06；用户已确认字段并授权实施。取代：无。

## 背景
旧七表绑定easybi单源，控制进度已在生产运行。新增数据来自多个MySQL与Doris；Doris为Duplicate模型，样本42876行只有3个eid，不能按eid或展示列去重。源端历史留存范围小于请求范围，Doris持续滚动删分区。

## 决策
- 新增独立部署脚本、owner、源指纹、锁、控制/暂存表，沿用现有正式镜像和目标库，旧任务不扩为通用任意SQL执行器。
- 代码维护固定源表/字段/SQL白名单。目标快照或业务日先暂存和校验后原子替换，进度与业务提交一致，真实重复行保留，私有技术主键不等于事件身份。
- 完成进度与可用历史、缺失区间分开；过期源分区不触发目标历史清理，源空监控快照不当业务零。跨日迟到用有限近期回刷及显式日期补跑处理，不承诺无限期追踪历史改删。
- 本任务不参与Wren问数或知识库生命周期。凭据位于外部私有配置，源只读；结构变动经显式版本化迁移，不随源新增列自动扩展。

## 备选
直接把六表加入旧任务会改变既有水位/全局成功语义及故障边界；按eid唯一或展示列哈希会丢真实事件；全历史重复追加不能幂等；全历史镜像删除会误删已归档点击；以上不采用。

## 后果
新增少量私有暂存、计数/校验账本与独立运维入口。六表不具备跨源全局快照，状态按表/天提供；当前部门、配额等仍是源报表当前口径。目标类型/加减字段需显式迁移及知识库建模调整；源已过期历史字段可能无法回补。实际Doris、66资源/吞吐和生产验收需现场确认。
