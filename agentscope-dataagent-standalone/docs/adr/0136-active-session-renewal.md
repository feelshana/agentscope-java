# ADR0136：DataAgent 登录凭证按用户活动续期

## 状态

已被 [ADR0137](0137-fixed-login-token-lifetime.md) 取代，2026-11-05。

## 决策

DataAgent 使用现有签名 JWT 管理短会话。前端在受保护页面就绪后监听实际操作，短时间内合并续期请求。服务端验证未到期的 Bearer 凭证，按其签名用户 ID 读取平台账号和当前角色，签发新凭证。凭证携带原始登录时间，最终到期取空闲窗口和原始登录上限的较早时间。旧凭证仍按原签名及到期规则验证。

后台轮询和流式输出不触发续期。前端按当前凭证到期时间退出，并检查续期响应是否仍属于原凭证。已失效的会话沿用分析云或开发登录入口。续期不读取 BI Local Storage 来重新登录，保持 ADR0116 的入口身份边界。

## 后果

主动使用可以跨过初次签发的 30 分钟，空闲时无需访问服务端即可显示退出状态。续期请求合并会带来秒级的空闲窗口偏差。无会话表或迁移，平台角色在续期时重新读取；已签发的旧凭证仍在其原时限内有效。
