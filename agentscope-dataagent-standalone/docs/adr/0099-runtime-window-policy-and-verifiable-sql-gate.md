# ADR0099：动态窗口只作运行策略，门禁结果独立留证

## 状态

已接受，2026-10-20。补充ADR0097/0098，并按用户最新确认替代“建模样例日期必须询问用户”的提示限制。

## 决策

平台具体查询窗口仍独立保存在数据库。建模和问数每轮只读本轮授权库的策略，不将具体天数写入MDL描述/业务规则；这些位置只写明确日期、小窗口等通用建议。真正的业务时间口径（例如滚动30天活跃）不是平台窗口，不能误删。历史工程由用户正常建模修订并显式发布，不通过平台重写官方编译产物或批量改线上模型。

建模Agent可以自行选择样例日期、直接验证，无需用户确认日期；样例只能表示验证范围，不改变用户原始问题。具体SQL执行仍经数据库策略门禁。样例和答案SQL须保持已确认的业务过滤一致，不由平台增加未经确认的业务条件，不增加SQL AST或业务路由。

新增独立SQL_WINDOW_GATE审计文件，记录调用入口、trace/session/group、SQL指纹、配置快照、检查明细及允许/拒绝/跳过/缓存终态。主Agent自发澄清不算工具门禁拒绝，检查器原始模型消息不混入主Agent会话日志。

验收绕过主Agent的自然语言决策，直接调用实际CLI/MCP Java适配器；使用真实配置LLM和合成表配置，但执行端用测试替身，拒绝必须发生在数据库查询前。不声称覆盖Wren物理执行或整个HTTP/UI链路。

## 限制

LLM门禁可能误判，特别是未匹配视图/未登记表按现有取舍跳过。只检查单条SQL，没有跨查询累计范围策略；本次不扩展查询拆分能力。真实验证失败需如实记录，不能用mock通过代替。
