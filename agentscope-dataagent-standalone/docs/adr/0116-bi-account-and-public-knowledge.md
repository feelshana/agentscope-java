# ADR0116: BI客户端账号接入与公共知识库

状态：已接受（用户2026-10-28批准实施）

## 决策
同源BI入口读取username/account，由显式启用的服务器端点关联或创建平台普通用户并签发JWT。此方案接受客户端可修改身份的边界，不视为可信SSO；不再依赖前端AES票据，新旧入口独立控制。平台管理员角色不得来自客户端。

人员资料按唯一登录账号匹配，中文名仅显示检索。BI密码不迁移，已有平台ID与授权不替换。组织筛选批量授权只保存具体人员快照。

管理员集中选择全员可使用的库，以库级标识接入统一QUERY权限；默认关闭，非匿名公开，保留显式授权。读取只返回受限数据投影和已发布模型，写入仍MANAGE。个人会话、附件和连接配置不因库公开而公开。

## 后果
新增库级可见性和用户资料字段，首次DDL与已有库迁移并行交付。原ADR0114整合中关于AES正式入口的选择在本入口启用时被本决定替代，其余整合边界仍有效。真实BI与代理需现场验收，不因本地模拟通过而宣称生产接入完成。
