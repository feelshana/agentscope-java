# ADR 0075：语义建模中的 SQL 问答对管理与视图文件路径

## 状态

已接受（2026-10-15）

## 决策

语义建模页面新增独立的 SQL 问答对模块，统一展示官方 Wren 产生的建模问答对和问数点赞后保存的问答对。建模来源仍以工作区 `knowledge/sql/*.md` 为事实源，修改后标记为待发布；点赞来源使用当前知识库隔离的 `runtime/liked-examples/knowledge/sql/*.md`，修改后通过官方 Wren memory index 重建索引。所有接口按用户和知识库校验，并限制文件名与路径。

视图目录返回的文件路径必须是实际存在的工作区文件；没有 `sql.yml` 时使用 `metadata.yml`，避免前端请求不存在的派生路径导致 404。

## 影响

问答对编辑不会改写官方编译产物。建模问答对需显式重新发布后才进入问数工程；点赞问答对更新后立即重建官方记忆索引。历史文件不迁移。
