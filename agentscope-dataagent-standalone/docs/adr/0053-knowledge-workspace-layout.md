# ADR 0053：知识库工作台统一布局

日期：2026-10-09
状态：已实现前端；真实浏览器及业务操作验收待开展

## 背景

用户通过两版 HTML 预览选择：三个页面采用第一版的布局、样式和色调，知识库卡片三点菜单采用第二版的锚定菜单。改造之前先提交回退点 `77c637a1`，新布局独立留在工作区待确认。

## 决策

1. 知识库列表增加搜索、排序、卡片/列表切换；卡片按名称、说明、数据量、创建时间和操作排序。不显示实现细节说明。
2. 菜单使用共享 `WorkspaceMenu`，通过 portal 定位到触发按钮旁，避免容器裁剪；支持点击外部关闭、Escape、方向键和操作后焦点返回。删除保留既有确认流程和接口。
3. 知识库详情采用面包屑、页头、顶部页签与单一内容区；移除重复侧栏。上传入口使用弹窗，保留拖拽、多工作表选择、覆盖确认、任务状态和重试。图谱、目录及全屏建模继续使用现有实现。
4. 数据集详情拆分数据预览、字段信息和技术信息；预览采用紧凑表头、固定表头/行号、内部滚动。数据值保持原样，不自动舍入、不猜测字段的业务单位。
5. 字段说明与数据集描述分别编辑。补齐描述更新接口，沿用数据集所属用户校验，保存后刷新数据源注册信息并标记语义模型待更新；字段类型仍为只读。
6. 样式封装在 `knowledge-workspace.css`，不覆盖回答表格、聊天页及管理页的布局。全局侧栏及共用页头统一为 64px，面包屑为 14px，业务术语和例行任务沿用共用页头，不迁移预览里的示例数据和页面切换控件。

侧栏“更多”使用三个点，菜单向右展开，仅提供工作区；点击外部、Escape、路由切换或窗口缩放关闭。

字段说明编辑采用宽弹窗与多行输入；业务术语、例行任务沿用知识库工作台视觉，保留现有业务接口。

## 边界

2026-10-10：知识库卡片与列表增加“创建人：用户名”，使用低强调的元信息样式，长用户名省略并可悬停查看。接口返回 ownerUsername，列表批量读取创建人，避免每个卡片单独查询用户；用户记录缺失显示“未知用户”，不使用当前登录人冒充创建人。不增加共享权限或修改 owner 归属。

除补齐数据集描述保存与创建人展示外，不修改权限、Wren 查询流程、导入接口及存储。知识库共享规则按 ADR 0050，身份协议和多库范围待确认后实施。更换视觉布局不等于新增共享授权。
