# ADR 0050: 知识库共享权限与 BI 用户身份

日期：2026-10-08；更新：2026-10-10
状态：产品权限规则已确认；身份协议及多库范围待确认，尚未实现

## 当前代码

知识库、数据集按 ownerId 隔离，使用本地账户和 JWT。Agent RUN/EDIT 与知识库授权独立。DatasetScope 使用单个 ownerId，Wren 按该 owner 枚举库；共享问答必须调整运行作用域，不能只增加列表卡片。

## 已确认决策

1. 在 65 单实例部署前后端、Docker 沙箱及 Wren，为 65 开通业务数据库访问。
2. BI 全量用户同步到本地用户表，用户进入 DataAgent 无须再次输入账号密码。用户同步与访问身份验证是两件事。
3. 首期不分组织或租户。DataAgent 全局管理员可以查看、管理所有知识库；普通用户依授权访问，创建者自动有管理权限。管理员身份由服务端可信角色决定。
4. 知识库仅保留 QUERY（使用）与 MANAGE（管理），原 EDIT 和 MANAGE 合并。管理包括使用、详情、数据维护、建模、发布、成员授权及删除库。
5. QUERY 可看到获授权卡片、选择问答、下载本人问答 CSV 明细；不能进入库/数据集详情、预览原始数据、下载源文件或编辑。前后端均执行规则。
6. 撤权禁止新问答、续问和新数据工具查询；本人已有历史和附件继续可读。库管理员不因管理权限获得他人私有会话和附件。
7. 首期不做行列级权限。QUERY 是数据读取权限，问答和 CSV 可能包含库内明细，隐藏详情不代表限制查询数据。
8. 旧库保持私有，普通用户必须显式授权；新库默认创建者及全局管理员可管理。

## BI iframe 与免登录建议（协议待确认）

iframe 在 BI 指定区域嵌入 DataAgent，本身不决定新开标签。BI 可在当前工作区放 iframe，也可先打开新的 BI 页面再放 iframe。建议在主内容区域大尺寸展示，避免窄小弹窗。

不采用浏览器裸用户名即登录及统一 123456 的生产方案：改请求用户名即可冒充其他用户，破坏授权和私有历史隔离。建议 BI 后端提供短期可信身份凭据，DataAgent 验证后建立会话，用户无感登录；或使用经过 BI 会话验证的可信网关。该建议仍需用户和 BI 团队确认，本次未实现或视为已批准。

优先以 BI 稳定用户 ID 映射本地 userId，用户名/显示名可更新；改名不能创建新账号而丢失授权和历史。同步不导入 BI 密码，不自动授予管理员。建议生产同步用户禁用本地密码入口，开发路径另行保留。同步频率、停用规则、管理员映射及旧用户映射待确认。

iframe 需约定 HTTPS、允许嵌入的 BI Origin、Cookie/令牌传递及过期/登出。postMessage 校验来源并指定目标 Origin。采用同域子路径代理时同步适配资源、路由及 API 路径，不能仅修改 nginx 地址。

## 数据作用域、撤权与删除

- 前端传 groupId，后端按当前身份查 ACL，解析真实 (ownerId,groupId)。一个共享库也要查库所有者数据，不能查提问用户 ownerId。
- Wren、检索、概览、导出和建模统一使用授权上下文，模型参数不能扩权。维护工具检查 MANAGE。
- 运行中撤权后不再执行新的数据工具查询，保留已经产生的本人历史和附件。定时任务按任务用户的当前权限运行。
- 删除库清理成员与模型/任务引用，不静默删除别人已有会话；旧历史提示库已删除并禁止继续查询。
- 多个不同创建者的库：例如一次选择甲的销售库和乙的客户库。建议首期一次只选一个库，跨库提问/JOIN 后续设计；仍待用户确认。空选库不能自动扩大到平台全部库。

## 分页与容量建议

知识库列表服务端分页，建议默认 20 条、上限 100 条；先权限过滤，再搜索、排序和分页。授权选人使用分页用户目录。列表只查元数据，不启动 Docker/Wren、不逐库连接数据库。

10 并发是目标，尚未验证；默认沙箱总数 8，同库 Wren 调用串行，详见部署与容量评估。

## 待确认

1. BI 稳定用户 ID、可信身份协议、同步/停用和管理员映射。
2. 首期是否一次仅选择一个知识库。
3. 65 可分配 CPU/内存、共用服务及模型限额。
