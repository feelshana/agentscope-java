# ADR0123：仅放开 MySQL 5.7 数据源接入

## 状态

已撤销，2026-11-02。真实5.7问数因Wren生成WITH报1064，用户决定上线暂不支持5.7，连接放开已回退，ADR0113恢复完整有效。下文保留当时方案，不代表当前行为；验收与后续候选见spec107及20261102-mysql57-connection-admission报告。

取代：ADR0113（仅外部源连接最低版本部分；保留 SQL 语法提示和日期常量规则）。

## 背景

公司存量业务源包含 MySQL 5.7，现场连接、认证和版本查询成功后被平台版本门禁阻止。完整方言适配方案未获采纳，用户明确只允许改连接检测及保存，不改 Wren、提示词或其他业务流程。

## 决策

数据源管理允许 MySQL 5.7、MySQL 8.0及以上或 Doris 进行连接测试、新建和修改；其余原有连接、认证、只读及权限检查保留。5.6及更早版本不放开。

接入成功不等于建模、发布或问数兼容；这些阶段仍使用现有 Wren 和 MySQL 8.0 语法提示，不能声称支持所有5.7查询。真实流程失败时记录具体阶段和 SQL，不自动追加转换器或物理 SQL 回退。

## 备选方案

- 完整能力识别和 AST 转换：保留为后续候选，本次不实施。
- 直接允许所有低版本：不符合本次明确的5.7范围，不采用。

## 后果

可以保存5.7连接并继续实际验证。官方引擎可能展开 WITH，即使简单查询也可能失败；不以入口测试或 Mock 证明全流程可用。无数据库迁移、配置或生产环境改动。
