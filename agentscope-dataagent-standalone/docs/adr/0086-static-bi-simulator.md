# ADR 0086：独立静态 BI 模拟入口

日期：2026-10-19

状态：接受（用户批准先本地跑通，需要云部署时通知）

## 决策

模拟BI首页和iframe宿主作为独立联调材料放在docs/integration，不新增生产后端认证接口，不随JAR自动公开模拟用户选择入口。复用现有bi-login.mjs、真实免登/JWT/用户库和授权。模拟密钥通过外置私有配置提供，Git仅带无有效密钥的示例。

本地用Node内置HTTP静态/流式代理复现同源子路径；云端改为Nginx提供相同静态文件和应用代理，无Node部署依赖。保持用户名和JWT不进URL，用户名只作为模拟宿主身份，管理员权限来自数据库。保留每标签页固定身份和刷新不续期规则。

## 边界

此入口用于已约定的前端持钥方案验证，既有ADR0081风险接受不变。真实BI最后仍需确认用户名来源、路由生命周期和嵌入策略。当前不部署云端，不建设BI后端，不变更业务模型或清理已有数据。

## 执行进度补充（2026-10-20）

以上“当前不部署云端”是本决策初始的本地实施阶段边界。用户随后授权并配合完成独立云端演练，实际进度见模拟BI专项报告和上线总账；本次整理提交不新增部署授权或自动更新云服务，正式BI接入仍待联调。
