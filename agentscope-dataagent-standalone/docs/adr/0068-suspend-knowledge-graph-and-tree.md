# ADR 0068：暂缓知识图谱与树结构目录展示

日期：2026-10-10。状态：已实施，待用户整体试用。

## 决策

知识库详情仅展示数据集与语义建模，移除知识图谱和树结构目录页签。旧 graph/tree 查询参数回退到数据集视图，不挂载组件、不发起图谱请求。保留组件及已有数据以便后续恢复。

GraphRAG 构建服务和 `/api/dataset-groups/{id}/kg/**` 控制器由 `dataagent.knowledge-graph.enabled` 控制，默认 false，不创建构建服务；旧表关系图 `/api/dataset-groups/{id}/graph` 默认返回 404。开关只恢复后端能力，恢复前端入口需另行决定。

## 调用链核对

- 数据文件上传和数据库表关联没有自动调用 GraphRAG 构建；树结构目录只在前端根据数据集元信息生成，没有独立后端构建流程。
- 文档上传的 DocEnhance、数据变更后的基础模型发布属于 Wren 建模流程，继续保留。
- Wren 关系定义、语义建模中的模型关系图、问答证据与检索不属于此次停用的知识图谱页签，继续保留。
- 不删除图谱表、历史结果或关系元数据，不迁移数据库。

## 同期分支合并

当前分支合并 `origin/data-agent-multiAgent-Mdl` 截止 `9f8b0462`：新增提交为 `b7f18957`（Wren 建模）、`a240788c`（合入本分支旧提交）及 `9f8b0462`（问答反馈与业务查询记忆）。保留现有工作台样式，并接入建模状态与新版建模入口。构建产物由合并后的源码重新生成。
