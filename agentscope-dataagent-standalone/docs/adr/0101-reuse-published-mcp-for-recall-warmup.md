# ADR0101：在实际查询MCP预热召回并公开准备状态

- 状态：接受
- 日期：2026-10-20

先完成实际MCP的只读召回预热、冗余status进程优化及可观测状态。预热与请求使用同一WrenInstanceRegistry实例预算、授权门锁及回收机制，不保留独立无预算实例。固定预热文本不成为用户输入或正式SQL素材。发布先失效旧实例，随后索引准备和预热，避免刚预热即被控制器再次销毁。

安装版memory index输出只有LanceDB分支包含Indexed N schema items，可据此省去status；未知输出兼容fallback，grep不能冒充成功。官方CLI未暴露独立示例同步，暂不改安装包或写自定义索引服务。

此步仍为发布后准备，失败不回滚发布。候选快照、派生索引、MCP实例就绪后原子切换需要独立双版本生命周期及容量验收，不声称本步已提供；已有版本服务延续与运行目录并发切换问题应在该阶段一并处理。实测报告记录本步真实覆盖和未测项。
