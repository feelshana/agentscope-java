# ADR0100：发布后提前准备官方问数索引

- 状态：接受
- 日期：2026-10-20

## 决定

已发布工程索引是派生物，发布提交后异步准备，使用有界调度、同库合并与现有源hash锁。失败不回滚发布，问数仍按需检查、重试；点赞保存的源变化检测保留。只缓存同一MCP实例无参数get_instructions成功结果，每次命中仍授权，发布失效/销毁丢弃。

## 理由与影响

首次召回同步构建索引增加问数等待；提前构建可转移成本，但不能消除官方模型冷加载。增加细分耗时以实测区分索引、排队和执行。不通过自定义召回或删除权限复核换取速度。预准备是库级派生资产维护，使用事件中的资源owner定位工程，不将其替代请求用户；请求仍使用原DatasetScope与QUERY授权。事务回滚不准备。后台状态通过execution-timing日志观察，暂不新增前端状态API。

## 验证

见spec086与当前测试记录。未重启服务或取得真实端到端加速数据前，不宣称达到5–8秒。
