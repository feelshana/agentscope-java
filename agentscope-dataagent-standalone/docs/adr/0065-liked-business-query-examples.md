# ADR 0065：点赞后保存成功业务查询样例

- 状态：Accepted（用户已授权文档和开发）
- 日期：2026-10-10
- 关联：ADR 0062/0063、specs/056；对应决策由本 ADR 取代，旧 ADR 不修改。

## 背景

SQL 成功但遗漏查询声明会导致点赞漏存。用户只要求保存点赞后的业务中文 question 与 SQL，且不考虑撤回。

## 决策

wren_run_sql 必填 query_type（BUSINESS / DIAGNOSTIC）与包含中文的 question；非法参数不执行。点赞最终答案时从服务端当轮成功历史保存全部 BUSINESS 的 question、SQL 和实际 limit。回执绑定类型和执行参数。移除 wren_answer_queries，不依赖声明。记忆 SQL 含实际 LIMIT，召回执行时转为工具 limit。重复点赞幂等、保存失败可重试；后续点踩仅记录反馈，不删除样例。新版本状态和记忆目录不读取、迁移或补存旧数据；无类型历史调用不保存。

## 验证与取舍

通过参数、成功回执、反馈、CLI 和装配测试验证；多租户必须覆盖看不到他人的数据。固定安装版 CLI 实测不得被模拟测试替代。禁用问数工作区上下文同时停止其旧 MEMORY.md/knowledge 注入；本项目动态知识库与官方示例仍保留。

## 不做

历史数据处理、用户自定义规则、点赞撤回、自研检索。
