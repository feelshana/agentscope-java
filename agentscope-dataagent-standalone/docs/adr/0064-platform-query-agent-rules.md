# ADR 0064：问数助手统一加载平台运行规则

- 状态：Accepted（用户已授权文档和开发）
- 日期：2026-10-10
- 关联：ADR 0062/0063、specs/056；对应决策由本 ADR 取代，旧 ADR 不修改。

## 背景

旧工作区 AGENTS.md 仅初始化一次，代码提示词更新后仍注入旧规则。所有用户使用同一类 Agent，无自定义需求。

## 决策

主问数 Agent 装配时通过 HarnessAgent 原生 sysPrompt 直接设置平台提示词，关闭工作区上下文注入；动态知识库上下文和技能仍保留，建模 Agent 不改变。部署级配置仍统一对所有用户生效。重启后新装配实例加载最新规则，不覆盖旧文件。仓库根 AGENTS.md 是开发规范，不受影响。ownerId / DatasetScope 隔离不变。

## 验证与取舍

通过参数、成功回执、反馈、CLI 和装配测试验证；多租户必须覆盖看不到他人的数据。固定安装版 CLI 实测不得被模拟测试替代。禁用问数工作区上下文同时停止其旧 MEMORY.md/knowledge 注入；本项目动态知识库与官方示例仍保留。

## 不做

历史数据处理、用户自定义规则、点赞撤回、自研检索。
