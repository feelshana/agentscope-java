# ADR0143：管理会话检索复用消息投影

## 状态

已接受，2026-11-11。取代：无。

## 背景

已确认的历史页需要用户提问正文搜索、每会话问题数和筛选后的统一统计。既有消息以 JSON payload 保存；逐行解析会话或让前端汇总全部正文会增加请求和内存，并扩大正文暴露面。

## 决策

在既有消息投影内保存规范化角色及仅 USER 的正文，不改变原始 payload 和引擎事实源。后台既有索引任务分批补齐旧消息，条件更新避免覆盖并发新内容。管理列表在数据库完成过滤、聚合、排序和分页；所有新读面保留当前全局管理员校验与附件隔离。

## 备选方案

请求时读取全部 JSON 或引擎文件：首屏与数据量线性增长且重复解析。独立搜索服务：当前规模不值得引入新组件。数据库专有 JSON 查询：不利于现有 MySQL/H2 双环境。

## 后果

升级需增量两列及索引，空库 DDL 同步。旧数据整理期间统计明确标记未完成；读取不触发全库同步回填。正文包含搜索词的扫描仍受数据库规模影响，后续可基于实际监测增加专门全文索引。
