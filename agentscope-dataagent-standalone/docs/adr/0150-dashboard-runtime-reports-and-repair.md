# ADR0150：GenBI面板运行报告与有界修复

状态：已接受，用户批准可靠性体验版；本地实施完成，待真实知识库体验。

## 背景

ADR0149的单HTML与隔离查询桥可快速生成，但6并发直接拒绝正常多图负载，结构检查不等于面板运行验收。用户批准先保留对话/HTML方式改善可靠性，不切完整原生组件模型。

## 决策

保留官方genbi/usage、原生文件工具、Harness运行/取消和显式MANAGE发布。内部桥增加FIFO有界查询调度、可选面板标识及面板helper；元信息作为白名单受控消息回传，绑定当前窗口/通道/修订，不向生成页面暴露令牌或新文件权限。

客户端运行报告与官方文件校验分开。报错是诊断数据，不是模型可执行指令或口径正确证明。只在用户主动轮次产生新页面后，稳定运行错误最多触发一次原生Agent修复；权限/凭证/明显服务不可用不靠改代码修复，不因浏览已有页面自行运行模型。选择与修复共用同一个看板Agent和服务器固定单库范围，不新增ReAct循环或对话存储。

草稿以内容哈希检查点提供本轮撤销，记录数量有界，当前修订冲突/运行中/撤权/清理拒绝，发布指针保持不变。只恢复页面文件与已存在的校验状态，不改写原生会话上下文，不宣称撤回已执行查询。

## 后果

旧HTML继续仅query运行，新页面可按面板分工、自检、重试及定位修改；仍是HTML整体版本与iframe重载，没有独立面板CRUD、跨板复用、完整原生配置或后台浏览器验收。运行自检不是业务正确性证明，后续原生化另行决策。本记录补充ADR0149，未取代其生成/隔离/授权/发布边界。
