# ADR0148：管理员只读回看会话视觉内容

- 状态：已接受，2026-11-13用户确认；取代ADR0141的仅正文投影限制，其余独立接口/身份校验原则保留。

## 决策

管理员历史复用普通会话展示组件，但独立只读加载与授权，不借用他人身份访问普通API，不挂载发送、执行、重置、删除或反馈写入能力。按轮展示持久知识库快照与已有反馈，缺失历史不推断。

管理资源接口每次校验全局管理员与目标用户/main会话；图表从该会话特定位置的render_chart结果解析，持久图表再次核对owner。图片只从该用户该会话的持久Artifact读取，不开放工作区路径或任意URL。正文资源引用经只读适配，外链/未知图片不自动加载，资源响应private/no-store。已删除资源显示不可用；不重跑工具补图。

页面按轮分页，反馈按详情页批量读取；不将文件反馈接入列表全量扫描，不新增数据库迁移。原会话、图表、附件和反馈普通接口维持所有者权限。

## 后果

管理员获得已保存业务图表及图片的只读可见性，这是用户明确授权的管理功能扩展；原始工具记录和任意文件不随之开放。老版本未持久化或已清理的视觉结果无法还原，需明确提示。正文查看不新增操作审计，沿用原边界。
